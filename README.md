# ourfuture studio · 직접 해 보기

블로그 「기계와 생각」·기술 노트·SQLD 공부에 연결되는 정적 체험 모음입니다.

- 첫 화면: https://ourfuture-studio.github.io/
- 머신러닝과 기술 노트 30개: https://ourfuture-studio.github.io/viz/
- SQLD 쿼리 실험 12개: https://ourfuture-studio.github.io/sql/

VIZ는 자체 가상 데이터를 JavaScript로 계산하는 독립 HTML입니다. `?shorts=1`로 녹화용 화면을 엽니다.

SQL은 sql.js 1.13.0 / WebAssembly로 브라우저 메모리의 SQLite에서 실제 쿼리를 실행합니다. 외부 DB 서버·로그인은 필요하지 않습니다. 예제는 직접 만든 교육 자료이며 Oracle·MySQL의 모든 문법과 동작을 재현하지 않습니다. sql.js의 라이선스와 저자 고지는 `sql/vendor/`에 있습니다.

이 저장소는 원본에서 생성한 공개본입니다. 원본을 수정하고 공개본 생성기를 다시 실행해 갱신합니다. 비공개 원고·편집 링크는 포함하지 않습니다.
