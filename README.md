# ourfuture studio · 인터랙티브 그래프

블로그 「기계와 생각」과 기술 노트에 딸린 인터랙티브 그래프 모음입니다.

- 첫 화면: https://ourfuture-studio.github.io/
- 모음: https://ourfuture-studio.github.io/viz/

각 페이지는 HTML 파일 하나로 끝나며 외부 스크립트를 쓰지 않습니다. 데이터는 모두 직접 만든 가상 데이터입니다.
주소 뒤에 `?shorts=1`을 붙이면 9:16 쇼츠 녹화 화면이 됩니다.

이 저장소는 작업 폴더의 `깃허브_공개본_만들기.py`로 만든 공개본입니다. 고칠 때는 원본을 고친 뒤 다시 만듭니다.
