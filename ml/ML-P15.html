같은 예제의 이론

PCA: 열을 줄이면 무엇을 남기는 걸까?

티스토리 글은 비공개 검토 중입니다. 공개 후 같은 번호로 찾을 수 있습니다.

티스토리 이론 찾기 (공개 후) →

이번 입력

표본 첫 열 둘째 열
1 1 1
2 2 2
3 3 3

직접 만든 학습용 숫자입니다. 원리를 확인하는 예제이며 실제 성능 비교는 아닙니다.

1→2→3 순서로 실행하고, 4에서는 homework = None 한 줄만 바꿔 보세요. 각 실행은 필요한 앞 코드도 함께 실행합니다. 앞 코드를 바꾸면 뒤의 결과에도 반영됩니다.

실행 버튼을 누르면 Python을 준비합니다.

1. 직접 구현하기

아직 실행하지 않았습니다.
예상 결과 보기
직접 구현: 2차원을 1차원으로 → [-1.414  0.     1.414]

소수 끝자리·축의 부호 등은 실행 환경에 따라 다를 수 있습니다.

2. 라이브러리로 확인하기

아직 실행하지 않았습니다.
예상 결과 보기
sklearn: [-1.414  0.     1.414]

소수 끝자리·축의 부호 등은 실행 환경에 따라 다를 수 있습니다.

3. 같이 풀기

특성 2개를 주성분 1개로 줄이면 출력의 열은 몇 개일까?

  1. 변환 전 입력에는 특성 열이 두 개 있습니다.
  2. n_components=1은 각 행에 주성분 좌표 하나만 남긴다는 뜻입니다.
  3. 따라서 변환 표의 열은 1개입니다. 표본 세 개라면 3행 1열이며, 행 수는 유지됩니다.
아직 실행하지 않았습니다.
예상 결과 보기
변환 전: 2 열 → 변환 후: 1 열

소수 끝자리·축의 부호 등은 실행 환경에 따라 다를 수 있습니다.

4. 아주 쉬운 과제

특성 3개를 주성분 2개로 줄이면 출력의 열은 몇 개일까?

힌트: n_components=2이다.

아직 실행하지 않았습니다.

정답과 이유 보기

n_components=2이면 변환 결과의 열도2개입니다. homework = 2로 적습니다.

기억할 조건

  • 축의 부호가 반대여도 같은 직선입니다. 출력의 부호만 보고 직접 계산과 라이브러리가 다른 원리라고 판단하지 않습니다.
  • 기본 PCA는 자동으로 각 열의 단위를 같게 만들지 않습니다. 단위가 다른 특성은 스케일 처리를 검토해야 합니다. 큰 분산이 항상 예측에 중요한 정보라는 뜻도 아닙니다.
