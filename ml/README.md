# 머신러닝 실습15편

티스토리는 이론과 원리, 이곳은 같은 예제의 실제 Python 실행을 맡습니다. 14번은 기준 PDF 번호가 비어 있어 유지합니다.

실행 도구는 Pyodide0.28.3(CDN)와 해당 배포판의 numpy·pandas·scikit-learn입니다. 처음 실행에는 네트워크가 필요합니다. 각 실행은 새 Python 이름 공간에서 앞 블록까지 순서대로 실행하므로 다른 실습의 변수가 섞이지 않습니다.

원본 Python·노트북은 files/에 보관합니다. 공식 참고: https://pyodide.org/en/0.28.3/usage/quickstart.html

사용자가 요청한 양방향 연결을 위해 기존 이론 글2편의 일반 글 주소를 연결하고 현재 비공개임을 표시합니다. 비공개 접근 권한은 그대로이며 로그인한 작성자만 읽을 수 있습니다. 편집/관리 URL·로컬 원고 경로·Notion 링크는 포함하지 않습니다. 나머지13편은 공개 후 같은 번호로 찾는 검색 링크를 제공합니다.
