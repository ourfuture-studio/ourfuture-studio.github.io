같은 예제의 이론

부스팅: 다음 모델은 무엇을 보완할까?

티스토리 글은 비공개 검토 중입니다. 공개 후 같은 번호로 찾을 수 있습니다.

티스토리 이론 찾기 (공개 후) →

이번 입력

입력 x 정답 y
1 1
2 1

직접 만든 학습용 숫자입니다. 원리를 확인하는 예제이며 실제 성능 비교는 아닙니다.

1→2→3 순서로 실행하고, 4에서는 homework = None 한 줄만 바꿔 보세요. 각 실행은 필요한 앞 코드도 함께 실행합니다. 앞 코드를 바꾸면 뒤의 결과에도 반영됩니다.

실행 버튼을 누르면 Python을 준비합니다.

3. 같이 풀기

실제값이 5, 현재 예측이 3이면 잔차는 얼마일까?

  1. 잔차 공식은 실제값−예측값입니다. 순서를 바꾸지 않습니다.
  2. 주어진 값을 넣으면 5−3=2입니다.
  3. 잔차가 양수 2이므로 예측이 2만큼 부족합니다. 다음 과제는 이 2의 절반만 예측에 더하는 연습입니다.
아직 실행하지 않았습니다.
예상 결과 보기
5 - 3 = 2

소수 끝자리·축의 부호 등은 실행 환경에 따라 다를 수 있습니다.

4. 아주 쉬운 과제

현재 예측 3에 잔차 2의 절반만 더하면 얼마일까?

힌트: 3 + 0.5*2

아직 실행하지 않았습니다.

정답과 이유 보기

3+0.5×2=4입니다. homework = 3 + 0.5*2로 씁니다.

기억할 조건

  • 잔차를 그대로 배우는 설명은 여기의 제곱오차 조건입니다. 모든 부스팅과 모든 손실이 똑같이 작동하지는 않습니다.
  • 나무를 더 많이 쌓으면 학습 오차가 줄어도 새 데이터 예측이 나빠질 수 있습니다. 학습률과 반복 수는 별도 검증으로 정해야 합니다.
