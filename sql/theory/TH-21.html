GROUP BY의 열 순서는 출력 순서일까

일반 GROUP BY는 결과 순서를 보장하지 않는다. GROUP BY 열 순서와 달리 ROLLUP의 열 순서는 생성하는 소계에 영향을 준다.

핵심 먼저 GROUP BY는 같은 그룹의 행을 묶으며 결과 행의 순서를 보장하지 않습니다. 출력 순서가 필요한 경우 ORDER BY를 명시합니다. 두 그룹 열의 나열 순서만 바꿔도 일반 GROUP BY의 그룹 조합은 같습니다.

어떤 자료와 조건을 볼까요

부서 20의 주문을 먼저 입력하고, 그다음 부서 10의 주문을 입력했습니다. 그룹 집계 화면이 입력 순서나 그룹 열 순서와 항상 같을지 생각해 봅니다.

답을 가르는 기준은 무엇일까요

GROUP BY의 결과는 부서·채널 조합마다 한 행입니다. 구현이 해시나 정렬 중 어떤 방식을 택하는지는 출력 순서 계약이 아닙니다.

ROLLUP의 열 순서는 생성할 소계에 영향을 줍니다. 여기서 열 순서가 그룹 조합을 바꾸지 않는다는 설명은 일반 GROUP BY에 한정합니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 정렬을 지정하지 않은 그룹

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

세 행의 값 조합을 확인합니다. 이 표의 표시 순서는 실행 결과의 보장이 아닙니다.

WITH sales (dept, channel, amount) AS (
    SELECT 20, 'WEB', 5 FROM dual
    UNION ALL
    SELECT 10, 'SHOP', 8 FROM dual
    UNION ALL
    SELECT 10, 'WEB', 3 FROM dual
)
SELECT dept, channel, SUM(amount) AS total
FROM sales GROUP BY dept, channel;

예상 결과

DEPT CHANNEL TOTAL
10 SHOP 8
10 WEB 3
20 WEB 5

표시 순서는 보장하지 않고 값 조합만 비교합니다.

조건과 구조를 바꾸어 비교해 봅니다

실행 2 · 출력 순서를 따로 지정

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH sales (dept, channel, amount) AS (
    SELECT 20, 'WEB', 5 FROM dual
    UNION ALL
    SELECT 10, 'SHOP', 8 FROM dual
    UNION ALL
    SELECT 10, 'WEB', 3 FROM dual
)
SELECT dept, channel, SUM(amount) AS total
FROM sales GROUP BY channel, dept
ORDER BY dept DESC, channel;

예상 결과

DEPT CHANNEL TOTAL
20 WEB 5
10 SHOP 8
10 WEB 3

두 SQL은 같은 그룹과 합계를 만듭니다. 두 번째 SQL의 부서 내림차순은 GROUP BY 열 순서를 바꿔서가 아니라 ORDER BY dept DESC로 지정한 결과입니다.

결과를 어디까지 해석할 수 있을까요

FROM → WHERE → GROUP BY 같은 논리적 설명 순서를 저장 장치 접근이나 조인 실행 계획의 고정 순서로 외우지 않습니다. 옵티마이저가 실제 처리 방법을 선택할 수 있습니다.

직접 예상해 볼 질문 GROUP BY dept, channel만으로 부서별 오름차순을 약속할 수 있을까요?

직접 예상해 본 뒤 풀이 확인

확인: 약속할 수 없습니다. 필요한 출력 키와 동률 처리까지 ORDER BY에 명시해야 합니다.
