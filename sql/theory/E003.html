그룹 조건은 HAVING으로.

WHERE가 남기는 주문 행과 HAVING이 남기는 고객 그룹을 구분합니다.

Oracle 19c 문서에서 동작을 대조한 고정 입력 문제 · 브라우저 SQLite 실행 · Oracle 직접 실행 비교는 미수행

11번 고객의 두 주문은 8과 7입니다. 각 주문은 15보다 작지만 고객별 합계는 15가 됩니다.

GROUP BY customer_id 뒤 HAVING SUM(amount)>=15는 11번 그룹을 남깁니다. WHERE amount>=15는 주문 행을 먼저 걸러 다른 질문이 됩니다.

그룹을 만들기 전 무엇을 지웠는지 확인하면 WHERE와 HAVING을 함께 쓴 결과도 추적할 수 있습니다.
