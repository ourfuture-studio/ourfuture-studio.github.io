핵심 판단 규칙

PRIOR 뒤 표현식은 탐색상 이전 단계 행에서 읽는다. 위로 탐색할 때도 그 이전 단계 행이라는 뜻이다. LEVEL은 시작 행을 1로 센 깊이이며 고정 직급이 아니다. SQLite 체험은 한 단계 자기 조인이다.

핵심 먼저 PRIOR 바로 뒤의 표현식은 계층 탐색에서 이전 단계인 부모 행의 값을 읽습니다. PRIOR employee_id = manager_id는 부모의 사번과 현재 후보 행의 관리자 번호를 연결해 아래로 내려갑니다.

어떤 자료와 조건을 볼까요

ROOT 아래에 MGR과 SUB가 있고 MGR 아래에 STAFF가 있습니다. ROOT에서 아래로 찾는 것과 STAFF에서 위로 찾는 것을 같은 데이터로 비교합니다.

답을 가르는 기준은 무엇일까요

START WITH는 탐색 시작 행을 고릅니다. LEVEL은 그 시작을 1로 세는 깊이이며 조직 전체의 고정 직급 번호가 아닙니다.

반대로 올라갈 때는 이전 행의 manager_id와 현재 후보의 employee_id를 맞춥니다. PRIOR를 어느 항에 붙이는지와 시작 행을 함께 봐야 합니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · ROOT에서 아래로

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH employees (employee_id, manager_id, employee_name) AS (
    SELECT 1, CAST(NULL AS NUMBER), 'ROOT' FROM dual
    UNION ALL
    SELECT 2, 1, 'MGR' FROM dual
    UNION ALL
    SELECT 3, 2, 'STAFF' FROM dual
    UNION ALL
    SELECT 4, 1, 'SUB' FROM dual
)
SELECT LEVEL AS depth, employee_id, manager_id
FROM employees
START WITH employee_id = 1
CONNECT BY PRIOR employee_id = manager_id
ORDER SIBLINGS BY employee_id;

예상 결과

DEPTH EMPLOYEE_ID MANAGER_ID
1 1 NULL
2 2 1
3 3 2
2 4 1

실행 2 · STAFF에서 위로

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH employees (employee_id, manager_id, employee_name) AS (
    SELECT 1, CAST(NULL AS NUMBER), 'ROOT' FROM dual
    UNION ALL
    SELECT 2, 1, 'MGR' FROM dual
    UNION ALL
    SELECT 3, 2, 'STAFF' FROM dual
    UNION ALL
    SELECT 4, 1, 'SUB' FROM dual
)
SELECT LEVEL AS depth, employee_id, manager_id
FROM employees
START WITH employee_id = 3
CONNECT BY PRIOR manager_id = employee_id
ORDER SIBLINGS BY employee_id;

예상 결과

DEPTH EMPLOYEE_ID MANAGER_ID
1 3 2
2 2 1
3 1 NULL

두 번째 탐색에서는 STAFF가 LEVEL 1, ROOT가 LEVEL 3입니다. LEVEL은 이 질의에서 시작한 위치에 따라 달라집니다. ORDER SIBLINGS BY는 형제끼리 정렬하면서 계층 순서를 유지합니다.

결과를 어디까지 해석할 수 있을까요

계층을 만든 뒤 WHERE로 어떤 행을 제외하는 것과 그 행 아래의 탐색 전체를 끊는 것은 다릅니다. 순환이 있는 데이터라면 NOCYCLE 등 별도 조건도 검토해야 합니다.

직접 예상해 볼 질문 ROOT에서 내려가는 조건에서 PRIOR를 manager_id 쪽으로 옮기기만 하면 같은 하위 조직을 볼 수 있을까요?

직접 예상해 본 뒤 풀이 확인

확인: 아닙니다. 연결 방향이 달라집니다. START WITH와 부모 행에서 가져올 열을 한 쌍으로 읽어야 합니다.
