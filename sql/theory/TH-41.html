CHECK가 있으면 NULL도 막을 수 있을까

CHECK(quantity > 0)는 NULL을 FALSE로 판정할까요?

고정 입력의 공통 SQL 예제 · SQLite 실행 / Oracle 19c 공식 문서 대조 · Oracle 19c 19.26 고정 입력 실제 결과 대조 완료. 실패 INSERT를 실행하지 않고 CASE로 제약의 판정 규칙을 조회합니다. PASS_CHECK는 이 조건만 통과한다는 뜻이며 모든 제약 통과를 뜻하지 않습니다.
