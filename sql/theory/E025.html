SUM 안과 밖의 덧셈.

SUM 괄호 안부터 한 행씩 계산합니다. 수수료가 NULL인 행의 금액도 따로 살펴보세요.

Oracle 19c 문서에서 동작을 대조한 고정 입력 문제 · 브라우저 SQLite 실행 · Oracle 19c 19.26 고정 입력 실제 결과 대조 완료

A는 행별로 amount+fee를 계산한 10, NULL, 10을 합쳐 20입니다. 12+NULL을 자동으로 12로 계산하지 않습니다.

B는 amount 합계 27과 fee 합계 5를 더해 32입니다. 수수료가 NULL이라는 이유로 같은 행의 amount=12까지 버리지 않습니다.

COALESCE를 적용할 위치도 계산 순서의 일부입니다. NULL 수수료를 0으로 간주하는 업무 조건을 따로 정한 뒤 비교해야 합니다.
