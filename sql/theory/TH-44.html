조건부 DELETE는 대상 행만 지우고 되돌릴 수 있을까요?

고정 입력의 공통 SQL 예제 · SQLite 실행 / Oracle 19c 공식 문서 대조 · Oracle 19c 19.26 고정 입력 실제 결과 대조 완료. DELETE와 저장점만 실제 실행합니다. Oracle TRUNCATE·DROP의 암묵적 커밋이나 구조 삭제는 SQLite 결과로 대신 검증하지 않습니다.
