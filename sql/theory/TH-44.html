DELETE와 TRUNCATE와 DROP은 무엇을 지울까

행을 지우는 것과 표의 정의를 없애는 것, ROLLBACK으로 되돌릴 수 있는 범위를 함께 봅니다.

개념과 판단을 한눈에

데이터 조작어(Data Manipulation Language, DML), 데이터 정의어(Data Definition Language, DDL), 삭제(DELETE), 전체 행 제거(TRUNCATE), 객체 삭제(DROP)

핵심 판단 규칙

Oracle 일반 영구 테이블 기준이다. DELETE도 COMMIT되면 이후 ROLLBACK으로 복구되지 않는다. DDL은 암묵적 COMMIT 경계를 만들므로 실습 조건과 자동 커밋 여부를 확인한다.

아래 이론과 문제·실험은 같은 원리를 다른 입력으로 확인할 수 있습니다. 숫자를 대조할 때는 각 화면에 표시된 표·조건·SQL을 먼저 확인하세요.

핵심 먼저 DELETE는 조건에 맞는 행을 지우는 DML이며 커밋 전에는 롤백할 수 있습니다. TRUNCATE는 표의 모든 행을 제거하는 DDL로 ROLLBACK 복구가 되지 않습니다. DROP은 표를 삭제하는 DDL입니다.

어떤 자료와 조건을 볼까요

숫자 두 행만 든 개인 실습 표에서 시작합니다. 데이터를 지운 뒤 ROLLBACK을 해 보고, 같은 표의 TRUNCATE 뒤에도 같은 결과가 나오는지 확인합니다.

답을 가르는 기준은 무엇일까요

DELETE 후 표 정의는 남고, 이 실습에서 커밋 전 ROLLBACK을 하면 삭제한 두 행이 돌아옵니다. 자동 커밋이 켜져 있으면 이 비교가 성립하지 않습니다.

Oracle은 문법적으로 유효한 DDL 실행 전에, 성공한 DDL 실행 뒤에 암묵적 COMMIT을 합니다. DDL과 다른 미확정 작업을 섞으면 예상하지 못한 확정이 생길 수 있으므로 이 실습 전용 연결에서 순서대로 실행합니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 준비하고 DELETE 뒤 롤백

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

개인 실습 스키마의 같은 세션에서 자동 커밋을 끄고 순서대로 실행합니다. 같은 이름이 있으면 실습 표 이름을 바꾸세요. 여러 SELECT의 결과 탭을 각각 확인합니다.

CREATE TABLE OFS_T44_DEMO (id NUMBER PRIMARY KEY);
INSERT INTO OFS_T44_DEMO (id)
WITH seed (id) AS (
 SELECT 1 FROM dual UNION ALL SELECT 2 FROM dual
) SELECT id FROM seed;
COMMIT;
DELETE FROM OFS_T44_DEMO;
SELECT COUNT(*) AS after_delete FROM OFS_T44_DEMO;
ROLLBACK;
SELECT COUNT(*) AS after_rollback FROM OFS_T44_DEMO;

예상 결과 · DELETE 직후

AFTER_DELETE
0

예상 결과 · ROLLBACK 직후

AFTER_ROLLBACK
2

실행 3 · DROP 뒤 데이터 사전에서 확인

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

실행 순서: 실행 1·2 완료

직접 만든 이 실습 표만 삭제합니다. 이 단계가 실습 정리도 겸합니다.

DROP TABLE OFS_T44_DEMO;
SELECT COUNT(*) AS named_tables
FROM user_tables WHERE table_name = 'OFS_T44_DEMO';

예상 결과

NAMED_TABLES
0

DELETE의 복구 가능성에는 “커밋 전”이라는 조건이 있습니다. TRUNCATE 뒤의 ROLLBACK은 두 행을 돌려주지 않습니다. DROP 뒤에는 원래 이름의 표가 데이터 사전 조회에 남지 않습니다.

결과를 어디까지 해석할 수 있을까요

DROP을 ROLLBACK으로 되돌릴 수 없다는 말과 모든 복구 수단이 언제나 불가능하다는 말은 다릅니다. 휴지통·Flashback·백업 등은 설정과 조건이 다른 별도 기능이며 이 실습에서는 수행하지 않습니다.

직접 예상해 볼 질문 DELETE 직후 COMMIT을 한 다음 ROLLBACK을 하면 두 행이 돌아올까요?

직접 예상해 본 뒤 풀이 확인
