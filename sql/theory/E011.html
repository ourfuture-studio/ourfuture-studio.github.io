DISTINCT는 어느 열의 중복을 없앨까.

중복의 기준은 SELECT한 열 전체입니다. 고유 주문번호를 포함하는지도 살펴보세요.

Oracle 19c 문서에서 동작을 대조한 고정 입력 문제 · 브라우저 SQLite 실행 · Oracle 직접 실행 비교는 미수행

원본에는 (11,커피)가 두 번 있습니다. customer_id와 menu만 고르면 두 결과가 같아 하나로 합쳐집니다.

나머지 (11,차), (22,커피)를 포함해 세 행입니다. 원본의 주문번호가 다르더라도 SELECT하지 않았다면 이번 중복 기준에는 없습니다.

고객만 선택하면 두 행, 주문번호까지 선택하면 네 행입니다. DISTINCT를 특정 한 열의 중복 제거로만 읽지 않습니다.

Oracle 19c SELECT·조인·DISTINCT·HAVING

원 문제는 결과의 값과 행 수를 묻고 문자 정렬 순서는 묻지 않습니다. 표시 순서를 Oracle 결과와 비교하는 문제로 사용하지 않습니다.
