IN과 EXISTS와 NOT EXISTS는 무엇을 물을까

같은 주문을 한 번 더 넣으면 IN과 EXISTS의 고객 수가 늘어날까요?

고정 입력의 공통 SQL 예제 · SQLite 실행 / Oracle 19c 공식 문서 대조 · Oracle 19c 19.26 고정 입력 실제 결과 대조 완료. 외부 고객 ID는 NULL이 아닙니다. 임의의 NULL 포함 조건에서 IN과 EXISTS가 항상 동치라고 일반화하지 않습니다.

IN은 값이 목록에 포함되는지, EXISTS는 일치하는 행이 있는지 묻습니다.

이 고정 입력에서는 두 조건이 같은 고객 1, 2를 반환하고 NOT EXISTS는 3을 반환합니다.
