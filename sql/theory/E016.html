ON과 WHERE의 조건 위치.

22번은 주문이 있지만 10천원 이상 주문은 없습니다. 주문 없음과 조건에 맞는 주문 없음을 구분하세요.

Oracle 19c 문서에서 동작을 대조한 고정 입력 문제 · 브라우저 SQLite 실행 · Oracle 19c 19.26 고정 입력 실제 결과 대조 완료

A의 ON 조건은 고객 ID가 같고 주문 금액이 10천원 이상인 주문을 붙입니다. 22와 33은 붙일 주문이 없어도 고객 행이 남습니다.

B는 ID가 같은 주문을 붙인 뒤 o.amount>=10으로 결과를 거릅니다. 22의 7은 조건에 맞지 않고, 33의 NULL 비교도 TRUE가 아닙니다.

WHERE에 o.order_id IS NULL을 더하는 수정은 A와 같지 않습니다. 22에게는 NULL이 아닌 실제 주문번호가 붙어 있기 때문입니다.

이 금액 비교 조건에서의 차이입니다. 모든 WHERE 조건이 같은 방식으로 LEFT JOIN을 바꾼다고 일반화하지 않습니다.
