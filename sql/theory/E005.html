UNION은 표 안의 중복도 지울까.

두 표 사이의 중복뿐 아니라 한 입력 안의 중복도 함께 확인합니다.

Oracle 19c 문서에서 동작을 대조한 고정 입력 문제 · 브라우저 SQLite 실행 · Oracle 직접 실행 비교는 미수행

A의 고객 ID는 11,11,22이고 B는 22,33입니다. UNION ALL은 다섯 행을 이어 붙입니다.

UNION은 합친 선택 결과 전체에서 중복을 제거하여 11,22,33을 남깁니다. 두 입력 사이에만 중복 제거를 적용하지 않습니다.

한쪽 표가 비어도 다른 표 안의 중복 여부를 살펴야 합니다. 선택한 열이 여러 개면 열 전체의 값을 기준으로 판단합니다.
