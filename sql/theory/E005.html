두 결과를 붙이면 같은 값은 몇 번 남을까

왼쪽 결과 안의 중복과 두 결과 사이의 중복을 함께 놓고 UNION을 읽어 봅니다.

이 주제 직접 체험하기

GitHub SQL 실험실은 SQLite로 실행됩니다. Oracle 전용 코드는 Oracle 체험에서 실행합니다.

핵심 먼저 UNION ALL은 두 결과의 행을 모두 이어 붙입니다. UNION은 합친 결과에서 같은 행을 한 번만 남깁니다. 중복 판단 대상은 선택한 열 전체이며 출력 순서는 ORDER BY로 별도 지정합니다.

어떤 자료와 조건을 볼까요

A에는 10이 두 번, B에는 10과 20이 한 번씩 있습니다. A와 B를 합칠 때 입력 행은 모두 네 개입니다.

답을 가르는 기준은 무엇일까요

UNION ALL에서는 A의 두 10도, B의 10도 각각 남습니다. 결과는 10 세 행과 20 한 행입니다.

UNION은 출처와 관계없이 같은 결과 행을 합칩니다. 같은 10은 한 행이 되어 10·20 두 행만 남습니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 전부 이어 붙이기

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH a (x) AS (
    SELECT 10 FROM dual
    UNION ALL
    SELECT 10 FROM dual
),
b (x) AS (
    SELECT 10 FROM dual
    UNION ALL
    SELECT 20 FROM dual
)
SELECT x FROM a
UNION ALL
SELECT x FROM b
ORDER BY x;

예상 결과

X
10
10
10
20

실행 2 · 같은 결과 행 제거

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH a (x) AS (
    SELECT 10 FROM dual
    UNION ALL
    SELECT 10 FROM dual
),
b (x) AS (
    SELECT 10 FROM dual
    UNION ALL
    SELECT 20 FROM dual
)
SELECT x FROM a
UNION
SELECT x FROM b
ORDER BY x;

예상 결과

X
10
20

UNION의 제거 대상은 두 표 사이에 겹치는 값만이 아닙니다. A 안에서 두 번 있던 같은 결과 행도 한 번만 남습니다.

결과를 어디까지 해석할 수 있을까요

원본 표를 수정하는 연산은 아닙니다. SELECT 결과에서 중복을 다루는 것입니다. 조회 열에 출처 라벨 A·B를 추가하면 (10,A)와 (10,B)는 다른 행이 됩니다.

직접 예상해 볼 질문 SELECT x, source처럼 출처까지 출력하면 UNION에서 10이 두 행 남을 수 있을까요?

직접 예상해 본 뒤 풀이 확인

확인: 그렇습니다. 출처 값이 다르면 전체 열 조합이 다릅니다. 원하는 중복 기준에 맞춰 조회 열을 정해야 합니다.
