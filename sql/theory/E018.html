SELECT NULL인데 EXISTS는 왜 참일까

EXISTS가 묻는 것은 그 칸의 값일까요, 아니면 그 칸을 담은 행이 있느냐일까요?

이 주제 직접 체험하기

GitHub SQL 실험실은 SQLite로 실행됩니다. Oracle 전용 코드는 Oracle 체험에서 실행합니다.

핵심 먼저 EXISTS는 서브쿼리 결과에 행이 하나라도 있는지 판단합니다. SELECT 목록이 NULL이어도 WHERE를 통과한 행이 있으면 TRUE입니다. 반환 열의 NULL과 결과의 0행을 구분해야 합니다.

어떤 자료와 조건을 볼까요

고객별로 주문이 있는지만 알고 싶습니다. 주문 금액이나 주문 번호를 보여 줄 필요는 없습니다. 서브쿼리의 SELECT 목록을 NULL로 적고도 고객을 찾을 수 있는지 살펴봅니다.

답을 가르는 기준은 무엇일까요

바깥의 고객 한 명에 대해 안쪽 orders에서 같은 customer_id의 행을 찾습니다. SELECT NULL은 그 행의 출력 값을 NULL로 만들 뿐, 찾아낸 행을 없애지 않습니다.

EXISTS의 상관 조건을 빠뜨리면 현재 고객과의 연결 여부가 사라집니다. 주문 표 어디에든 한 행이 있으면 모든 고객에 대해 참이 될 수 있습니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 고객과 연결되는 주문의 존재

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH customers (customer_id, customer_name) AS (
    SELECT 1, 'MIN' FROM dual
    UNION ALL
    SELECT 2, 'JUN' FROM dual
    UNION ALL
    SELECT 3, 'SOL' FROM dual
),
orders (order_id, customer_id, amount) AS (
    SELECT 101, 1, 10 FROM dual
    UNION ALL
    SELECT 102, 1, 20 FROM dual
    UNION ALL
    SELECT 103, 2, 5 FROM dual
)
SELECT c.customer_id
FROM customers c
WHERE EXISTS (
  SELECT NULL FROM orders o
  WHERE o.customer_id = c.customer_id
)
ORDER BY c.customer_id;

예상 결과

CUSTOMER_ID
1
2

실행 2 · 연결 조건을 빼면

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH customers (customer_id, customer_name) AS (
    SELECT 1, 'MIN' FROM dual
    UNION ALL
    SELECT 2, 'JUN' FROM dual
    UNION ALL
    SELECT 3, 'SOL' FROM dual
),
orders (order_id, customer_id, amount) AS (
    SELECT 101, 1, 10 FROM dual
    UNION ALL
    SELECT 102, 1, 20 FROM dual
    UNION ALL
    SELECT 103, 2, 5 FROM dual
)
SELECT c.customer_id
FROM customers c
WHERE EXISTS (SELECT NULL FROM orders)
ORDER BY c.customer_id;

예상 결과

CUSTOMER_ID
1
2
3

첫 SQL에서 SOL이 제외되는 이유는 출력 값이 NULL이어서가 아닙니다. SOL과 연결되는 주문 행이 없기 때문입니다. 두 번째 SQL은 전체 주문 표가 비어 있는지만 확인합니다.

결과를 어디까지 해석할 수 있을까요

SELECT 1과 SELECT NULL 중 어느 쪽이 언제나 더 빠르다고 단정하지 않습니다. 이 글에서 비교하는 것은 존재 조건의 의미이며 성능 측정 결과가 아닙니다.

직접 예상해 볼 질문 서브쿼리에 WHERE 1 = 0을 추가하면 SELECT 1로 바꿔도 EXISTS가 참일까요?

직접 예상해 본 뒤 풀이 확인

확인: 거짓입니다. 출력하려는 상수와 관계없이 조건을 통과한 행이 0개이기 때문입니다.
