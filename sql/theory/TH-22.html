ROLLUP과 CUBE는 몇 종류의 소계를 만들까

지역·상품 두 기준에서 상품별 소계가 추가되면 몇 행 늘어날까요?

고정 입력의 공통 SQL 예제 · SQLite 실행 / Oracle 19c 공식 문서 대조 · Oracle 직접 실행 비교는 미수행. ROLLUP·CUBE 함수를 SQLite에서 실행하지 않습니다. GROUP BY와 UNION ALL로 해당 그룹 구성만 명시적으로 만듭니다.

상세·지역 소계·전체 합계는 ROLLUP의 그룹 구성을 나타냅니다. CUBE 구성에는 상품 소계도 더해집니다.

level_no는 이 예제에서 붙인 행 구분 번호입니다. 0=상세, 1=지역 소계, 2=상품 소계, 3=전체 합계입니다.
