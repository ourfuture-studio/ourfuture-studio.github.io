SQLD · 집계와 소계

ROLLUP과 CUBE는 몇 종류의 소계를 만들까

그룹 조합의 수와 실제 결과 행 수를 구분하면 소계 문제를 더 정확히 읽을 수 있습니다.

이 주제 직접 체험하기

GitHub SQL 실험실은 SQLite로 실행됩니다. Oracle 전용 코드는 Oracle 체험에서 실행합니다.

핵심 먼저 ROLLUP(a,b)는 (a,b)·(a)·()를, CUBE(a,b)는 여기에 (b)까지 포함한 네 조합을 만듭니다. GROUPING SETS는 적어 둔 조합만 만듭니다. 조합 세 종류가 결과 세 행을 뜻하지는 않습니다.

어떤 자료와 조건을 볼까요

부서 10에는 직무 1·2의 매출이 있고 부서 20에는 직무 1만 있습니다. 상세 세 행에서 부서별 소계, 직무별 소계, 전체 합계를 구해 봅니다.

답을 가르는 기준은 무엇일까요

ROLLUP(dept, job)의 상세는 세 그룹, 부서 소계는 두 그룹, 전체 합계는 한 그룹입니다. 이 입력에서는 6행입니다.

CUBE는 부서와 관계없는 직무별 소계 두 행도 만듭니다. GROUPING 값은 그 열이 소계 표현에서 빠진 자리인지 알려 줍니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 순서가 있는 소계 ROLLUP

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH sales (dept, job, amount) AS (
    SELECT 10, 1, 10 FROM dual
    UNION ALL
    SELECT 10, 2, 20 FROM dual
    UNION ALL
    SELECT 20, 1, 5 FROM dual
)
SELECT dept, job, SUM(amount) AS total,
       GROUPING(dept) AS gd, GROUPING(job) AS gj
FROM sales GROUP BY ROLLUP(dept, job)
ORDER BY GROUPING(dept), dept, GROUPING(job), job;

예상 결과

DEPT JOB TOTAL GD GJ
10 1 10 0 0
10 2 20 0 0
10 NULL 30 0 1
20 1 5 0 0
20 NULL 5 0 1
NULL NULL 35 1 1

실행 3 · 필요한 조합만 지정

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH sales (dept, job, amount) AS (
    SELECT 10, 1, 10 FROM dual
    UNION ALL
    SELECT 10, 2, 20 FROM dual
    UNION ALL
    SELECT 20, 1, 5 FROM dual
)
SELECT dept, SUM(amount) AS total, GROUPING(dept) AS gd
FROM sales GROUP BY GROUPING SETS ((dept), ())
ORDER BY GROUPING(dept), dept;

예상 결과

DEPT TOTAL GD
10 30 0
20 5 0
NULL 35 1

세 SQL은 같은 매출 35원을 다른 수준으로 보여 줍니다. 소계 행까지 모두 다시 더하면 중복 계산이므로 어떤 수준의 값을 사용하는지 먼저 정합니다.

결과를 어디까지 해석할 수 있을까요

ROLLUP(job, dept)는 직무 소계를 만들므로 ROLLUP(dept, job)와 다릅니다. 일반 GROUP BY에서 열 순서를 바꾸는 문제와 섞지 않습니다.

직접 예상해 볼 질문 GROUPING SETS ((dept), (job))에는 전체 합계가 포함될까요?

직접 예상해 본 뒤 풀이 확인

확인: 아닙니다. 전체 합계를 원하면 빈 그룹 ()를 따로 적습니다. 같은 조합을 중복 나열하면 같은 결과 행이 반복될 수도 있습니다.
