고객은 세 명인데 LEFT JOIN은 왜 네 행일까

조인은 고객 명단에 열 하나만 붙이는 작업이 아닙니다. 조건이 맞는 행의 쌍을 먼저 셉니다.

이 주제 직접 체험하기

GitHub SQL 실험실은 SQLite로 실행됩니다. Oracle 전용 코드는 Oracle 체험에서 실행합니다.

핵심 먼저 왼쪽 한 행과 오른쪽 두 행이 일치하면 결과에는 두 쌍이 생깁니다. LEFT JOIN은 일치하는 오른쪽 행이 없는 왼쪽 행도 한 번 남기고 오른쪽 열을 NULL로 채웁니다.

어떤 자료와 조건을 볼까요

MIN에게 주문 두 건, JUN에게 한 건이 있고 SOL에게는 주문이 없습니다. “모든 고객과 주문을 함께 보여 달라”는 요청에서는 MIN의 주문 둘과 SOL의 미일치 행을 모두 표현해야 합니다.

고객 주문 수
MIN 2
JUN 1
SOL 0

답을 가르는 기준은 무엇일까요

조인 조건 c.customer_id = o.customer_id가 TRUE인 쌍을 찾습니다. MIN은 101번·102번 주문 각각과 연결되므로 고객 이름이 두 번 나옵니다.

INNER JOIN은 일치하는 쌍만 남깁니다. LEFT JOIN은 그 결과에 왼쪽의 미일치 행도 보존합니다. 이 예제의 결과 수는 2 + 1 + 1 = 4입니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 왼쪽 고객을 보존

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH customers (customer_id, customer_name) AS (
    SELECT 1, 'MIN' FROM dual
    UNION ALL
    SELECT 2, 'JUN' FROM dual
    UNION ALL
    SELECT 3, 'SOL' FROM dual
),
orders (order_id, customer_id, amount) AS (
    SELECT 101, 1, 10 FROM dual
    UNION ALL
    SELECT 102, 1, 20 FROM dual
    UNION ALL
    SELECT 103, 2, 5 FROM dual
)
SELECT c.customer_id, c.customer_name, o.order_id
FROM customers c LEFT JOIN orders o
  ON c.customer_id = o.customer_id
ORDER BY c.customer_id, o.order_id;

예상 결과

CUSTOMER_ID CUSTOMER_NAME ORDER_ID
1 MIN 101
1 MIN 102
2 JUN 103
3 SOL NULL

조건과 구조를 바꾸어 비교해 봅니다

실행 2 · 일치하는 쌍만 조회

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH customers (customer_id, customer_name) AS (
    SELECT 1, 'MIN' FROM dual
    UNION ALL
    SELECT 2, 'JUN' FROM dual
    UNION ALL
    SELECT 3, 'SOL' FROM dual
),
orders (order_id, customer_id, amount) AS (
    SELECT 101, 1, 10 FROM dual
    UNION ALL
    SELECT 102, 1, 20 FROM dual
    UNION ALL
    SELECT 103, 2, 5 FROM dual
)
SELECT c.customer_id, c.customer_name, o.order_id
FROM customers c JOIN orders o
  ON c.customer_id = o.customer_id
ORDER BY c.customer_id, o.order_id;

예상 결과

CUSTOMER_ID CUSTOMER_NAME ORDER_ID
1 MIN 101
1 MIN 102
2 JUN 103

두 결과에서 MIN은 모두 두 행입니다. LEFT JOIN과 INNER JOIN의 차이는 중복 제거가 아니라 이 예제에서 SOL을 보존하는지입니다.

결과를 어디까지 해석할 수 있을까요

고객 이름에 DISTINCT를 붙여 행 수를 줄이면 어떤 주문과 연결됐는지 잃을 수 있습니다. 조회 목적이 고객 목록인지 고객별 주문 목록인지 먼저 정해야 합니다.

직접 예상해 볼 질문 MIN의 주문이 세 건으로 늘어나면 LEFT JOIN 결과는 몇 행일까요?

직접 예상해 본 뒤 풀이 확인

확인: 다른 조건이 같다면 5행입니다. MIN 3행, JUN 1행, SOL의 미일치 1행입니다.
