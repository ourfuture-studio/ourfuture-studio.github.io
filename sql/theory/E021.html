순위 함수(Ranking Function), 순위(RANK), 밀집 순위(DENSE_RANK), 동률(Peer)

핵심 판단 규칙

RANK=앞선 행 수+1, DENSE_RANK=앞선 서로 다른 정렬 키 수+1. 동률은 OVER 안의 전체 ORDER BY 키로 정하며 최종 출력 정렬과 구분한다.

아래 이론과 문제·실험은 같은 원리를 다른 입력으로 확인할 수 있습니다. 숫자를 대조할 때는 각 화면에 표시된 표·조건·SQL을 먼저 확인하세요.

GitHub SQL 실험실은 SQLite로 실행됩니다. Oracle 전용 코드는 Oracle 체험에서 실행합니다.

핵심 먼저 RANK는 동점 행 수를 반영해 다음 순위를 건너뛰고, DENSE_RANK는 서로 다른 점수 그룹마다 순위를 하나씩 늘립니다. 순위 계산의 ORDER BY에 무엇을 넣었는지도 확인해야 합니다.

어떤 자료와 조건을 볼까요

점수는 100·90·90·80입니다. 90점 두 사람을 같은 순위로 놓은 뒤 80점의 순위를 정해 봅니다.

답을 가르는 기준은 무엇일까요

RANK 결과는 1·2·2·4, DENSE_RANK 결과는 1·2·2·3입니다. DENSE_RANK의 3은 세 번째로 높은 서로 다른 점수라는 뜻입니다.

같은 점수의 학생을 결과 화면에서 일정하게 나열하려면 최종 ORDER BY에 student_id를 더합니다. 순위 함수 안에 학생 번호까지 더하면 동점 기준 자체가 바뀔 수 있습니다.

Oracle에서 첫 조건을 확인해 봅니다

실행 1 · 같은 점수 기준의 두 순위

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH scores (student_id, score) AS (
    SELECT 1, 100 FROM dual
    UNION ALL
    SELECT 2, 90 FROM dual
    UNION ALL
    SELECT 3, 90 FROM dual
    UNION ALL
    SELECT 4, 80 FROM dual
)
SELECT student_id, score,
 RANK() OVER (ORDER BY score DESC) AS rnk,
 DENSE_RANK() OVER (ORDER BY score DESC) AS dense_rnk
FROM scores ORDER BY student_id;

예상 결과

STUDENT_ID SCORE RNK DENSE_RNK
1 100 1 1
2 90 2 2
3 90 2 2
4 80 4 3

조건과 구조를 바꾸어 비교해 봅니다

실행 2 · 3 이하인 순위를 고르면

복사한 쿼리를 Oracle 체험(FreeSQL)에 붙여 넣어 실행하세요.

WITH scores (student_id, score) AS (
    SELECT 1, 100 FROM dual
    UNION ALL
    SELECT 2, 90 FROM dual
    UNION ALL
    SELECT 3, 90 FROM dual
    UNION ALL
    SELECT 4, 80 FROM dual
),
ranked AS (SELECT student_id, RANK() OVER (ORDER BY score DESC) AS r, DENSE_RANK() OVER (ORDER BY score DESC) AS d FROM scores)
SELECT 'DENSE' AS method, student_id FROM ranked WHERE d <= 3
UNION ALL
SELECT 'RANK' AS method, student_id FROM ranked WHERE r <= 3
ORDER BY method, student_id;

예상 결과

METHOD STUDENT_ID
DENSE 1
DENSE 2
DENSE 3
DENSE 4
RANK 1
RANK 2
RANK 3

두 번째 예제에서 RANK 방식은 3명, DENSE 방식은 4명을 고릅니다. “상위 3명”과 “상위 3개 점수 그룹”이 같은 요구인지는 별도로 정해야 합니다.

결과를 어디까지 해석할 수 있을까요

분석 함수 안의 정렬이 최종 결과 출력 순서를 항상 보장하는 것은 아닙니다. 원하는 표시 순서는 바깥 ORDER BY로 적습니다.

직접 예상해 볼 질문 90점이 세 명이라면 80점의 RANK와 DENSE_RANK는 각각 얼마일까요?

직접 예상해 본 뒤 풀이 확인
