RANK와 DENSE_RANK의 동률.

같은 점수의 묶음과 다음 순위 번호를 구분합니다. 윈도우 정렬 키 전체를 확인하세요.

Oracle 19c 문서에서 동작을 대조한 고정 입력 문제 · 브라우저 SQLite 실행 · Oracle 19c 19.26 고정 입력 실제 결과 대조 완료

90점 두 명이 공동 1위입니다. RANK는 그 다음 고객 33에게 3위를, DENSE_RANK는 2위를 부여합니다.

윈도우의 ORDER BY에 고유 customer_id까지 추가하면 90점 두 행도 정렬 키 전체가 달라집니다. 이때는 동률이 아닙니다.

결과 표시용 바깥 ORDER BY와 순위를 정하는 OVER 안 ORDER BY를 구분해야 합니다.
