빈 문자열과 공백 한 칸은 같은 값일까

NULL과 공백 한 칸의 길이는 둘 다 0일까요?

고정 입력의 공통 SQL 예제 · SQLite 실행 / Oracle 19c 공식 문서 대조 · Oracle 직접 실행 비교는 미수행. 빈 문자열은 Oracle에서 NULL로 취급되지만 SQLite에서는 다릅니다. 이 체험은 동일 결과를 위해 명시적 NULL과 공백만 비교하며 TRIM으로 빈 문자열을 만드는 실험도 포함하지 않습니다.

NULL은 값이 없다는 표시이고 공백은 실제 문자입니다. LENGTH(NULL)은 NULL, 공백 한 칸의 길이는 1입니다.

입력과 결과 모두 빈 문자열을 사용하지 않습니다.
