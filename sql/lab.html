문제 선정 기준과 실행 범위
  • Oracle Database 19c 공식 문서와 동작을 대조한 공통 문법·고정 입력 문제만 등록합니다. Oracle에서 직접 실행한 결과 비교는 아직 수행하지 않았습니다.
  • 작은 정수·NULL·비어 있지 않은 문자열을 사용하고 값·행 수·중복·NULL을 비교합니다. 빈 문자열·암묵적 형 변환·문자 정렬·NULL 정렬 차이를 묻는 문제는 제외합니다.
  • 쿼리를 자유 편집하거나 자료를 바꾸면 그 결과는 SQLite에서의 자유 실험입니다. Oracle 결과 동일성을 확인한 것으로 표시하지 않습니다. 자료를 되돌리거나 등록된 조건을 다시 선택하면 원본 문제로 돌아갑니다.
  • 기본 풀이와 이론 요약은 등록된 입력을 설명합니다. 임의 SQL의 자동 해설이나 공식 시험 정답 판정이 아닙니다.
  • 표는 최대 200행까지 표시합니다. 오래 걸리는 실행은 중단되고 원본 자료를 다시 불러올 수 있습니다.
