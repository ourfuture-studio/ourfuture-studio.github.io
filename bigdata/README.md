# 빅분기 공부방 · ourfuture studio

빅데이터분석기사 필기 네 과목의 자체 교육 자료108개를 학습과 복습으로 연결합니다.

- 홈: 네 과목과 학습 현황, 입문 추천12개 안내.
- 과목별 핵심:108개 개념 검색, 과목·학습 상태 필터와 이론 읽기.
- 이론 읽기: 기존108개 상세 원고의 이론·예제 표·문항·접힌 해설·변형·출처를 사이트 안에서 읽고 해당 문제와 체험으로 이어갑니다.
- 문제풀이: 과목별/섞어서5·10·20문제, 즉시 해설, 개별문제 다시 풀기.
- 체험: 기존108개 조건 변경 실험과 자체 그림102종.
- 오답노트: 최근 풀이가 틀린 문제, 북마크, 풀이 기록과 JSON 내보내기/불러오기.

읽음·북마크·문제 답안 기록은 현재 브라우저의 localStorage에만 저장합니다.
체험의 숫자 입력값은 저장하지 않고, 방문자 답안·학습 기록을 서버로 전송하지 않습니다.
저장이 차단되면 경고를 표시하고 그 페이지 안의 메모리로 동작합니다.
기록 불러오기는 문제별 최근 updatedAt을 기준으로 합치며 풀이 횟수를 더하지 않습니다.

직접 만든 교육용 예제이며 공식 기출문항 서비스·합격 예측·실제 학습 성과 보고가 아닙니다.
입문 추천은 개념 연결을 위한 시작점이며 경험적 오답률 순위가 아닙니다.
그림과 설명의 출처는 각 체험 페이지에서 확인할 수 있습니다.
