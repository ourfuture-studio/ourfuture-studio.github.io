상자그림(Box Plot)과 사분위수(Quartile)

평균(Mean) 기호와 바깥 점을 추가했을 때 그림에서 직접 읽을 수 있는 값을 구분한다.

정식 용어와 정의

상자그림(Box Plot)은 중앙값(Median)과 사분위수(Quartile), 수염(Whisker) 등으로 분포를 요약한다. 평균(Mean) 표시가 별도로 없으면 상자그림(Box Plot)만으로 정확한 산술평균(Arithmetic Mean)을 읽을 수 없다.

  • 상자그림(Box Plot)
  • 사분위수(Quartile)
  • 중앙값(Median)
  • 수염(Whisker)
  • 산술평균(Arithmetic Mean)
  • 사분위범위(IQR, Interquartile Range)

정의 참고: NIST: Box Plot

조건을 바꾸며 확인하기

전체 자료가 없는 요약 도식이다. 평균(Mean)7은 가상으로 추가한 표시이며 다섯 요약값에서 계산한 결과가 아니다.

설명 그림과 비교하기

아래 그림과 표는 고정된 설명 예제입니다. 기본·변형 중 어떤 조건인지 캡션을 읽고, 바꾼 입력의 결과는 계산 칸에서 확인하세요.

같은 문제를 직접 골라 보기

상자그림(Box Plot)에 아래 수염(Whisker)2·Q1=4·중앙값(Median)6·Q3=8·위 수염(Whisker)10만 표시하고 평균(Mean) 기호는 없다.

그림에서 정확한 값을 직접 읽을 수 없는 것은?

조건을 더 바꾸면?

위 수염(Whisker) 10보다 큰 바깥 점 15가 하나 추가로 표시됐다. 10을 자료 전체의 최댓값으로 읽어도 될까?

변형 풀이 확인

안 된다. 적어도 15라는 더 큰 관측(Observation)이 표시됐다.

이 상황의 수염(Whisker)은 전체 극값이 아니라 정해진 관례에 따른 경계 안의 관측(Observation)까지 표시한 것으로 읽어야 한다.

중앙선은 중앙값(Median)이며 평균(Mean)은 별도 표시를 확인한다.
