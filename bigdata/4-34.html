전처리 파이프라인(Preprocessing Pipeline)과 모형 배포(Model Deployment)

입력 값과 전처리(Preprocessing) 경로를 바꾸어 지정 파이프라인(Pipeline)의 결과를 비교한다.

정식 용어와 정의

전처리 파이프라인(Preprocessing Pipeline)은 학습한 변환과 모형(Model)을 순서대로 연결한다. 운영 예측에서도 학습 때 정한 열 순서와 단위, 전처리(Preprocessing) 모수(Parameter)를 적용해 입력과 출력의 의미를 유지한다.

  • 전처리 파이프라인(Preprocessing Pipeline)
  • 파이프라인(Pipeline)
  • 모형 배포(Model Deployment)
  • 모형(Model)

정의 참고: scikit-learn Pipelines · Google MLCC Monitoring pipelines

조건을 바꾸며 확인하기

고정 저장값10·2와 선형식의 산술이다. 요청마다 fit하거나 실제 모형(Model) 성능을 평가(Evaluation)하지 않는다.

설명 그림과 비교하기

아래 그림과 표는 고정된 설명 예제입니다. 기본·변형 중 어떤 조건인지 캡션을 읽고, 바꾼 입력의 결과는 계산 칸에서 확인하세요.

같은 문제를 직접 골라 보기

저장된 전처리(Preprocessing)는 z=(x−10)/2, 모형(Model)은 ŷ=3z+1이다. 운영 입력 x=14에 같은 파이프라인(Pipeline)을 적용한다.

올바른 처리와 출력은?

조건을 더 바꾸면?

학습한 변환과 모형(Model)을 그대로 두고 운영 입력만 x=10으로 바꾸면 출력은?

변형 풀이 확인

z=0이고 ŷ=1이다.

(10−10)/2=0, 3×0+1=1이다. 입력 하나가 달라졌을 뿐 평균(Mean)·표준편차(SD, Standard Deviation)를 새로 학습하지 않는다.

새 입력에는 fit 말고 저장한 transform.
