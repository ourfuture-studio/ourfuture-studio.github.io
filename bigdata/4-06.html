불균형 데이터(Imbalanced Data)의 정확도(Accuracy)와 재현율(Recall)

같은 100건에서 양성 탐지와 오경보를 바꾸어 지표를 비교한다.

정식 용어와 정의

정확도(Accuracy)는 전체 예측 중 올바른 예측의 비율이다. 불균형 데이터(Imbalanced Data)에서는 다수 클래스(Majority Class)만 예측해도 정확도(Accuracy)가 높을 수 있으므로 소수 클래스(Minority Class)의 재현율(Recall)과 오류 비용도 확인한다.

  • 불균형 데이터(Imbalanced Data)
  • 정확도(Accuracy)
  • 균형 정확도(Balanced Accuracy)
  • 다수 클래스(Majority Class)
  • 소수 클래스(Minority Class)

정의 참고: scikit-learn balanced_accuracy_score · scikit-learn precision_score

조건을 바꾸며 확인하기

양성1·음성99인 자체 고정 자료다. 표본(Sample)의 불확실성·비용·모집단(Population) 우열을 자동 평가(Evaluation)하지 않는다.

설명 그림과 비교하기

아래 그림과 표는 고정된 설명 예제입니다. 기본·변형 중 어떤 조건인지 캡션을 읽고, 바꾼 입력의 결과는 계산 칸에서 확인하세요.

같은 문제를 직접 골라 보기

실제 양성 1건·음성 99건인 100건에서 모형(Model) A가 전부 음성으로 예측했다. 양성 탐지가 평가(Evaluation) 목적이다.

A의 정확도(Accuracy)와 양성 재현율(Recall)은 각각?

조건을 더 바꾸면?

양성을 모두 찾는 B가 참양성(TP, True Positive)=1·거짓양성(FP, False Positive)=3·거짓음성(FN, False Negative)=0·참음성(TN, True Negative)=96이면 정밀도(Precision)는 얼마이며 A보다 항상 낫다고 할 수 있는가?

변형 풀이 확인

정밀도(Precision) 25%다. 항상 낫다는 결론은 낼 수 없다.

양성 누락을 줄이는 목적에는 개선이 있지만 오경보 3건의 비용도 생긴다. 오류 비용과 허용 조건을 먼저 정해야 실제 선택을 판단할 수 있다.

많이 맞힌 클래스(Class)와 꼭 찾아야 할 클래스(Class)를 나눈다.
