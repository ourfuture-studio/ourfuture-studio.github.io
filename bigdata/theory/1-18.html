핵심 이론

새 AI를 도입할 때는 업무에 맞는 평가 결과뿐 아니라 데이터 사용 근거, 외부 전송 가능 여부, 응답 시간, 처리 비용과 장애 대응을 확인해야 한다. 같은 정확도라도 결과가 필요한 시간 안에 도착하지 않으면 해당 업무의 요구를 충족하지 못한다.

NIST AI RMF는 설계·개발·평가·사용 전반에서 위험을 관리하는 자발적 프레임워크다. 여기서는 이 관점을 바탕으로 자체 도입 조건표를 만든다. 특정 제품의 최신 성능 순위나 규정 준수 인증을 제시하는 자료는 아니다.

파일럿에서는 성공 기준과 중단 조건을 먼저 정한다. 예를 들어 정해진 지연 시간, 사용 가능한 데이터 범위, 사람의 검토 절차를 기록하고 실제 자료로 확인한다. 기준 미충족을 알고도 데모 점수만 근거로 운영 완료라고 보고하지 않는다.

작은 예제로 확인하기

아래 수치는 자체 의사결정 예시이며 실제 제품 측정값이 아니다.

조건 업무 요구 후보 A의 가정값
응답 시간 2초 이내 8초
외부 데이터 전송 금지 외부 전송 필요

성능 점수가 높다는 추가 정보가 주어져도 두 필수 조건의 미충족이 사라지지 않는다. 다른 배치나 내부 운영 방식이 가능한지 새로 검토해야 한다. 후보의 응답이 8초에서 1초로 줄어도 외부 전송이 남으면 전송 금지 조건은 여전히 미충족이다. 반대로 내부 설치만 했다면 시간 조건은 남는다. 두 조건을 모두 통과해도 여기서 확인한 것은 이 두 항목뿐이다. 실제 정확도와 비용·장애 대응은 별도 평가해야 한다.

정답과 오답의 이유 확인하기

정답 2번 — 필수 운영 조건 미충족

제시된 응답 시간과 데이터 전송의 필수 조건을 모두 충족하지 못한다.

  • 1번은 필수 제약을 성능 점수로 무시한다.
  • 3번은 확인된 미충족 조건을 검토 없이 건너뛴다.
  • 4번은 데이터 운영 조건을 도입 판단에서 누락한다.
