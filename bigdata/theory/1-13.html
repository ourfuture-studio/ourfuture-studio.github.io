데이터 마이닝은 지식을 얻는 전체 과정 안에 놓인 작업이다.

핵심 이론작은 예제직접 고르기

핵심 이론

KDD는 자료에서 유용한 지식을 얻는 전체 과정과 데이터 마이닝 단계를 구분한다. 교육용으로 정리하면 자료 선택, 전처리, 변환, 데이터 마이닝, 해석·평가의 흐름을 확인할 수 있다. 알고리즘으로 패턴을 찾기 전에 어떤 자료를 대상으로 삼고 어떻게 가공할지 정해야 한다.

CRISP-DM의 대표적인 여섯 단계는 업무 이해, 데이터 이해, 데이터 준비, 모델링, 평가, 배포다. 여섯 이름을 KDD의 단계와 무조건 일대일로 대응시키지 않는다. CRISP-DM은 업무 목표와 배포를 포함해 프로젝트를 관리하는 관점이 드러난다.

절차도는 한 번만 지나가는 고정 순서가 아니다. 모델링 중 입력 형식의 문제가 드러나면 준비 단계로 돌아갈 수 있고, 평가에서 업무 목표와 어긋남을 발견하면 문제 정의를 재검토한다. 성능 점수를 계산했다는 이유만으로 업무 적용 준비까지 끝났다고 보지 않는다.

작은 예제로 확인하기

반품 예측의 자체 작업을 단계에 배치한다.

작업 CRISP-DM에서의 주된 위치
어떤 반품 비용을 줄일지 합의 업무 이해
코드와 입력 열을 정리 데이터 준비
예측 규칙 학습 모델링
업무 목표에 부합하는지 검토 평가

모형을 학습했더라도 적합한 업무 조치와 평가 기준을 확인하는 과정이 남는다. 모형의 예측 점수가 좋아도 점주가 결과를 받는 시간이 발주 마감 뒤라면 업무 목표를 충족하지 못할 수 있다. 평가 단계에서는 점수 외에 이런 적용 조건도 되짚는다. 입력 코드 오류가 드러났다면 데이터 준비로 돌아가고, 수정 뒤 같은 기준으로 다시 검토한다. 단계의 이름보다 지금 해결하려는 작업을 고른다.

  • 4. 자료 선택만 수행
정답과 오답의 이유 확인하기

정답 3번 — 평가

학습 후 결과가 업무 목표에 부합하는지를 검토하는 것은 평가 단계다.

  • 1번은 입력 자료를 분석 가능한 형태로 준비하는 단계다.
  • 2번은 예측 규칙을 학습하는 작업에 해당한다.
  • 4번은 전체 검토를 자료 범위 선정으로 축소한다.

조건 하나 바꾸어 풀기

학습 중 입력 코드 오류가 발견돼 다시 자료를 정리한다면 절차 위반인가?

풀이: 아니다. 필요한 이전 단계로 돌아가는 반복이 허용된다.

CRISP-DM은 단계 간 의존 관계를 제시하며 일방향 진행만 강제하지 않는다.
