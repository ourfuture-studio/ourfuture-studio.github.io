데이터 마이닝(Data Mining)은 지식을 얻는 전체 과정 안에 놓인 작업이다.

그림으로 먼저 이해하기

학습 점수가 좋아졌으면 분석 프로젝트도 바로 끝난 걸까?

CRISP-DM(Cross-Industry Standard Process for Data Mining)은 모델링 뒤에도 업무 목표와 적용 조건을 평가(Evaluation)하는 반복 과정이다.

정식 용어와 정의

지식 발견 프로세스(KDD, Knowledge Discovery in Databases)는 데이터 선택(Selection)·전처리(Preprocessing)·변환(Transformation)·데이터 마이닝(Data Mining)·해석과 평가(Interpretation and Evaluation)를 거쳐 지식을 얻는 과정이다. CRISP-DM(Cross-Industry Standard Process for Data Mining)은 업무 이해(Business Understanding)에서 배포(Deployment)까지 여섯 단계로 구성되는 반복적 분석 방법론이며, 두 방법론의 단계를 일대일로 대응시키거나 한 번만 진행하는 절차로 이해하지 않는다.

핵심 이론

지식 발견 프로세스(KDD, Knowledge Discovery in Databases)는 자료에서 유용한 지식을 얻는 전체 과정과 데이터 마이닝(Data Mining) 단계를 구분한다. 교육용으로 정리하면 자료 선택, 전처리(Preprocessing), 변환(Transformation), 데이터 마이닝(Data Mining), 해석과 평가(Interpretation and Evaluation)의 흐름을 확인할 수 있다. 알고리즘으로 패턴을 찾기 전에 어떤 자료를 대상으로 삼고 어떻게 가공할지 정해야 한다.

CRISP-DM(Cross-Industry Standard Process for Data Mining)의 대표적인 여섯 단계는 업무 이해(Business Understanding), 데이터 이해(Data Understanding), 데이터 준비(Data Preparation), 모델링(Modeling), 평가(Evaluation), 배포다. 여섯 이름을 지식 발견 프로세스(KDD, Knowledge Discovery in Databases)의 단계와 무조건 일대일로 대응시키지 않는다. CRISP-DM(Cross-Industry Standard Process for Data Mining)은 업무 목표와 배포(Deployment)를 포함해 프로젝트를 관리하는 관점이 드러난다.

절차도는 한 번만 지나가는 고정 순서가 아니다. 모델링(Modeling) 중 입력 형식의 문제가 드러나면 준비 단계로 돌아갈 수 있고, 평가(Evaluation)에서 업무 목표와 어긋남을 발견하면 문제 정의를 재검토한다. 성능 점수를 계산했다는 이유만으로 업무 적용 준비까지 끝났다고 보지 않는다.

핵심 판단 원리

핵심 판단 규칙

입력 정리 → 데이터 준비 / 규칙 학습 → 모델링 / 업무 적합성 검토 → 평가

같은 반품 과제 안에서도 지금 수행하는 작업에 따라 단계가 다르다.

적용 조건: KDD와 CRISP-DM은 이름과 단계 구성이 다른 과정이며, 반복·되돌아감을 허용한다.

기존 예제의 조건과 표 자세히 보기

반품 예측의 자체 작업을 단계에 배치한다.

작업 CRISP-DM(Cross-Industry Standard Process for Data Mining)에서의 주된 위치
어떤 반품 비용을 줄일지 합의 업무 이해(Business Understanding)
코드와 입력 열을 정리 데이터 준비(Data Preparation)
예측 규칙 학습 모델링(Modeling)
업무 목표에 부합하는지 검토 평가(Evaluation)

모형(Model)을 학습했더라도 적합한 업무 조치와 평가(Evaluation) 기준을 확인하는 과정이 남는다. 모형(Model)의 예측 점수가 좋아도 점주가 결과를 받는 시간이 발주 마감 뒤라면 업무 목표를 충족하지 못할 수 있다. 평가(Evaluation) 단계에서는 점수 외에 이런 적용 조건도 되짚는다. 입력 코드 오류가 드러났다면 데이터 준비(Data Preparation)로 돌아가고, 수정 뒤 같은 기준으로 다시 검토한다. 단계의 이름보다 지금 해결하려는 작업을 고른다.

  • 3. 평가(Evaluation)
  • 4. 자료 선택만 수행
정답과 오답의 이유 확인하기

정답 3번 — 평가(Evaluation)

학습 후 결과가 업무 목표에 부합하는지를 검토하는 것은 평가(Evaluation) 단계다.

  • 1번은 입력 자료를 분석 가능한 형태로 준비하는 단계다.
  • 2번은 예측 규칙을 학습하는 작업에 해당한다.
  • 4번은 전체 검토를 자료 범위 선정으로 축소(Shrinkage)한다.

조건 하나 바꾸어 풀기

학습 중 입력 코드 오류가 발견돼 다시 자료를 정리한다면 절차 위반인가?

풀이: 아니다. 필요한 이전 단계로 돌아가는 반복이 허용된다.

CRISP-DM(Cross-Industry Standard Process for Data Mining)은 단계 간 의존 관계를 제시하며 일방향 진행만 강제하지 않는다.

다시 떠올릴 단서
