인공지능(AI, Artificial Intelligence)·머신러닝(ML, Machine Learning)·딥러닝(DL, Deep Learning)과 전이학습(Transfer Learning)

분야의 포함 관계와 학습 지식을 재사용하는 전략을 구분한다.

관련 문제 풀기조건 바꿔 체험

그림으로 먼저 이해하기

사전학습한 망의 앞부분을 고정해도 전이학습이라고 할 수 있을까?

전이학습(Transfer Learning)은 사전학습(Pretraining)한 표현을 새 과제에 재사용하는 것이며, 고정하거나 미세 조정(Fine-tuning)하는 방식이 있다.

정식 용어와 정의

인공지능(AI, Artificial Intelligence)은 머신러닝(ML, Machine Learning)을 포함하고, 딥러닝(DL, Deep Learning)은 다층 신경망(Neural Network)을 사용하는 머신러닝(ML, Machine Learning)의 한 분야다. 전이학습(Transfer Learning)은 사전학습 모형(Pre-trained Model)의 지식이나 가중치(Weights)를 새 과제에 활용하는 전략으로, 특성 추출(Feature Extraction)이나 미세조정(Fine-tuning) 등으로 구현하며 인공지능(AI, Artificial Intelligence)·머신러닝(ML, Machine Learning)·딥러닝(DL, Deep Learning) 다음의 별도 포함 단계는 아니다.

핵심 이론

통상적인 범주 설명에서 인공지능(AI, Artificial Intelligence)은 지능적 작업을 수행하는 방법을 넓게 다루고, 머신러닝(ML, Machine Learning)은 데이터로부터 규칙이나 모형(Model)을 학습하는 접근을 포함한다. 딥러닝(DL, Deep Learning)은 여러 층의 신경망(Neural Network)을 사용하는 머신러닝(ML, Machine Learning)의 한 분야다. 모든 인공지능(AI, Artificial Intelligence)이 딥러닝인 것은 아니다.

전이학습(Transfer Learning)은 먼저 학습한 지식이나 표현을 다른 과제에 활용하는 전략이다. 딥러닝(DL, Deep Learning) 이미지 모형(Model)의 사전학습 가중치(Weights)를 가져오는 사례가 익숙하지만, 전이학습(Transfer Learning)을 딥러닝(DL, Deep Learning) 다음에 놓인 독립적인 네 번째 포함 단계로 외우면 관계를 잘못 읽게 된다.

PyTorch의 예에서는 사전학습망을 초기값으로 미세 조정하거나 앞부분을 고정한 특징 추출기로 사용한다. 특징 추출기는 사진을 분류에 쓸 숫자 표현으로 바꾸고, 출력층(Output Layer)은 그 표현을 새 상품의 범주 점수로 바꾼다. 고정은 새 자료를 통과시키지 않는다는 뜻이 아니라 해당 가중치(Weights)를 학습 중 갱신하지 않는다는 뜻이다. 일부 층을 고정해도 새 분류기처럼 학습하는 부분이 있을 수 있다. 기존 지식이 새 데이터에 적합한지는 검증해야 하며, 가져왔다는 이유만으로 향상을 보장하지 않는다.

핵심 판단 원리

핵심 판단 규칙

사전학습 재사용 + 고정 → 특징 추출 / 재사용 + 갱신 → 미세 조정

yes·yes는 고정 특징 추출, yes·no는 미세 조정이다.

적용 조건: 새 과제·자료·갱신할 층을 명시한다. AI·ML·DL의 포함 관계와 전이학습의 방식은 다른 구분이다.

정의와 원리 참고: IBM: AI vs machine learning vs deep learning · PyTorch: Transfer Learning for Computer Vision Tutorial

작은 예제로 확인하기

기존 과제는 두 종류의 상품 사진 분류다. 기본값은 사전학습 사용 yes, 앞부분 고정 yes다.

  1. 1재사용 여부 확인

    pretrained=yes이므로 기존 표현을 사용한다.

  2. 2갱신 범위 확인

    frozen=yes이면 앞부분을 고정하고 새 출력층을 학습한다.

기본은 고정 특징 추출을 통한 전이학습이다. 고정을 풀면 미세 조정 방식으로 바뀐다.

고정 특징 추출에서도 새 출력층은 학습한다. 어떤 방식이 항상 우수하다고 단정하지 않는다.

기존 예제의 조건과 표 자세히 보기

자체 과제는 두 종류의 상품 사진을 분류하는 것이다.

방법 기존 지식 사용
모든 가중치(Weights)를 무작위로 시작 사전학습을 사용하지 않음
사전학습 특징 추출기를 고정하고 새 출력층(Output Layer) 학습 전이학습(Transfer Learning) 사례

둘째 방법은 전체 망을 다시 학습하지 않아도 기존 표현을 새 과제에 사용한다. 특징 추출기를 고정하는 경우에도 새 출력층(Output Layer)의 가중치(Weights)는 새 상품 자료로 학습한다. 전체 미세 조정에서는 사전학습 가중치(Weights)를 초기값으로 사용하되 앞부분도 갱신한다. 고정 여부가 다르더라도 “이미 학습한 표현을 재사용했는가”라는 전이학습(Transfer Learning)의 판단 기준은 유지된다.

직접 고르기

가장 직접적인 설명은?

  • 1. 전이학습(Transfer Learning) 활용
  • 2. 데이터 없이 인과 확정
  • 3. 신경망(Neural Network)을 전혀 사용하지 않음
  • 4. 모든 가중치(Weights)를 무작위 초기화(Initialization)
정답과 오답의 이유 확인하기

정답 1번 — 전이학습(Transfer Learning) 활용

먼저 학습한 표현을 새로운 분류 과제에 재사용하는 전이학습(Transfer Learning) 사례다.

  • 2번은 학습과 인과 추론을 혼동한다.
  • 3번은 사전학습 신경망(Neural Network)을 쓴다는 조건과 다르다.
  • 4번은 기존 가중치(Weights)를 유지한다는 조건과 모순된다.
