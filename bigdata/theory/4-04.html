정밀도(Precision)와 재현율(Recall)

정밀도(Precision)와 재현율(Recall)은 모두 맞게 찾은 양성 참양성(TP, True Positive)을 쓰지만 분모가 다르다. 양성=스팸이라는 기준을 고정하고, 예측한 스팸부터 모을지 실제 스팸부터 모을지 확인한다.

관련 문제 풀기조건 바꿔 체험
핵심 이론작은 예제직접 고르기

정식 용어와 정의

정밀도(Precision)는 예측 양성 중 실제 양성의 비율이고 재현율(Recall)은 실제 양성 중 예측 양성의 비율이다. 두 지표는 참양성(TP, True Positive)을 분자로 쓰지만 분모가 다르므로 양성 클래스(Class)와 평가(Evaluation) 목적을 먼저 정한다.

  • 정밀도(Precision)
  • 재현율(Recall)
  • 참양성(TP, True Positive)
  • 거짓양성(FP, False Positive)
  • 거짓음성(FN, False Negative)
  • 참음성(TN, True Negative)
  • 민감도(Sensitivity)

정의 참고: scikit-learn precision_score

핵심 이론

혼동행렬에서 행과 열의 배치를 먼저 읽는다. 이 글은 행이 실제값, 열이 예측값(Predicted Value)이며 양성을 스팸으로 정한다. 참양성(TP, True Positive)은 실제 스팸을 스팸으로 맞힌 수, 거짓양성(FP, False Positive)은 정상 메일을 스팸으로 잘못 표시한 수다. 거짓음성(FN, False Negative)은 놓친 스팸, 참음성(TN, True Negative)은 정상으로 맞힌 정상 메일이다. 양성은 좋다는 평가(Evaluation)가 아니라 찾아내려는 클래스(Class)의 이름이므로 문제에서 양성 기준이 바뀌면 네 칸의 의미도 다시 읽어야 한다.

정밀도(Precision)는 양성으로 예측한 집합에서 실제 양성이 차지하는 비율 참양성(TP, True Positive)/(TP+FP)다. 스팸함에 모인 메일을 열어 얼마나 제대로 골랐는지 보는 질문이다. 재현율(Recall)은 실제 양성 집합에서 찾아낸 비율 참양성(TP, True Positive)/(TP+FN)다. 정답을 보고 실제 스팸을 모두 모은 뒤 얼마나 놓치지 않았는지 확인한다. 같은 참양성(TP, True Positive)을 분자로 써도 ‘모아 놓은 전체’가 달라 두 지표는 같을 필요가 없다.

어느 지표가 높은지만으로 목적을 달성했다고 판단하지 않는다. 스팸 하나만 표시해 맞혔다면 정밀도(Precision)는 높아도 나머지 스팸을 놓칠 수 있다. 모든 메일을 스팸으로 표시하면 재현율(Recall)은 높아도 정상 메일의 피해가 커질 수 있다. 양성 예측이나 실제 양성이 전혀 없는 자료에서는 분모가 0이므로 정의와 소프트웨어의 처리 규칙도 확인해야 한다. 아래는 두 분모가 모두 양수인 자체 예제이며 실제 서비스 성능이 아니다.

작은 예제로 확인하기

기존 머신러닝(ML, Machine Learning)15와 같은 자체 메일 10통 예제다. 양성은 스팸이며 실제 스팸 5통 중3통을 찾고2통을 놓쳤다. 정상5통 중1통을 스팸으로 잘못 보냈다.

실제＼예측 스팸 정상
스팸 참양성(TP, True Positive)=3 거짓음성(FN, False Negative)=2
정상 거짓양성(FP, False Positive)=1 참음성(TN, True Negative)=4

예측 스팸은3+1=4통이므로 정밀도(Precision)3/4=75%다. 실제 스팸은3+2=5통이므로 재현율(Recall)3/5=60%다. 10통 전체를 분모로 삼은3/10은 두 지표 중 어느 것도 아니며, 정확도(Accuracy)는(3+4)/10=70%로 별도 계산한다. 스팸이라고 한 통도 고르지 않아 참양성(TP, True Positive)=거짓양성(FP, False Positive)=0이면 정밀도(Precision)의 분모가 0이다. 그 비율을 임의로 100%라고 두지 않는다. 실제 스팸이 남아 있다면 재현율(Recall)은 0으로 계산할 수 있어 두 지표의 상태도 다를 수 있다. 체험은 수학적으로 정의되지 않은 비율을 “정의 불가”로 표시한다.

그림으로 확인하기

직접 고르기

양성은 스팸이다. 참양성(TP, True Positive)=3, 거짓양성(FP, False Positive)=1, 거짓음성(FN, False Negative)=2, 참음성(TN, True Negative)=4인 자체 메일 10통의 같은 판정 결과다.

정밀도(Precision)와 재현율(Recall)은 각각 얼마인가?

  • 1. 60%와 75%
  • 2. 75%와 60%
  • 3. 70%와 60%
  • 4. 75%와 70%
정답과 오답의 이유 확인하기

정답 2번 — 75%와 60%

정밀도(Precision)는 예측 양성 4통 중 3통인 75%, 재현율(Recall)은 실제 양성 5통 중 3통인 60%다. 분모가 예측 집합인지 실제 집합인지 구별한다.

  • 1번: 실제 양성 분모와 예측 양성 분모를 바꾸어 사용했다.
  • 3번: 정밀도(Precision) 자리에 전체 정답 비율인 정확도(Accuracy) 70%를 넣었다.
  • 4번: 재현율(Recall) 자리에 참음성(TN, True Negative)까지 포함한 정확도(Accuracy) 70%를 넣었다.

조건 하나 바꾸어 풀기

같은 실제 메일 구성에서 놓친 스팸 1통을 추가로 찾았다. 정상 오경보 1통은 그대로다. 새 정밀도(Precision)와 재현율(Recall)은?

풀이: 참양성(TP, True Positive)=4·거짓양성(FP, False Positive)=1·거짓음성(FN, False Negative)=1·참음성(TN, True Negative)=4이므로 둘 다 80%다.

예측 스팸과 실제 스팸의 수가 이번에는 모두 5통이다. 두 지표가 같아졌어도 정의의 분모가 같은 개념으로 바뀐 것은 아니다.

다시 떠올릴 단서

정밀도(Precision)는 예측한 것, 재현율(Recall)은 실제인 것부터.
