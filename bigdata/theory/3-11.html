활성화 함수(Activation Function): 시그모이드(Sigmoid), 쌍곡탄젠트(Tanh), ReLU(Rectified Linear Unit)

출력이 0이 될 수 있는지, 음수가 가능한지, 상한이 있는지 비교한다.

관련 문제 풀기조건 바꿔 체험
개념도핵심 수식·판단예제로 이해문제·체험

그림으로 먼저 이해하기

같은 입력 0인데 활성화 함수에 따라 출력이 0.5와 0으로 나뉘는 이유는 무엇일까요?

활성화 함수(Activation Function)는 입력을 정해진 식과 범위로 변환하며, 출력값을 언제나 클래스 확률로 읽는 것은 아닙니다.

정식 용어와 정의

활성화 함수(Activation Function)는 신경망(Neural Network) 뉴런(Neuron)의 입력을 변환하며, 시그모이드(Sigmoid), 쌍곡탄젠트(tanh, Hyperbolic Tangent), 정류 선형 유닛(ReLU, Rectified Linear Unit)은 값의 범위와 미분 특성이 다르다. 시그모이드 함수(Sigmoid Function)는 유한한 실수 입력에서 (0, 1), 쌍곡탄젠트(tanh, Hyperbolic Tangent)는 (-1, 1), 정류 선형 유닛(ReLU, Rectified Linear Unit)은 [0, ∞)의 값을 가지므로 원점의 함수값과 도함수(Derivative)를 구분해야 한다.

핵심 이론

시그모이드 함수(Sigmoid Function)는 실수 입력 z를 1/(1+exp(−z))로 바꾼다. 유한한 실수 z에 대해 수학적 값은 0보다 크고 1보다 작으며 z=0에서 0.5다. 확률처럼 해석할 수 있는 출력 형식이지만, 모든 시그모이드 함수(Sigmoid Function) 출력이 잘 보정된 사건 확률이라는 뜻은 아니다.

쌍곡탄젠트(tanh, Hyperbolic Tangent)는 음수와 양수를 모두 내며 범위는 (−1,1), 원점의 값은 0이다. 정류 선형 유닛(ReLU, Rectified Linear Unit)은 max(0,z)이므로 음수에서는 0, 양수에서는 z를 유지한다. 정류 선형 유닛(ReLU, Rectified Linear Unit)은 양의 방향 상한이 없어서 출력이 항상 0과 1 사이라는 보기는 틀린다. 범위와 특정 입력에서의 값을 혼동하지 않는다.

기울기를 물으면 입력 위치를 확인한다. 시그모이드 함수(Sigmoid Function)와 쌍곡탄젠트(tanh, Hyperbolic Tangent)는 큰 절댓값 구간에서 기울기가 작아질 수 있다. 정류 선형 유닛(ReLU, Rectified Linear Unit)도 음수 영역에서는 기울기가 0이고 원점에서는 수학적 미분이 유일하지 않다. 이 때문에 정류 선형 유닛(ReLU, Rectified Linear Unit)이 기울기 문제를 전부 해결한다고 단정하지 않는다. 아래 문항은 원점의 함수값만 물으며 도함수(Derivative)는 묻지 않는다.

핵심 수식

세 활성화 함수의 정의

σ(z)=11+e−ztanh(z)=ez−e−zez+e−zReLU(z)=max(0,z)

긴 수식은 좌우로 넘겨 전체 식을 볼 수 있습니다.

z
활성화 전 실수 입력
σ(z)
이 식에서는 시그모이드(Sigmoid) 함수값

z=0이면 차례로 0.5, 0, 0입니다.

적용 조건: 유한한 실수 입력에서의 수학적 함수 정의입니다. ReLU의 미분이나 분류 문턱을 계산하는 식은 아닙니다.

정의와 원리 참고: Stanford CS231n Neural Networks 1

작은 예제로 확인하기

입력 z=0에 시그모이드·쌍곡탄젠트·ReLU를 각각 적용합니다.

  1. 1시그모이드

    e⁰=1이므로 1/(1+1)=0.5입니다.

  2. 2쌍곡탄젠트

    (e⁰−e⁰)/(e⁰+e⁰)=0입니다.

  3. 3ReLU

    max(0,0)=0입니다. z=2를 넣으면 출력 2가 됩니다.

함수의 식과 범위를 읽고 나서 출력의 의미를 해석합니다.

모든 활성화 출력을 확률로 해석하지 않습니다. 이 예는 함수값 계산이며 신경망 학습 실험이 아닙니다.

기존 예제의 조건과 표 자세히 보기

입력 z=0에 세 함수를 적용한다.

함수 식 z=0
시그모이드 함수(Sigmoid Function) 1/(1+e^(−z)) 0.5
쌍곡탄젠트(tanh, Hyperbolic Tangent) (e^z−e^(−z))/(e^z+e^(−z)) 0
정류 선형 유닛(ReLU, Rectified Linear Unit) max(0,z) 0

시그모이드 함수(Sigmoid Function)의 0.5는 클래스(Class) 레이블 0 또는 1로 문턱 처리하기 전 값이다.

세 함수값의 순서는?

  • 1. (0,0,0)
  • 2. (0.5,0,0)
  • 3. (1,0,1)
  • 4. (0.5,0.5,0.5)
정답과 오답의 이유 확인하기

정답 2번 — (0.5,0,0)

sigmoid(0)=1/(1+1)=0.5, tanh(0)=0, ReLU(0)=0이다.

  • 1번: 시그모이드 함수(Sigmoid Function)가 원점에서 0.5라는 점을 놓쳤다.
  • 3번: 함수값을 이진 레이블처럼 취급했다.
  • 4번: 서로 다른 세 함수에 시그모이드 함수(Sigmoid Function)의 값을 모두 적용했다.

조건 하나 바꾸어 풀기

입력을 z=2로 바꿨다. 세 함수 중 출력이 1을 넘는 함수는?

풀이: 정류 선형 유닛(ReLU, Rectified Linear Unit)만 해당한다.

ReLU(2)=2다. 시그모이드 함수(Sigmoid Function)와 쌍곡탄젠트(tanh, Hyperbolic Tangent)는 각각 상한 1 아래에 있다.

다시 떠올릴 단서

시그모이드 함수(Sigmoid Function)는 반, 나머지 둘은 원점에서 영.
