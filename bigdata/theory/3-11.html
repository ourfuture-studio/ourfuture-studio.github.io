출력이 0이 될 수 있는지, 음수가 가능한지, 상한이 있는지 비교한다.

관련 문제 풀기조건 바꿔 체험
핵심 이론작은 예제직접 고르기

핵심 이론

sigmoid는 실수 입력 z를 1/(1+exp(−z))로 바꾼다. 유한한 실수 z에 대해 수학적 값은 0보다 크고 1보다 작으며 z=0에서 0.5다. 확률처럼 해석할 수 있는 출력 형식이지만, 모든 sigmoid 출력이 잘 보정된 사건 확률이라는 뜻은 아니다.

tanh는 음수와 양수를 모두 내며 범위는 (−1,1), 원점의 값은 0이다. ReLU는 max(0,z)이므로 음수에서는 0, 양수에서는 z를 유지한다. ReLU는 양의 방향 상한이 없어서 출력이 항상 0과 1 사이라는 보기는 틀린다. 범위와 특정 입력에서의 값을 혼동하지 않는다.

기울기를 물으면 입력 위치를 확인한다. sigmoid와 tanh는 큰 절댓값 구간에서 기울기가 작아질 수 있다. ReLU도 음수 영역에서는 기울기가 0이고 원점에서는 수학적 미분이 유일하지 않다. 이 때문에 ReLU가 기울기 문제를 전부 해결한다고 단정하지 않는다. 아래 문항은 원점의 함수값만 물으며 미분값은 묻지 않는다.

작은 예제로 확인하기

입력 z=0에 세 함수를 적용한다.

함수 식 z=0
sigmoid 1/(1+e^(−z)) 0.5
tanh (e^z−e^(−z))/(e^z+e^(−z)) 0
ReLU max(0,z) 0

sigmoid의 0.5는 클래스 레이블 0 또는 1로 문턱 처리하기 전 값이다.

직접 고르기

입력 z=0. 순서는 sigmoid, tanh, ReLU다.

세 함수값의 순서는?

  • 1. (0,0,0)
  • 2. (0.5,0,0)
  • 3. (1,0,1)
  • 4. (0.5,0.5,0.5)
정답과 오답의 이유 확인하기

정답 2번 — (0.5,0,0)

sigmoid(0)=1/(1+1)=0.5, tanh(0)=0, ReLU(0)=0이다.

  • 1번: sigmoid가 원점에서 0.5라는 점을 놓쳤다.
  • 3번: 함수값을 이진 레이블처럼 취급했다.
  • 4번: 서로 다른 세 함수에 sigmoid의 값을 모두 적용했다.

조건 하나 바꾸어 풀기

입력을 z=2로 바꿨다. 세 함수 중 출력이 1을 넘는 함수는?

풀이: ReLU만 해당한다.

ReLU(2)=2다. sigmoid와 tanh는 각각 상한 1 아래에 있다.
