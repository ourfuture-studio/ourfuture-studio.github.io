카토그램(Cartogram)의 면적 부호화(Area Encoding)

실제 지리면적과 인구에 비례해 다시 그린 면적은 다른 정보다. 지역이 크게 보이면 땅이 넓다는 뜻인지, 표시한 통계량(Statistic)이 많다는 뜻인지 범례부터 확인한다.

관련 문제 풀기조건 바꿔 체험
핵심 이론작은 예제직접 고르기

정식 용어와 정의

카토그램(Cartogram)은 지리적 영역의 면적을 인구 등 선택한 통계량(Statistic)에 따라 변형한 지도다. 표시 면적은 실제 지리 면적이 아니라 부호화한 통계량(Statistic)의 크기를 나타낸다.

  • 카토그램(Cartogram)
  • 면적 부호화(Area Encoding)

정의 참고: Gastner and Newman Density equalizing maps

핵심 이론

일반적인 지도에서는 위치·경계와 지리적 형상을 읽는다. 카토그램(Cartogram)은 인구나 선거인 수 같은 선택 통계량(Statistic)에 지역의 표시 면적을 비례시키는 표현이다. 실제 땅이 넓은 지역이라도 인구가 적으면 작게 표현될 수 있다. 크기의 의미를 바꾸어 넓은 땅의 시각적 영향보다 사람이나 사건의 규모(Volume)를 보여주려는 목적을 가진다. 크기 변화는 자료값의 변화가 아니라 인코딩 규칙의 변화다.

같은 지역을 늘이거나 줄이면 경계 형상·거리·방향이 왜곡될 수 있다. 인접 관계를 유지하는 방식과 단순 도형으로 대체하는 방식 등 여러 설계가 있으므로 모든 카토그램(Cartogram)이 실제 위치와 형태를 정확히 유지한다고 설명하지 않는다. 읽는 사람이 어느 지역인지 찾을 수 있도록 이름과 비교용 지도를 두고, 면적이 어떤 변수에 비례하는지 명시한다.

총사건 수와 인구당 사건비율도 구분해야 한다. 인구에 비례하는 면적에 사건을 표시하는 설계는 분모 정보를 시각적으로 반영할 수 있지만, 면적 하나만 보고 발생률이나 위험(Risk)도를 자동 추론할 수는 없다. 지역별 합계·분모·색상 변수의 의미를 따로 읽는다. 아래 자체 예제는 비례 면적 계산을 설명하며 실제 지리 경계 변형 알고리즘을 실행하거나 실제 인구 자료를 분석한 결과가 아니다.

작은 예제로 확인하기

가상 지역A의 실제 면적100, B의 실제 면적50이며 인구는 A10만·B30만이다. 인구에 비례하는 카토그램(Cartogram)의 총 표시 면적을200으로 정한다.

지역 실제 지리면적 인구 카토그램(Cartogram) 면적
A 100 10만 50
B 50 30만 150

표시 면적은 A=200×10/40=50, B=200×30/40=150이다. 실제 땅은A가B의2배지만 인구 기준 표시 면적은B가A의3배다. 어느 지도가 틀렸다는 뜻이 아니라 면적에 연결한 변수가 다르다.

그림으로 확인하기

직접 고르기

인구가 A는 10만 명, B는 30만 명인 두 지역을 인구 비례 면적의 카토그램(Cartogram)으로 그린다. 같은 비례상수를 사용한다.

B의 표시 면적은 A의 몇 배인가?

  • 1. 1/3배
  • 2. 2배
  • 3. 3배
  • 4. 실제 지리 면적을 알아야만 계산 가능
정답과 오답의 이유 확인하기

정답 3번 — 3배

표시 면적을 인구에 비례시켰으므로 30/10=3배다. 실제 지리 면적 비율은 이 인코딩의 크기를 정하는 기준이 아니다.

  • 1번: 인구의 분자와 분모를 반대로 나누었다.
  • 2번: 자체 예제의 실제 지리 면적A/B=2를 카토그램(Cartogram)의B/A 비율로 옮겼다.
  • 4번: 이 문제는 인구 비례라고 명시했으므로 인구 비율만으로 표시 면적 비율을 구할 수 있다.

조건 하나 바꾸어 풀기

인구만 A20만·B20만으로 바꾸고 같은 인구 비례 카토그램(Cartogram)을 그린다. 표시 면적은 같으며 실제 땅 면적도 같아지는가?

풀이: 표시 면적은 같지만 실제 땅 면적이 같아지는 것은 아니다.

선택 통계량(Statistic)이 같아져 같은 표시 면적을 배정할 뿐이다. 실제 지리 면적 100·50이라는 원자료(Raw Data)의 의미를 바꾸지 않는다.
