데이터 유형(Data Types): 정형(Structured)·반정형(Semi-structured)·비정형(Unstructured)

파일 이름보다 값에 어떤 구조와 의미가 붙어 있는지 확인한다.

관련 문제 풀기조건 바꿔 체험
개념도핵심 수식·판단예제로 이해문제·체험

그림으로 먼저 이해하기

같은 통화 내용을 녹음 파일로 볼 때와 고정 열의 표로 볼 때 분류가 같을까?

데이터 유형(Data Types)은 분석 대상의 표현 구조에 붙이며 정형(Structured), 반정형(Semi-structured), 비정형(Unstructured)을 구별한다.

정식 용어와 정의

정형 데이터(Structured Data)는 정해진 스키마(Schema)에 따라 행·열 등의 일관된 구조로 표현되고, 반정형 데이터(Semi-structured Data)는 키·태그 같은 구조 요소를 가지면서 엄격한 고정 테이블 구조에 매이지 않는 자료다. 비정형 데이터(Unstructured Data)는 자연어 문서·음성·영상처럼 분석 대상 내용이 고정된 필드 구조로 표현되지 않는 자료이며, 파일 규격이나 메타데이터(Metadata)까지 없다는 뜻은 아니다.

핵심 이론

정형 데이터(Structured Data)의 대표 예는 각 열의 의미와 자료형이 정해진 관계형 표다. 반정형 데이터(Semi-structured Data)는 JSON(JavaScript Object Notation)의 키와 중첩, XML(Extensible Markup Language)의 태그처럼 구조를 설명하는 단서가 있지만 전통적인 고정 표 형식만으로 구성되지는 않는 경우를 가리킨다.

자유 서술 문서, 원본 음성, 영상은 보통 분석에 필요한 의미가 고정 열에 직접 담겨 있지 않아 비정형의 예로 설명한다. 영상 파일도 코덱이나 촬영 시각 같은 기술적 구조와 메타데이터(Metadata)를 가진다. 비정형이 바이트 구조가 전혀 없다는 뜻은 아니다.

JSON(JavaScript Object Notation)이라고 언제나 같은 수준의 구조를 갖는 것은 아니다. 엄격한 스키마(Schema)를 적용할 수 있고 표로 변환할 수도 있다. 시험 문항에서는 고정 열인지, 자기 설명적인 키·태그인지, 내용 해석이 필요한지에 대한 조건을 읽고 분류한다.

핵심 판단 원리

핵심 판단 규칙

분류 대상 표현을 먼저 고정한 뒤 구조를 확인한다

고정 열 표는 정형, 키·중첩 JSON 예는 반정형, 원본 자유 통화는 비정형이다.

적용 조건: 통상적인 교육 분류의 예이며 JSON으로 저장했다는 사실 하나만으로 모든 구조 속성을 확정하지 않는다.

작은 예제로 확인하기

기존 문의 예제는 고정 열의 표, 키·중첩 구조의 JSON, 원본 통화 녹음을 비교한다.

  1. 1현재 표현 확인

    원본 음성을 보고 있는지 추출한 표를 보고 있는지 먼저 정한다.

  2. 2구조의 규칙 읽기

    고정 열, 키·중첩 구조, 자유 형식 중 무엇인지 살핀다.

기본 json은 이 교육 분류에서 반정형이다. 같은 문의의 표 산출물은 정형으로 볼 수 있다.

파일 확장자만으로 구조·암호화·값의 정확성까지 한꺼번에 판단하지 않는다.

기존 예제의 조건과 표 자세히 보기

같은 고객 문의를 세 방식으로 표현한다.

표현 통상적인 교육 분류
문의ID·접수일·유형 열의 표 정형
키와 선택적 중첩 항목을 가진 JSON(JavaScript Object Notation) 반정형
자유롭게 말한 원본 통화 녹음 비정형

원본 녹음에서 유형과 접수일을 추출한 표는 새 정형 산출물이다. 원본과 가공 결과를 같은 형태로 단정하지 않는다. 같은 통화라도 원본 음성은 비정형 예시이고, 여기서 추출한 문의ID·유형을 고정 열로 저장하면 그 산출물은 정형으로 다룬다. 구조 분류는 분석하는 대상 표현에 붙인다. 파일 확장자만 보고 암호화(Encryption) 여부나 값의 정확성(Accuracy)까지 판단할 수 없는 이유도 같다.

직접 고르기

항목마다 키가 있고 일부 항목은 중첩되며 선택 필드도 있는 JSON(JavaScript Object Notation) 문서를 받았다.

통상적인 교육 분류는?

  • 1. 반정형
  • 2. 항상 무구조
  • 3. 반드시 관계형 표
  • 4. 암호화(Encryption) 자료
정답과 오답의 이유 확인하기

정답 1번 — 반정형

키와 중첩처럼 자기 설명적인 구조를 가진 반정형 데이터(Semi-structured Data)의 대표 사례다.

  • 2번은 구조 단서가 있다는 조건과 다르다.
  • 3번은 JSON(JavaScript Object Notation)을 반드시 관계형 고정 표라고 볼 수 없기 때문에 틀리다.
  • 4번은 자료 구조와 암호화(Encryption) 여부를 혼동한다.

조건 하나 바꾸어 풀기

원본 통화에서 문의ID·유형을 추출해 고정 열 표로 만들었다면 추출 결과는?

풀이: 정형 데이터(Structured Data)로 다룰 수 있다.

원본 음성과 추출된 표는 표현 구조와 분석 단위가 다르다.
