데이터 유형(Data Types): 정형(Structured)·반정형(Semi-structured)·비정형(Unstructured)

파일 이름 대신 표현 구조를 바꾸며 통상 분류를 판단한다.

정식 용어와 정의

정형 데이터(Structured Data)는 정해진 스키마(Schema)에 따라 행·열 등의 일관된 구조로 표현되고, 반정형 데이터(Semi-structured Data)는 키·태그 같은 구조 요소를 가지면서 엄격한 고정 테이블 구조에 매이지 않는 자료다. 비정형 데이터(Unstructured Data)는 자연어 문서·음성·영상처럼 분석 대상 내용이 고정된 필드 구조로 표현되지 않는 자료이며, 파일 규격이나 메타데이터(Metadata)까지 없다는 뜻은 아니다.

  • 정형 데이터(Structured Data)
  • 반정형 데이터(Semi-structured Data)
  • 비정형 데이터(Unstructured Data)
  • 스키마(Schema)
  • 메타데이터(Metadata)
  • JSON(JavaScript Object Notation)
  • XML(Extensible Markup Language)

정의 참고: IBM — Structured vs. unstructured data: What's the difference? · RFC 8259 — The JavaScript Object Notation (JSON) Data Interchange Format · W3C — Extensible Markup Language (XML) 1.0
