연관규칙 분석(Association Rule Analysis)의 지지도(Support), 신뢰도(Confidence), 향상도(Lift)

방향을 바꿔 신뢰도(Confidence)의 분모가 달라져도 향상도(Lift)는 같은지 확인한다.

정식 용어와 정의

연관규칙 분석(Association Rule Analysis)은 거래(Transaction)에서 품목집합(Itemset)의 동시 출현을 이용하여 선행항(Antecedent)과 후행항(Consequent)의 연관을 요약한다. 지지도(Support)는 전체 거래(Transaction)의 동시 출현 비율, 신뢰도(Confidence)는 선행항(Antecedent) 조건부 후행항(Consequent) 비율, 향상도(Lift)는 신뢰도(Confidence)를 후행항(Consequent)의 기본 출현 비율로 나눈 값이며 인과효과(Causal Effect)는 아니다.

  • 연관규칙 분석(Association Rule Analysis)
  • 거래(Transaction)
  • 품목집합(Itemset)
  • 선행항(Antecedent)
  • 후행항(Consequent)
  • 지지도(Support)
  • 신뢰도(Confidence)
  • 향상도(Lift)

정의 참고: mlxtend: association_rules

조건을 바꾸며 확인하기

완전 관측(Observation) 이진 포함 여부, N40·A10·B20 고정이다. 판매량·인과효과(Causal Effect)로 해석하지 않는다. 체험의 큰 결과는 선택한 방향의 신뢰도(Confidence)이고, 문항에서 묻는 향상도(Lift)는 계산 항목에서 따로 확인한다. 기본값의 신뢰도(Confidence)는0.8, 향상도(Lift)는1.6이다.

설명 그림과 비교하기

아래 그림과 표는 고정된 설명 예제입니다. 기본·변형 중 어떤 조건인지 캡션을 읽고, 바꾼 입력의 결과는 계산 칸에서 확인하세요.

같은 문제를 직접 골라 보기

거래(Transaction) 40장, A 10장, B 20장, 동시 8장. 결측은 없다.

A→B 향상도(Lift)는?

조건을 더 바꾸면?

방향을 B→A로 바꾸면 신뢰도(Confidence)와 향상도(Lift)는?

변형 풀이 확인

신뢰도(Confidence) 0.4, 향상도(Lift) 1.6.

신뢰도(Confidence) 8/20=0.4, A의 기본 비율 10/40=0.25이므로 0.4/0.25=1.6이다.

신뢰도(Confidence) 분모는 화살표 앞, 향상도(Lift)는 기본 비율 비교.
