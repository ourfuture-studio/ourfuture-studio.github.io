1과목 · 빅데이터(Big Data) 분석 기획 · 1-26

데이터 수집(Data Collection): 웹 크롤링(Web Crawling)·API(Application Programming Interface)·데이터베이스(Database)

필요한 응용 프로그래밍 인터페이스(API, Application Programming Interface)와 허용 데이터베이스(DB, Database)의 존재를 바꾸어 경로를 선택한다.

정식 용어와 정의

데이터 수집(Data Collection) 경로는 웹 문서의 탐색을 자동화하는 웹 크롤링(Web Crawling), 제공된 인터페이스로 요청하는 응용 프로그래밍 인터페이스(API, Application Programming Interface), 권한이 있는 데이터베이스(DB, Database)의 조회 등으로 구분할 수 있다. 공식 응용 프로그래밍 인터페이스(API, Application Programming Interface)가 목적에 맞게 제공되면 인증(Authentication), 호출 제한(Rate Limit), 페이지 나누기(Pagination)와 이용 조건을 확인하며, 웹 페이지에서 필요한 내용을 추출하는 웹 스크레이핑(Web Scraping)과 탐색 자체를 구분한다.

  • 데이터 수집(Data Collection)
  • 웹 크롤링(Web Crawling)
  • 웹 스크레이핑(Web Scraping)
  • 응용 프로그래밍 인터페이스(API, Application Programming Interface)
  • 데이터베이스(DB, Database)
  • 인증(Authentication)
  • 호출 제한(Rate Limit)
  • 페이지 나누기(Pagination)
