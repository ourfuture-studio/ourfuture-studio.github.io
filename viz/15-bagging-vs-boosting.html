기계와 생각 · 05 나무·앙상블 · VIZ-15

여러 모델은 어떻게 힘을 합칠까.

같은 데이터에 작은 회귀나무 여러 개를 쓰는 두 가지 방법입니다. 배깅은 서로 다른 부트스트랩 표본으로 나무를 따로따로 키워 평균을 내고, 부스팅은 앞 단계가 못 맞힌 잔차를 다음 나무가 차례로 메웁니다. 두 슬라이더를 움직여 선이 어떻게 변하는지 비교해 보세요.

● 가상 데이터40개 점 · 고정 시드 · 참 함수 f(x) = 1.5·sin(0.9x) + 0.25x + 잡음

배깅 · 나란히

부트스트랩 표본마다 깊이 3 회귀나무를 따로 학습 → 예측을 평균

부스팅 · 차례로

잔차에 스텀프(깊이 1)를 맞춰 학습률 0.3만큼 더하기를 반복

지표배깅부스팅

회귀나무는 제곱오차(SSE)를 가장 많이 줄이는 임계값(서로 다른 이웃 x의 중간점)에서 나누고, 잎의 값은 그 잎 표본의 평균입니다. 배깅 나무는 깊이 3, 부스팅은 깊이 1(스텀프)이며 잎당 최소 표본은 1입니다.

배깅: 나무 k는 시드 1000 + k의 mulberry32로 40개를 복원추출한 표본으로 학습합니다. 나무 수를 늘려도 앞 나무들은 바뀌지 않습니다. 특성이 x 하나뿐인 1차원 예제라 랜덤 포레스트의 ‘분할마다 특성 무작위 선택’은 적용되지 않습니다. 그래서 이 그림은 엄밀히 랜덤 포레스트가 아니라 회귀나무의 배깅입니다(진짜 랜덤 포레스트는 특성 무작위 선택으로 나무끼리의 상관을 더 낮춥니다).

부스팅: 제곱오차 그래디언트 부스팅입니다. F₀ = 평균(y), 단계 m마다 잔차 rᵢ = yᵢ − Fₘ₋₁(xᵢ)(제곱오차의 음의 그래디언트)에 스텀프 hₘ을 맞추고 Fₘ = Fₘ₋₁ + 0.3·hₘ으로 갱신합니다. 표본 추출(확률적 부스팅)은 쓰지 않았습니다.

‘참 함수 대비 MSE’는 데이터를 만든 f(x)와 예측의 차이를 x = 0~10의 501개 격자점에서 평균한 값입니다. 실제 문제에서는 f를 모르므로 검증 데이터로 대신 잽니다. 모든 수치는 이 페이지가 브라우저에서 직접 계산한 값입니다.
