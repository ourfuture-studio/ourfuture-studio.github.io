기계와 생각 · 07 신경망·심화 기법 · VIZ-22

역전파는 무엇을 거꾸로 전할까.

L = (x·w + b − y)²를 계산 그래프로 쪼갰습니다. 순전파는 값을 왼쪽에서 오른쪽으로 채우고, 역전파는 ‘L이 각 노드에 얼마나 민감한가(∂L/∂노드)’를 오른쪽에서 왼쪽으로 전합니다. [다음 단계]를 누르고, 슬라이더로 입력값을 바꿔 보세요.

● 계산 예시입력값 4개 · 손으로 정한 값

u = x·w, z = u + b, d = z − y, L = d². 역전파의 각 단계는 연쇄법칙 ∂L/∂(입력) = ∂L/∂(출력) × ∂(출력)/∂(입력)입니다. 국소 기울기는 곱셈이면 ‘상대편 입력’(∂u/∂w = x), 덧셈이면 1, 뺄셈의 빼는 쪽은 −1, 제곱이면 2d입니다.

검증의 수치미분은 중앙차분 (L(w+h) − L(w−h)) / 2h, h = 10⁻⁴입니다. L이 w에 대해 2차식이라 중앙차분은 이론상 정확하고, 차이는 부동소수점 반올림 오차뿐입니다. 실제 신경망에서는 이렇게 역전파 구현을 수치미분과 비교하는 ‘기울기 검사(gradient check)’를 씁니다.

모든 수치는 이 페이지가 브라우저에서 직접 계산한 값입니다(표시는 소수 둘째 자리 반올림).
