단어는 다른 단어를 얼마나 볼까.

어텐션은 각 단어(질의 Q)가 문장의 모든 단어(키 K)와 얼마나 맞는지 내적으로 점수를 매기고, softmax로 합이 1인 가중치로 바꿉니다. 행을 눌러 한 단어가 어디를 보는지 확인하고, √d 나누기를 끄거나 온도를 바꿔 분포가 얼마나 날카로워지는지 보세요.

● 장난감 계산6토큰 · 손으로 만든 임베딩 d=4

스케일
1.00

장난감 계산 · 실제 모델의 학습된 가중치 아님

실제 언어모델에서 학습된 가중치가 아니라, 원리를 보여 주려고 손으로 정한 숫자로 계산한 장난감 계산입니다.

계산: Q = E·W_Q, K = E·W_K, 점수 S = Q·Kᵀ, 가중치 A = softmax(S / (√d·τ)) — softmax는 각 행(질의)마다 키 6개에 대해 적용합니다. d = 4이므로 √d = 2. 표준 트랜스포머는 τ = 1, ÷√d입니다. τ와 ‘÷1’ 토글은 점수의 크기가 분포의 날카로움을 어떻게 바꾸는지 보여 주려고 넣었습니다(÷√d에서 τ = 0.5는 √4 = 2이므로 ÷1·τ = 1과 같은 결과입니다).

√d로 나누는 이유: 차원 d가 커지면 내적의 크기(분산)가 d에 비례해 커지고, softmax가 한 칸에 쏠려 기울기가 매우 작아지기 때문입니다(Vaswani 외, 2017).

단순화: 임베딩 E(4차원: 사물·조사·장소·동작 느낌의 축)와 W_Q, W_K는 설명용으로 직접 정했고, W_K는 단위행렬입니다. 위치 인코딩·여러 헤드·값(V)과의 곱·마스킹은 생략했습니다. 위치 정보가 없으므로 ‘가’와 ‘에’는 어느 명사 뒤에 붙었는지 모르고, 단어 뜻 축만으로 점수가 정해집니다. 실제 모델의 어텐션 패턴은 이와 다르며, 어텐션 가중치를 곧바로 ‘설명’으로 해석하는 데에도 한계가 있습니다.

모든 숫자는 이 페이지가 브라우저에서 직접 계산한 값입니다(표시는 소수 둘째 자리 반올림이라 행 합이 1.00과 0.01 정도 다르게 보일 수 있습니다).
