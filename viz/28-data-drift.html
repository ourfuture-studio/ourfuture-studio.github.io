기계와 생각 · 09 과적합·튜닝·활용 · VIZ-28

작년 모델이 올해 틀리는 이유는.

0월 데이터로 학습한 분류 경계를 고정해 두고, 달이 지나며 들어오는 새 데이터에 겹쳐 봅니다. 시간 슬라이더를 움직이거나 [재생]을 누르고, 정확도가 떨어지면 [재학습]을 눌러 보세요. 위에서 [공변량 이동]과 [개념 이동]을 바꾸면 ‘무엇이’ 변했는지가 달라집니다.

● 가상 데이터월마다 120개 · 고정 시드 · 모델 = 최소제곱 선형 분류기

변화

모니터링 체크: ① 입력 특성의 평균·분포가 학습 때와 달라졌는가 ② 예측 비율이 변했는가 ③ 정답이 들어오는 대로 정확도를 다시 재는가 — ①②만 보면 개념 이동은 놓칩니다.

월입력 평균 (x₁, x₂)0월 모델 정확도재학습 반영 정확도

공변량 이동: 입력 분포 P(x)는 바뀌고, 입력이 주어졌을 때 정답의 분포 P(y|x)는 그대로입니다. 여기서는 점 구름의 중심이 오른쪽 위로 옮겨 가지만, 정답 규칙(x₂ > 0.25·x₁² 이면 1, 잡음 포함)은 24개월 내내 같습니다. 그래도 틀리는 이유는 선형 모델이 0월 데이터 근처에서만 맞는 근사였기 때문입니다 — 규칙이 휘어 있는 곳으로 입력이 옮겨 가면 근사가 깨집니다.

개념 이동: 입력 분포 P(x)는 그대로이고, P(y|x) — 같은 입력에 대한 정답 — 가 바뀝니다. 여기서는 점 구름은 제자리이고 정답을 가르는 직선이 24개월 동안 70° 돌아갑니다. 입력 통계만 보아서는 알아챌 수 없습니다.

데이터: 월마다 고정 시드(mulberry32)로 ‘평가용’ 120개(화면의 점)와 ‘재학습용’ 120개를 따로 만들었습니다. 정확도는 모두 평가용 점으로 잰 값이라, 재학습한 달의 정확도도 학습에 쓰지 않은 데이터로 잰 것입니다. 정답 잡음은 경계로부터의 거리에 더한 표준편차 0.3 정규 잡음입니다.

모델: 정답을 −1/+1로 두고 (1, x₁, x₂)에 최소제곱으로 맞춘 선형 분류기(값 ≥ 0 이면 1)입니다. 로지스틱 회귀 대신 닫힌 식으로 풀리는 단순한 방법을 썼습니다. 모든 정확도는 이 페이지가 브라우저에서 직접 계산했습니다.
