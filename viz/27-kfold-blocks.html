교차검증은 왜 여러 번 나눌까.

검증 점수는 ‘어떤 점이 검증 쪽에 걸렸느냐’에 따라 달라집니다. K-폴드 교차검증은 데이터를 K조각으로 나눠 조각마다 한 번씩 검증을 맡기고 점수를 평균합니다. [다음 폴드]나 [재생]으로 검증 칸이 옮겨 가는 것을 보고, [다른 분할로 홀드아웃]을 여러 번 눌러 한 번 나눈 점수가 얼마나 출렁이는지 비교해 보세요.

● 가상 데이터24개 점 · 고정 시드 · 모델 = 최소제곱 직선 · 점수 = 검증 MSE(낮을수록 좋음)

K
섞기

같은 방식으로 10번 반복점수 범위점수의 표준편차

데이터: x는 0~10 균등분포, y = 1.5 + 0.7x + 잡음(표준편차 1.3)으로 고정 시드(mulberry32)에서 만든 24개 점입니다. 그중 4개를 먼저 시험 세트로 떼어 두고, 나머지 20개로만 교차검증합니다.

폴드 나누기는 scikit-learn KFold와 같은 규칙입니다: (섞은 뒤) 차례대로 자르고, 20이 K로 나누어떨어지지 않으면 앞쪽 폴드가 하나씩 더 가집니다(K = 3이면 7·7·6). ‘섞기 끔’은 x 순서대로 모은 데이터를 그대로 자르므로, 검증 폴드가 x 범위의 한쪽 끝에 몰립니다.

홀드아웃은 20개를 섞어 14개 훈련 · 6개 검증으로 한 번 나눈 것입니다. 표준편차는 모집단 기준(ddof = 0)입니다. 표의 ‘±’는 폴드 점수의 흩어짐이지 평균의 신뢰구간이 아닙니다. 모든 수치는 이 페이지가 브라우저에서 직접 계산했습니다.
