기계와 생각 · 03 거리·K-NN·SVM · VIZ-05

K-NN은 정말 학습하지 않을까.

K-NN의 학습 단계는 데이터를 저장하는 일이 거의 전부입니다. 대신 예측할 때마다 새 점과 저장된 모든 점 사이의 거리를 잽니다. [학습]과 [예측]을 번갈아 눌러 보고, n을 바꿔 예측 1건의 계산량이 어떻게 늘어나는지 보세요.

● 가상 데이터고정 시드 · 2차원(d = 2) · K = 5 · 완전 탐색 기준

단계
저장 개수 n n = 200

구분K-NN (완전 탐색)로지스틱 회귀
학습 단계데이터 n개를 저장(필요하면 색인 구축)반복 최적화로 가중치 w, b를 찾음
예측 1건w·x + b: 곱셈 d번 + 덧셈 d번, 그 뒤 시그모이드 1번
n에 대한 관계n에 비례 (O(n·d))n과 무관 (O(d))
예측에 필요한 것훈련 데이터 전체가중치 d + 1개

지연 학습(lazy learning): 훈련 데이터로 일반화하는 일을 예측 요청이 들어올 때까지 미루는 방식입니다. K-NN은 대표적인 지연 학습기로, 학습 단계에서 하는 일이 데이터 저장(과 선택적인 색인 구축)이고 실제 계산은 예측 때 몰립니다. 로지스틱 회귀처럼 학습 때 모델을 미리 만들어 두는 방식은 즉시 학습(eager learning)이라 부릅니다. 그러니 “K-NN은 학습을 안 한다”기보다 “학습 단계가 가볍고 예측 단계가 무겁다”가 정확합니다. K, 거리 척도, 스케일링을 정하는 일도 학습 과정의 일부입니다.

막대는 완전 탐색(brute force) 기준입니다. KD-트리, 볼 트리 같은 색인 구조를 학습 단계에서 만들어 두면 저차원 데이터에서는 예측 때 거리를 재는 점의 수를 크게 줄일 수 있습니다. 다만 차원이 높아지면 이런 색인의 효과는 떨어지고, 이때는 근사 최근접 이웃 탐색을 쓰기도 합니다.

연산 수 세는 법: 거리 1번 = d번 뺄셈 + d번 제곱 + (d − 1)번 덧셈 = 3d − 1 = 5회(d = 2). 순위만 필요하므로 제곱근은 생략했고, 가장 가까운 K개를 고르는 비교 연산(이것도 n에 비례)은 막대에 넣지 않았습니다. 로지스틱 회귀는 w·x + b의 곱셈 d번 + 덧셈 d번 = 4회로 셌고 시그모이드는 따로 표시했습니다. 애니메이션 속도는 보기 좋게 조절한 것이며 실제 실행 시간이 아닙니다.
