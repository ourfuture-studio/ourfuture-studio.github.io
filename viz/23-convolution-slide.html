기계와 생각 · 07 신경망·심화 기법 · VIZ-23

필터는 이미지에서 무엇을 찾을까.

3×3 필터를 8×8 이미지 위에 한 칸씩 밀며, 겹친 9칸의 원소곱을 모두 더한 값을 특징 맵에 적습니다. 필터 모양과 같은 무늬가 있는 곳에서 값이 커집니다. 필터를 바꾸고 [한 칸씩]을 눌러 보세요. 입력 픽셀은 눌러서 켜고 끌 수 있습니다.

● 가상 데이터8×8 흑백 그림 · 손으로 그린 예시

필터
입력

스트라이드 1, 패딩 없음: 출력 크기 = 8 − 3 + 1 = 6, 그래서 6×6 특징 맵입니다. 각 칸은 out[i][j] = Σₐ Σ_b in[i+a][j+b] · k[a][b] (a, b = 0, 1, 2)입니다.

PyTorch·TensorFlow 같은 딥러닝 라이브러리의 ‘convolution’은 실제로는 필터를 뒤집지 않는 교차상관(cross-correlation)이며, 이 페이지도 그렇게 계산합니다. 수학의 합성곱은 필터를 180° 뒤집어 곱합니다. 필터를 학습으로 정하는 신경망에서는 뒤집힌 필터를 배우면 되므로 결과에 차이가 없습니다. 여기 보인 세로선·가로선 필터는 좌우·상하 대칭이라 뒤집어도 같습니다.

필터 값은 설명용으로 직접 정했습니다. CNN에서는 필터 값을 학습하며, 보통 편향을 더하고 ReLU 같은 활성화를 거칩니다(여기서는 생략). 흐리기 필터는 9칸 평균(모든 값 1/9)이고 특징 맵 숫자는 소수 둘째 자리로 반올림했습니다.
