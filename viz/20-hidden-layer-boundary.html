기계와 생각 · 07 신경망·심화 기법 · VIZ-20

은닉층은 경계를 어떻게 구부릴까.

은닉층이 없는 모델(로지스틱 회귀)이 그을 수 있는 경계는 직선 하나뿐입니다. tanh 은닉 뉴런을 넣으면 경계가 휘어집니다. 데이터와 은닉 뉴런 수를 고른 뒤 [학습 시작]을 눌러 경계가 자라는 모습을 보세요.

● 가상 데이터80점 · 고정 시드로 생성

데이터
은닉 뉴런

모델: 입력 2 → tanh 은닉 1층(뉴런 H개) → 시그모이드 출력 1개. H=0이면 입력이 곧바로 시그모이드로 가는 로지스틱 회귀입니다. 손실은 이진 교차엔트로피, 80점 전체배치에 Adam(학습률 0.03, β₁=0.9, β₂=0.999)을 적용합니다. 이 작은 신경망은 이 페이지가 브라우저에서 직접 JS로 학습합니다(라이브러리 없음).

가중치 초기값은 고정 시드(4)의 정규분포(Xavier 방식 분산)입니다. 초기값에 따라 실패할 수 있음: 특히 은닉 뉴런 2개로 XOR을 풀 때 같은 설정으로 시드 1~20을 시험해 보니 9개에서 정확도 71~75%에 머물렀습니다(나쁜 국소해·정체 구간). 이 페이지는 성공하는 시드를 고정했습니다.

정확도는 학습 데이터 80점에 대한 값입니다(검증 데이터로 잰 일반화 성능이 아님). 배경 면은 화면을 60×60 격자로 나눠 각 칸 중심의 예측 확률로 칠했습니다.
