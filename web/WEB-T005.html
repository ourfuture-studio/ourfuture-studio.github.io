HTML 내용과 CSS 표현의 분리

예제는 class="notice"인 div 요소 안에 h1과 p 요소를 둡니다. .notice h1 선택자로 해당 div 내부의 h1을 선택하고 color 선언으로 텍스트 색을 지정합니다.

요소의 텍스트와 계층은 HTML 소스에, 표시 스타일은 style 요소 안의 CSS에 작성합니다. 실습에서는 HTML을 유지한 채 CSS 선언값만 변경합니다.

CSS 선택자·속성·값

.notice { color: #1B2340; }에서 .notice는 선택자이고 color: #1B2340은 선언입니다. color는 CSS 속성, #1B2340은 속성값입니다. 여러 선언은 중괄호 안에 작성하고 세미콜론으로 구분합니다.

CSS는 HTML의 style 요소에 작성하거나 link 요소로 외부 스타일시트를 연결할 수 있습니다. HTML 요소의 style 속성에 작성하는 인라인 선언도 있습니다. 이 예제는 문서 내부 style 요소를 사용합니다.

CSS 글자색 변경 예제

.notice h1 규칙의 color를 #1B2340에서 #7A1F2E로 변경합니다. 저장·새로고침하거나 실습 편집기에서 적용한 뒤 h1의 계산된 color 값을 확인합니다.

h1의 텍스트와 p의 내용은 수정하지 않았으므로 유지됩니다. font-size, line-height, padding은 서로 다른 CSS 속성이므로 각 속성의 변경 결과도 따로 관찰합니다.

문서 구조와 색상 표현

선택자와 일치하는 요소가 있어도 선언이 문법상 유효하지 않거나 다른 규칙에 의해 재정의되면 원하는 값이 적용되지 않을 수 있습니다. 개발자 도구에서 선택자 일치 여부와 최종 계산값을 구분합니다.

CSS 스타일을 제거해도 HTML의 제목·문단 구조는 남아 있어야 합니다. 색상만으로 요소의 의미를 전달하지 않고, 적절한 HTML 요소와 텍스트를 함께 사용합니다.

중첩된 스타일 규칙

CSS 적용은 선택 대상, 속성명, 값, 최종 계산값으로 나누어 설명할 수 있습니다. 선택자에 포함된 HTML 속성값과 CSS 속성값은 서로 다른 위치에 작성됩니다.

같은 요소에 여러 선언이 적용될 때의 선택 기준은 다음 편의 캐스케이드와 명시도에서 다룹니다.
