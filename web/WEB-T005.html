예상 결과 · 제목은 버건디가 되고 제목 문구와 문단 내용은 유지됩니다.

CSS 선택자·속성·값

.notice { color: #1B2340; }에서 .notice는 class="notice"인 요소를 선택하고 color는 글자색 속성, #1B2340은 값입니다. CSS는 style 요소, 외부 스타일시트 등으로 연결할 수 있으며 이번에는 한 파일의 style을 사용합니다.

요소가 선택되었는지와 선언이 실제 적용되었는지는 구별합니다. 선언이 잘못되거나 다른 규칙에 밀릴 수 있습니다. 개발자 도구에서 일치하는 규칙과 계산된 스타일을 함께 확인합니다.

문서 구조와 색상 표현

CSS가 어떤 모양을 지정하더라도 안내문의 제목과 설명은 HTML에 남겨 두어야 합니다. 스타일을 껐을 때에도 내용 순서를 읽을 수 있는지 보는 것이 이 예제의 구조 점검입니다.

색은 제목의 유일한 구분 수단으로 쓰지 않습니다. 제목 요소와 문구가 역할을 전달하고, 색은 그 표현을 돕도록 둡니다. 색상 대비의 적합성은 실제 배경과 글자 크기 조건에서 따로 판단합니다.
