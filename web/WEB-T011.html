함수의 입력·출력 계약

remaining(capacity, enrolled) 함수는 두 정수의 차이를 계산합니다. 입력 조건은 두 값이 0 이상인 정수이고 enrolled가 capacity 이하인 것입니다.

조건에 맞는 값은 capacity-enrolled를 반환하고, 조건을 벗어난 값은 RangeError 예외를 발생시킵니다. 함수의 입력 조건과 정상 반환·예외 경로를 먼저 정합니다.

함수 정의·호출·반환

function remaining(capacity, enrolled) { ... }는 함수 선언입니다. capacity와 enrolled는 매개변수이고, remaining(10, 8)의 10과 8은 호출할 때 전달하는 인자입니다.

return 표현식은 실행 결과를 호출한 쪽으로 반환합니다. 반환 자체가 DOM을 변경하거나 화면에 출력하는 것은 아닙니다. 예제는 반환값을 values 배열에 넣은 다음 별도의 코드에서 출력합니다.

인자와 반환값 확인

remaining(10, 8)은 2, remaining(8, 5)는 3을 반환합니다. remaining(10, 10)을 호출하면 0입니다. 같은 함수 본문에 서로 다른 인자를 전달해 결과를 비교합니다.

remaining(10, 11)은 입력 검사에서 RangeError를 발생시킵니다. 예외를 처리하려면 호출한 쪽에서 try·catch를 사용하고, 처리하지 않은 경우에는 개발자 도구에서 예외 위치를 확인합니다.

함수 참조와 호출의 차이

remaining은 함수 값에 대한 참조이고 remaining(10, 8)은 함수를 실행하는 호출식입니다. 이벤트 리스너로 함수를 전달하는 경우와 즉시 호출하는 경우에도 이 차이를 유지합니다.

함수를 정의했다는 사실만으로 모든 입력을 처리하는 것은 아닙니다. 허용할 자료형·범위와 반환값·예외의 의미를 구체적으로 정해야 합니다.
