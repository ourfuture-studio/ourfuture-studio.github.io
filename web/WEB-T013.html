DOM 텍스트 변경 예제

예제는 id="notice"인 p 요소를 선택합니다. HTML 소스의 초기 텍스트와 JavaScript 실행 후 textContent의 값을 비교합니다. ‘신청 안내 준비 중’과 ‘연습 안내가 열렸습니다.’는 변경 전후를 구분하는 예제 문자열입니다.

HTML 파일의 원본, 파싱된 DOM, 렌더링된 결과는 서로 관련되지만 같은 대상은 아닙니다. 이 편에서는 DOM의 텍스트 변경을 확인합니다.

querySelector와 textContent

document.querySelector("#notice")는 CSS 선택자와 일치하는 첫 요소를 반환하며, 일치하는 요소가 없으면 null을 반환합니다. 유효하지 않은 선택자 문자열은 별도의 구문 오류가 될 수 있습니다.

선택한 요소의 textContent에 문자열을 대입하면 해당 요소의 기존 자식 콘텐츠를 그 텍스트로 대체합니다. 예제의 script는 대상 p 요소 뒤에 있으므로 요소가 생성된 후 실행합니다. 먼저 실행하는 스크립트는 defer나 문서 로드 시점 등 실행 순서를 고려해야 합니다.

원본 HTML과 실행 중인 DOM

문서를 열고 개발자 도구의 요소 패널에서 변경된 p의 텍스트를 확인합니다. 편집기의 HTML 파일에는 초기 문자열이 남아 있어도 실행 중인 DOM은 변경될 수 있습니다.

선택자를 #missing으로 바꾸면 반환값은 null입니다. 예제의 if 검사는 요소가 존재할 때에만 textContent를 변경하도록 합니다.

텍스트 삽입과 HTML 해석

textContent는 문자열을 HTML 마크업으로 해석하지 않습니다. <strong>연습</strong>을 대입하면 꺾쇠와 요소 이름까지 문자로 표시됩니다. HTML을 파싱하는 innerHTML과 구분합니다.

DOM 변경은 브라우저 메모리에서 일어나며 서버나 디스크의 HTML 파일을 자동으로 수정하지 않습니다. 문서에는 요소 노드 외에도 텍스트 노드 등이 있으므로 DOM의 모든 노드를 HTML 요소와 동일시하지 않습니다.

DOM 변경과 이벤트 시점

새로고침하면 HTML 소스를 다시 읽고 스크립트를 다시 실행합니다. 현재 예제는 문서 파싱 과정에서 텍스트를 변경합니다.

사용자 동작이나 폼 제출 시점에 변경하려면 이벤트 리스너를 등록합니다. 다음 편에서는 submit 이벤트와 기본 제출 동작을 구분합니다.
