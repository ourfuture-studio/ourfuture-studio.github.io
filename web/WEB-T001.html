HTML 문서 작성 예제

HTML은 문서의 구조와 내용의 의미를 표시하는 마크업 언어입니다. 예제의 h1 요소는 제목을, 두 개의 p 요소는 각각 문단을 나타냅니다. ‘웹 기초’와 ‘HTML부터 함께 배웁니다.’는 요소 안에 들어 있는 예제 텍스트입니다.

이 편에서는 HTML 파일을 작성하고, 소스 코드의 각 요소가 브라우저에서 어떻게 표시되는지 확인합니다. 문서 구조, 요소의 내용, 브라우저의 표시 결과를 구분해 읽습니다.

HTML 요소·속성과 기본 구조

<!doctype html>은 문서 형식 선언이며 HTML 요소가 아닙니다. html 요소는 문서의 루트이고, 그 안에 head와 body 요소를 둡니다. head 안의 title은 문서 제목, meta charset="utf-8"은 문자 인코딩 선언입니다. body 안의 h1과 p는 본문 요소입니다.

<p>설명</p>에서 <p>와 </p>는 시작 태그와 끝 태그이고, 두 태그와 그 사이의 내용을 포함한 전체가 p 요소입니다. lang="ko"는 html의 속성으로 문서의 주된 언어를 지정합니다. meta는 끝 태그를 쓰지 않는 빈 요소입니다. HTML 속성과 요소 안의 텍스트는 서로 다릅니다.

HTML 파일 저장과 브라우저 실행

전체 코드를 index.html로 저장하고 파일 인코딩을 UTF-8로 설정합니다. Windows에서는 확장명을 표시해 index.html.txt로 저장되지 않았는지 확인합니다. 저장한 파일을 브라우저에서 열면 body의 h1과 두 p 요소가 표시됩니다.

예제의 title 내용은 ‘웹 기초 강좌 안내’, h1 내용은 ‘웹 기초’입니다. title은 탭 등에서 문서를 구별하는 데 쓰이고 h1은 본문에 표시됩니다. p 요소의 텍스트만 수정하고 저장·새로고침하면 해당 문단의 내용이 바뀝니다.

HTML 구문 오류와 브라우저 기본 스타일

브라우저는 HTML 구문 오류의 일부를 정해진 파싱 규칙에 따라 복구합니다. 화면이 표시된다는 사실만으로 작성한 소스의 문법과 의미 구조가 모두 적합하다고 판단하지 않습니다. 이 예제는 학습을 위해 각 영역의 시작과 끝을 명시합니다.

CSS를 작성하지 않아도 h1의 글자 크기와 p의 여백은 브라우저 기본 스타일에 따라 표시됩니다. 이 크기는 요소의 의미 정의가 아닙니다. charset 선언만으로 다른 인코딩의 파일이 UTF-8로 변환되지는 않으므로 실제 저장 인코딩도 맞춰야 합니다.

file URL과 HTTP 실행의 차이

HTML 파일을 직접 열면 file: URL로 실행할 수 있습니다. HTTP로 제공하는 문서는 http: 또는 https: URL을 사용하며 서버에 대한 요청·응답이 발생합니다. 파일 직접 열기와 HTTP 실행은 서로 다른 실행 조건입니다.

다음 편에서는 h1~h6 제목 요소의 수준과 CSS 글자 크기를 분리해 설명합니다. 문서 구조는 HTML로, 표시 방식은 CSS로 지정한다는 구분을 유지합니다.
