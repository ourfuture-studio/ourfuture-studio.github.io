HTML 문서는 html·head·body 요소로 기본 구조를 구성합니다. head에는 문서 제목과 문자 인코딩을, body에는 제목·문단 등 본문 내용을 작성합니다.

HTML 요소·속성과 기본 구조

h1 요소는 최상위 수준의 제목, p 요소는 문단을 나타냅니다. <p>설명</p>에서 <p>는 시작 태그, </p>는 끝 태그이며 이 전체가 하나의 요소입니다. 속성은 lang="ko"처럼 시작 태그에 추가 정보를 적는 부분입니다.

head에는 문자 인코딩과 문서 제목 같은 메타데이터를, body에는 화면 본문을 둡니다. title은 탭 등에서 문서를 구별하는 이름이고 h1은 본문 안의 제목입니다. UTF-8 선언과 실제 UTF-8 저장을 함께 맞춥니다. meta처럼 끝 태그를 쓰지 않는 요소도 있습니다.

HTML 구문 오류와 브라우저 기본 스타일

브라우저는 잘못 적힌 HTML 일부를 보완해 표시합니다. 화면이 나왔다는 이유만으로 문법과 의미가 모두 맞았다고 판단할 수는 없습니다. 이번에는 시작과 끝이 분명한 작은 문서를 기준으로 비교합니다.

별도 CSS가 없어도 제목이 크게 보이는 것은 브라우저의 기본 스타일 때문입니다. 큰 글씨라는 모양과 제목이라는 역할을 같은 뜻으로 외우지 않습니다.
