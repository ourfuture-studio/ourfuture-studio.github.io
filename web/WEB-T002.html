HTML 제목 요소와 문단.

h1~h6은 HTML 문서의 제목 수준을 나타내고 p는 문단을 나타냅니다. 글자 크기는 CSS의 font-size 속성으로 지정하며, 크기를 바꾸어도 요소의 종류와 의미는 바뀌지 않습니다.

제목 요소와 문단의 표시 예제

예제는 h1, h2, p 요소를 포함합니다. h1은 문서의 주제, h2는 그 아래 절의 제목, p는 해당 절의 설명 문단으로 사용합니다. CSS에서 h2와 class="large"인 p의 font-size를 모두 24px로 지정합니다.

두 요소가 같은 크기로 표시되어도 HTML 구조는 서로 다릅니다. 요소 이름과 CSS 계산값을 각각 확인하는 것이 실습의 목표입니다.

h1~h6의 제목 수준

h1~h6의 숫자는 제목 수준을 나타냅니다. 이 예제의 h2는 h1 아래의 절을 표시하며, ‘두 번째로 큰 글씨’를 뜻하지 않습니다. p 요소는 문단이므로 font-size를 높여도 제목 요소가 되지 않습니다.

제목 수준은 문서 내용의 계층에 맞춰 정하고 표시 크기는 CSS로 조정합니다. 원하는 글자 크기를 얻기 위해 제목 수준을 임의로 건너뛰면 문서의 제목 계층이 내용과 어긋날 수 있습니다.

CSS 글자 크기 변경

개발자 도구의 요소 패널에서 h2와 p.large를 선택합니다. 계산된 스타일에서 두 요소의 font-size가 24px인지 확인합니다.

h2 규칙의 font-size만 18px로 변경하면 h2는 작아지고 p.large는 24px를 유지합니다. h2 요소 자체를 다른 요소로 바꾸지 않았으므로 제목 수준은 유지됩니다.

강조와 제목 요소의 차이

굵은 글자나 큰 글자로 표시하는 것은 시각적 스타일입니다. 절을 구분하는 제목 요소를 p와 CSS만으로 대체하면 제목에 해당하는 의미 구조가 빠집니다.

문서의 모든 줄을 제목으로 표시할 필요도 없습니다. 예제에서는 h1 하나와 하위 h2를 사용하지만, 제목 수와 계층은 실제 문서의 내용 구조에 맞춰 설계합니다. 제목 구조가 존재한다는 사실과 보조기술에서의 실제 사용성 검증은 구분합니다.

제목 계층과 문서 구조

문서를 작성할 때에는 먼저 전체 주제와 하위 절을 정하고 각 제목에 해당하는 요소 수준을 지정합니다. 그다음 CSS로 글자 크기·색·간격을 조정합니다.
