Promise와 상태를 연결합니다

Promise는 비동기 작업의 완료나 실패를 다루는 객체입니다. async 함수 안에서 await로 완료를 기다리고 try/catch로 실패를 처리할 수 있습니다. 예제의 finally는 성공·실패 뒤 버튼 상태를 복원합니다. fetch의 HTTP 상태 검사도 별도로 필요합니다.
