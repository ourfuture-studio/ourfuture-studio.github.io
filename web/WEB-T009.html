가상 인원 데이터와 계산

예제는 capacity=10과 enrolled=8이라는 숫자 값을 사용합니다. capacity는 상한값, enrolled는 검사할 값이며 두 값의 차이를 계산합니다. 인원이라는 단위는 이 숫자 예제의 적용 맥락입니다.

변수 선언, 비교식, 조건에 따른 출력 문자열을 차례로 읽습니다. 실제 서비스 데이터나 서버의 상태를 읽는 코드는 포함하지 않습니다.

변수·자료형·비교 조건

const는 다시 대입할 수 없는 바인딩을, let은 다시 대입할 수 있는 변수를 선언합니다. enrolled < capacity는 비교식이며 결과는 불리언 값입니다. if·else if·else는 조건에 따라 실행할 코드를 선택합니다.

숫자 8과 문자열 "8"은 자료형이 다릅니다. + 연산은 문자열 연결이 될 수도 있으므로 입력 문자열을 숫자로 사용할 때에는 변환을 명시합니다. Number("")는 0이므로 빈 문자열 검사와 숫자 변환을 구분해야 합니다.

입력값과 경계 조건

예제는 Number.isInteger(enrolled)로 정수 여부를 검사하고, 0 이상 capacity 이하인지 확인합니다. enrolled=8이면 차이 2를 출력하고, 10이면 상한 도달 상태를, 11이면 범위 오류를 출력합니다.

코드의 값만 바꾸고 분기문을 유지해 각 입력에서 어떤 조건이 참이 되는지 추적합니다. 예제의 출력 문구와 비교식의 결과를 짝지어 확인합니다.

클라이언트 계산의 한계

자료형이 숫자라는 사실만으로 허용되는 입력이라는 뜻은 아닙니다. 소수·음수·범위 초과 값은 이 예제의 정수 범위 계약에 맞지 않습니다.

브라우저의 입력 검사는 서버의 데이터 검증이나 동시 요청 처리를 대신하지 못합니다. 이 예제의 출력은 고정된 입력에 대한 조건식의 결과입니다.

여러 항목의 데이터 구성

변수는 개별 값을 저장하고, 배열과 객체는 여러 값을 구조화하는 데 사용합니다. 같은 구조의 데이터가 늘어나면 변수 이름을 계속 추가하기보다 자료 구조를 정합니다.

다음 편에서는 객체 배열과 반복문으로 여러 항목을 처리합니다.
