강좌 데이터 구성 예제

예제의 courses는 객체 세 개를 포함한 배열입니다. 각 객체는 title 문자열 속성과 capacity 숫자 속성을 가집니다. ‘웹 기초’ 등의 문자열은 객체 속성의 예제 값입니다.

관련된 두 값을 한 객체에 묶으면 이름과 숫자의 대응 관계를 함께 유지할 수 있습니다. 배열의 순서는 출력 순서에 사용합니다.

객체 배열과 반복

[ ... ]는 배열 리터럴이고 { title: "웹 기초", capacity: 10 }은 객체 리터럴입니다. 배열 인덱스는 0부터 시작하므로 첫 객체는 courses[0]으로 접근합니다. 객체 속성은 course.title이나 course.capacity처럼 읽습니다.

for...of는 배열의 값을 차례로 가져옵니다. 이 예제는 비어 있는 인덱스가 없는 배열이며 length는 3입니다. 일반적인 배열의 length는 실제 저장된 항목 수와 항상 같지는 않습니다.

배열 항목 추가

배열에 { title: "접근성 기초", capacity: 5 }를 추가하면 반복 횟수가 하나 늘어 출력도 네 줄이 됩니다. for...of의 본문은 수정하지 않습니다.

반복문은 각 객체에서 속성을 읽어 문자열을 lines 배열에 추가하고 join("\n")으로 결합합니다. 결합한 문자열을 pre 요소의 textContent에 대입해 줄바꿈을 유지합니다.

const와 배열 변경·length

const courses는 courses에 다른 배열을 다시 대입하지 못하게 하지만 배열의 항목이나 내부 객체 속성 변경까지 막지는 않습니다.

Array.length는 쓰기가 가능한 속성입니다. 길이를 줄이면 범위를 벗어난 뒤 항목이 제거됩니다. 희소 배열에서는 빈 인덱스가 존재할 수 있으므로 length를 일반적인 저장 항목 수와 동일시하지 않습니다.
