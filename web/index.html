웹 프로그래밍 기초.

HTML 문서 구조, CSS 스타일과 배치, JavaScript, HTTP, 브라우저 API를 학습합니다. 각 항목에서 코드를 수정하고 실행 결과를 확인할 수 있습니다.

문서와 표현 01~08 · 값과 동작 09~15 · 통신과 저장 16~18 · 기능 확장 19~22

  1. 01

    HTML 문서의 기본 구조.

    HTML 문서는 html·head·body 요소로 기본 구조를 구성합니다. head에는 문서 제목과 문자 인코딩을, body에는 제목·문단 등 본문 내용을 작성합니다.

  2. 02

    HTML 제목 요소와 문단.

    제목은 h1~h6으로 문서의 수준을 표시하고, 글씨 크기는 CSS로 바꿉니다. 같은 크기로 보여도 h2와 p가 맡는 역할은 다릅니다.

  3. 03

    HTML 하이퍼링크와 URL 경로.

    a 요소의 href에 이동할 주소를 적습니다. 상대 경로는 현재 문서의 기준 URL에서 해석되므로 파일의 위치를 함께 보아야 합니다.

  4. 04

    HTML 이미지와 대체 텍스트.

    img의 src는 그림의 위치를, alt는 그 그림이 문맥에서 전달하는 정보의 대안을 적습니다. 장식용 그림과 정보를 담은 그림의 alt는 다르게 정합니다.

  5. 05

    CSS 선택자와 스타일 적용.

    CSS는 선택한 요소에 속성과 값을 적용합니다. HTML의 문장을 유지하고 CSS 선언 하나만 바꾸면 내용과 표현의 차이를 확인할 수 있습니다.

  6. 06

    CSS 캐스케이드와 명시도.

    CSS는 단순히 마지막 줄만 따르지 않습니다. 같은 출처·중요도·레이어 등의 조건에서 선택자의 명시도를 비교하고, 그것도 같으면 뒤 선언이 적용됩니다.

  7. 07

    CSS 박스 모델과 box-sizing.

    content-box의 width는 내용 영역의 폭입니다. padding과 border가 더해지므로 전체 테두리 폭을 기준으로 맞추려면 box-sizing:border-box를 사용할 수 있습니다.

  8. 08

    CSS Flexbox와 반응형 배치.

    Flexbox의 줄바꿈과 카드의 크기 조건을 함께 정하면 좁은 화면에서 카드를 다음 줄로 보낼 수 있습니다. 뷰포트 설정과 실제 넘침도 확인해야 합니다.

  9. 09

    JavaScript 변수·자료형·조건문.

    JavaScript의 값과 비교식을 사용하면 인원에 따라 다른 안내를 선택할 수 있습니다. 입력 문자열을 숫자로 바꾸는 일과 허용 범위를 확인하는 일은 구분합니다.

  10. 10

    JavaScript 배열·객체·반복문.

    배열은 순서가 있는 목록을, 객체는 이름 붙은 속성을 묶습니다. 강좌 객체들을 배열에 넣고 반복하면 목록이 늘어도 같은 처리 흐름을 사용할 수 있습니다.

  11. 11

    JavaScript 함수와 반환값.

    함수는 입력을 받아 정한 처리를 수행하고 결과를 반환하도록 작성할 수 있습니다. 함수의 정의, 호출, 반환값을 나누어 읽습니다.

  12. 12

    HTML 폼과 입력 요소.

    label은 입력 요소의 이름을 연결하고, name은 폼 데이터의 키, value는 값을 나타냅니다. 입력칸을 그렸다는 사실과 서버에 접수했다는 사실은 다릅니다.

  13. 13

    DOM 요소 선택과 텍스트 변경.

    DOM에서 대상 요소를 찾고 textContent를 대입하면 그 요소의 텍스트를 바꿀 수 있습니다. 파일의 원본과 실행 중인 DOM을 구별합니다.

  14. 14

    이벤트 처리와 폼 제출.

    submit 이벤트에 함수를 등록하면 폼 제출 시도를 처리할 수 있습니다. 기본 제출을 막고 FormData를 읽는 이 예제는 화면 안의 연습이며 실제 접수가 아닙니다.

  15. 15

    Window 객체와 타이머.

    setTimeout은 지연 뒤 실행할 콜백을 예약합니다. 정한 시각의 실행을 보장하는 시계가 아니며, 반환된 식별자로 예약을 취소할 수 있습니다.

  16. 16

    HTTP 요청·응답과 Fetch API.

    HTTP에서는 클라이언트가 요청하고 서버가 상태와 본문 등을 담아 응답합니다. fetch로 받은 응답은 상태를 확인하고 본문을 해석해야 사용할 수 있습니다.

  17. 17

    Promise와 async·await 비동기 처리.

    비동기 작업은 대기·성공·실패 상태를 나눠 표시합니다. await는 비동기 함수의 다음 처리를 기다리게 하며 화면 전체를 동기 반복문처럼 멈추라는 지시가 아닙니다.

  18. 18

    Web Storage와 localStorage.

    localStorage는 같은 origin의 브라우저 저장소에 문자열을 저장합니다. 새로고침 뒤 읽을 수 있지만 서버 명단이나 영구 보관을 보장하지 않습니다.

  19. 19

    Canvas 2D 좌표와 도형 그리기.

    canvas의 2D 컨텍스트로 좌표와 크기를 지정해 그릴 수 있습니다. 그린 막대는 독립된 HTML 요소가 아니므로 같은 정보를 텍스트로도 제공합니다.

  20. 20

    HTML 미디어 요소와 재생 제어.

    audio·video는 재생할 파일과 제어 기능을 연결합니다. play()의 성공과 실패, 파일 로딩 오류를 구분하고 자동 재생을 보장하지 않습니다.

  21. 21

    Geolocation API의 위치 권한과 오류 처리.

    위치 API는 보안 컨텍스트와 사용자 권한 등의 조건을 요구합니다. 성공만 가정하지 않고 거절·사용 불가·시간 초과를 구별해 안내합니다.

  22. 22

    Web Worker와 메시지 통신.

    전용 Worker에 메시지로 계산 입력을 보내고 결과를 받을 수 있습니다. Worker는 문서 DOM에 직접 접근하지 않으며 화면 변경은 결과를 받은 메인 쪽에서 수행합니다.
