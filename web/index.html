웹 프로그래밍 기초.

HTML 문서 구조, CSS 스타일과 배치, JavaScript, HTTP, 브라우저 API를 학습합니다. 각 항목에서 코드를 수정하고 실행 결과를 확인할 수 있습니다.

문서와 표현 01~08 · 값과 동작 09~15 · 통신과 저장 16~18 · 기능 확장 19~22

  1. 01

    HTML 문서의 기본 구조.

    HTML 문서는 요소와 속성으로 내용의 구조와 메타데이터를 표현합니다. html은 루트 요소이고, head는 문서 제목·문자 인코딩 등의 메타데이터를, body는 제목·문단 등의 본문을 포함합니다.

  2. 02

    HTML 제목 요소와 문단.

    h1~h6은 HTML 문서의 제목 수준을 나타내고 p는 문단을 나타냅니다. 글자 크기는 CSS의 font-size 속성으로 지정하며, 크기를 바꾸어도 요소의 종류와 의미는 바뀌지 않습니다.

  3. 03

    HTML 하이퍼링크와 URL 경로.

    a 요소는 href 속성으로 이동할 URL을 지정하는 하이퍼링크를 만듭니다. 상대 URL은 문서의 기준 URL을 바탕으로 해석되므로 현재 HTML 파일과 대상 파일의 위치를 함께 확인해야 합니다.

  4. 04

    HTML 이미지와 대체 텍스트.

    img 요소의 src 속성은 이미지 리소스 URL을, alt 속성은 이미지의 문맥상 정보를 대체하는 텍스트를 지정합니다. width·height 속성과 CSS 표시 크기는 구분해서 설정합니다.

  5. 05

    CSS 선택자와 스타일 적용.

    CSS 규칙은 선택자로 HTML 요소를 지정하고 속성·값의 선언으로 스타일을 적용합니다. class는 HTML 속성이고 .notice는 그 속성값을 사용하는 CSS 클래스 선택자입니다.

  6. 06

    CSS 캐스케이드와 명시도.

    CSS 캐스케이드는 같은 요소·속성에 적용되는 선언 중 사용할 값을 결정합니다. 예제와 같이 출처·중요도·레이어 조건이 같을 때에는 명시도를 비교하고, 명시도도 같으면 뒤 선언을 적용합니다.

  7. 07

    CSS 박스 모델과 box-sizing.

    CSS 박스 모델은 내용 영역·padding·border·margin을 구분합니다. box-sizing:content-box에서는 width가 내용 폭이고, border-box에서는 padding과 border를 포함한 폭입니다.

  8. 08

    CSS Flexbox와 반응형 배치.

    Flexbox는 컨테이너 안의 flex item을 배치하는 CSS 레이아웃 방식입니다. flex-wrap, flex, gap과 요소의 최소 크기 조건을 함께 설정해 좁은 뷰포트에서의 줄바꿈을 제어합니다.

  9. 09

    JavaScript 변수·자료형·조건문.

    JavaScript는 변수에 값을 저장하고 자료형에 맞는 연산과 조건 분기를 수행합니다. 숫자 변환, 정수 여부 검사, 허용 범위 검사를 구분해 처리합니다.

  10. 10

    JavaScript 배열·객체·반복문.

    배열은 인덱스로 접근하는 순서 있는 자료 구조이고, 객체는 속성 이름과 값을 묶습니다. 객체 배열을 for...of로 순회하면 항목마다 같은 처리 코드를 적용할 수 있습니다.

  11. 11

    JavaScript 함수와 반환값.

    함수는 매개변수로 입력을 받고 코드를 실행한 뒤 return으로 값을 반환할 수 있습니다. 함수 정의·함수 참조·함수 호출·반환값을 구분합니다.

  12. 12

    HTML 폼과 입력 요소.

    HTML 폼은 form 요소와 input·select·button 등의 컨트롤로 구성합니다. label·for·id는 입력 이름과 연결을, name·value는 폼 데이터의 키와 값을 지정하는 데 사용합니다.

  13. 13

    DOM 요소 선택과 텍스트 변경.

    DOM은 브라우저가 문서를 객체 트리로 표현한 것입니다. querySelector로 요소를 선택하고 textContent 프로퍼티에 문자열을 대입해 실행 중인 DOM의 텍스트를 변경합니다.

  14. 14

    이벤트 처리와 폼 제출.

    form의 submit 이벤트 리스너에서 기본 제출을 취소하고 FormData로 현재 입력값을 읽을 수 있습니다. 이벤트 처리, 기본 동작, 폼 데이터, DOM 변경을 구분해 작성합니다.

  15. 15

    Window 객체와 타이머.

    Window 객체의 setTimeout()은 지연 후 실행할 콜백을 예약하고 식별자를 반환합니다. clearTimeout()은 해당 예약을 취소합니다. 지정한 지연은 정확한 실행 시각을 보장하지 않습니다.

  16. 16

    HTTP 요청·응답과 Fetch API.

    HTTP 요청은 URL의 리소스를 요청하고, 응답은 상태·헤더·본문 등을 제공합니다. Fetch API로 응답을 받은 뒤 HTTP 상태를 검사하고 본문을 JSON으로 파싱해 사용합니다.

  17. 17

    Promise와 async·await 비동기 처리.

    Promise는 비동기 작업의 완료나 실패를 다루며 async 함수는 Promise를 반환합니다. await·try·catch·finally를 사용해 결과 처리, 오류 처리, UI 상태 복원을 분리합니다.

  18. 18

    Web Storage와 localStorage.

    localStorage는 origin별 브라우저 저장소에 문자열 키·값을 저장합니다. setItem()·getItem()·removeItem()으로 쓰기·읽기·삭제를 수행하며 서버 저장과 구분합니다.

  19. 19

    Canvas 2D 좌표와 도형 그리기.

    canvas 요소는 그리기 영역을 제공하고 CanvasRenderingContext2D의 메서드로 도형을 그립니다. HTML 크기 속성, CSS 표시 크기, 그려진 픽셀과 DOM 요소를 구분합니다.

  20. 20

    HTML 미디어 요소와 재생 제어.

    audio·video 요소는 미디어 리소스를 포함하며 HTMLMediaElement API로 재생을 제어합니다. HTML 속성, DOM 프로퍼티·메서드, 재생 이벤트와 실제 출력 상태를 구분합니다.

  21. 21

    Geolocation API의 위치 권한과 오류 처리.

    Geolocation API는 보안 컨텍스트·권한 등의 조건에서 위치 결과를 콜백으로 제공합니다. 실습은 실제 위치를 요청하지 않고 성공·권한 거절·시간 초과의 모의 응답을 처리합니다.

  22. 22

    Web Worker와 메시지 통신.

    전용 Web Worker는 메인 문서와 별도의 실행 문맥에서 JavaScript를 실행합니다. postMessage()와 message 이벤트로 데이터를 전달하고, DOM 변경은 메인 문서에서 수행합니다.
