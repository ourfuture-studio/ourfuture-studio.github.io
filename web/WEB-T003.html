HTML 하이퍼링크와 URL 경로.

a 요소는 href 속성으로 이동할 URL을 지정하는 하이퍼링크를 만듭니다. 상대 URL은 문서의 기준 URL을 바탕으로 해석되므로 현재 HTML 파일과 대상 파일의 위치를 함께 확인해야 합니다.

연결 파일 전체 코드

details.html

<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>준비물 안내</title>
</head>
<body>
<h1>준비물 안내</h1>
<p>편집기와 브라우저를 준비합니다.</p>
<a href="index.html">강좌 안내로 돌아가기</a>
</body>
</html>

직접 확인

href를 missing.html로 바꾸어 한 번 이동한 뒤 details.html로 복원하세요.

예상 결과 · HTTP 실습 서버에서는 없는 경로가 404로 응답합니다. 파일 직접 열기는 다른 오류 화면일 수 있습니다. 복원하면 준비물 문서로 이동합니다.

HTML 파일 간 하이퍼링크

예제는 index.html과 details.html이라는 두 HTML 문서로 구성합니다. index.html의 a 요소에 href="details.html"을 지정하고, details.html에는 href="index.html"인 링크를 작성합니다.

두 파일은 같은 폴더에 둡니다. 링크 안의 텍스트는 목적지를 설명하는 문자열이고, 실제 이동 대상은 href 속성값으로 결정됩니다.

href와 URL 기준 위치

href="details.html"은 기준 URL과 같은 디렉터리의 파일을, materials/details.html은 하위 디렉터리의 파일을, ../index.html은 상위 디렉터리의 파일을 참조합니다. 이 예제는 base 요소를 사용하지 않으므로 문서 URL이 기준 URL이 됩니다.

https://로 시작하는 URL은 스킴과 호스트 등을 포함합니다. /로 시작하는 URL 경로는 HTTP 사이트의 루트 경로를 기준으로 해석합니다. 이 경로 루트는 Windows 파일 시스템의 드라이브 루트와 다릅니다.

문서 이동과 키보드 조작

index.html의 링크를 실행해 details.html의 h1이 표시되는지 확인합니다. 대상 문서의 복귀 링크를 실행하면 index.html로 이동합니다. Tab으로 a 요소에 초점을 옮긴 뒤 Enter로도 링크를 실행할 수 있습니다.

href를 missing.html로 바꾸면 존재하지 않는 파일을 참조합니다. HTTP 실행에서는 요청 URL과 404 상태를 개발자 도구의 네트워크 패널에서 확인하고, 다시 details.html로 복원합니다.

파일 경로와 공유 조건

로컬 파일의 절대 경로는 다른 컴퓨터에서 같은 파일 위치를 보장하지 않습니다. 배포할 디렉터리 안의 상대적인 파일 관계를 기준으로 URL을 작성하고 파일명·확장명·대소문자를 정확히 맞춥니다.

현재 문서나 대상 파일을 이동하면 기존 상대 URL이 다른 위치를 참조할 수 있습니다. 링크 텍스트만 수정해도 href 값은 바뀌지 않으므로 표시 문구와 이동 대상을 각각 확인합니다.

이미지 경로와의 연결

링크 오류를 점검할 때에는 문서의 기준 URL, href 속성값, 해석된 요청 URL, 대상 파일 존재 여부를 순서대로 확인합니다.

img 요소의 src도 기준 URL에서 리소스 주소를 해석합니다. 다음 편에서는 이미지 리소스 경로와 alt 속성을 다룹니다.
