연결 파일 전체 코드

details.html

<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>준비물 안내</title>
</head>
<body>
<h1>준비물 안내</h1>
<p>편집기와 브라우저를 준비합니다.</p>
<a href="index.html">강좌 안내로 돌아가기</a>
</body>
</html>

직접 확인

href를 missing.html로 바꾸어 한 번 이동한 뒤 details.html로 복원하세요.

예상 결과 · HTTP 실습 서버에서는 없는 경로가 404로 응답합니다. 파일 직접 열기는 다른 오류 화면일 수 있습니다. 복원하면 준비물 문서로 이동합니다.

href와 URL 기준 위치

이 예제의 href="details.html"은 현재 문서와 같은 폴더의 파일을 가리킵니다. materials/details.html은 하위 폴더, ../index.html은 한 단계 위 파일을 가리킵니다. 여기서는 base 요소를 사용하지 않아 문서 URL이 기준입니다.

https://로 시작하는 완전한 URL과 /로 시작하는 경로도 다릅니다. HTTP에서 /는 서버의 경로 루트를 기준으로 합니다. Windows 드라이브의 루트와 같다고 해석하지 않습니다.

파일 경로와 공유 조건

C:\Users\이름 같은 주소는 다른 사람의 컴퓨터에서 같은 파일을 보장하지 않습니다. 웹에 올릴 폴더 안의 파일 관계를 기준으로 상대 경로를 구성하는 편이 이 예제의 이동을 유지하기 쉽습니다.

파일을 옮겼다면 링크를 다시 눌러 확인합니다. 로컬에서 대소문자 차이가 드러나지 않아도 배포 환경에 따라 결과가 달라질 수 있으므로 이름을 정확히 맞춥니다.
