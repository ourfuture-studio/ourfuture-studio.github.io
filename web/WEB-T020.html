HTMLMediaElement 재생 API와 이벤트

audio의 controls는 브라우저 기본 제어기를 제공합니다. JavaScript의 play()는 Promise를 반환하므로 실패를 처리할 수 있습니다. pause()는 일시 정지, currentTime은 재생 위치입니다. ended와 error 이벤트로 끝남과 로딩 문제를 구분할 수 있습니다.

자동 재생·파일·출력 장치 조건

브라우저는 소리 있는 자동 재생을 제한할 수 있습니다. 파일 경로, 형식 지원, 정책, 음소거와 출력 장치를 구분해 확인합니다. 실제 소리를 들은 검수와 자동 브라우저의 재생 상태 검사는 별개입니다. 영상에는 상황에 맞는 자막과 텍스트 대안도 필요합니다.
