자체 테스트 음원 예제

예제의 audio 요소는 tone.wav를 src로 참조하고 controls 속성으로 기본 제어기를 표시합니다. tone.wav는 자체 생성한 1초짜리 테스트 신호이며 실제 강의 음성이나 외부 음악이 아닙니다.

별도 버튼은 play()·pause()를 호출하고 결과 요소는 재생 상태를 텍스트로 표시합니다. 재생 자동 시작이나 반복은 설정하지 않습니다.

HTMLMediaElement 재생 API와 이벤트

HTML의 src 속성은 미디어 URL을, controls 속성은 기본 제어기 표시를 지정합니다. JavaScript에서는 audio 요소의 DOM 객체를 선택해 메서드와 프로퍼티에 접근합니다.

play()는 재생 시작을 시도하는 Promise를 반환하므로 거부를 처리해야 합니다. pause()는 일시 정지 메서드이고 currentTime은 재생 위치를 다루는 프로퍼티입니다. ended와 error 이벤트로 종료와 리소스 오류를 구분합니다.

사용자 동작에 따른 재생

재생 버튼의 핸들러는 currentTime을 0으로 설정한 뒤 play()를 호출합니다. 이행되면 재생 상태를 표시하고 거부되면 실패 상태를 표시합니다.

미디어가 끝나면 ended 핸들러의 텍스트가 표시됩니다. 일시 정지 버튼은 pause()를 호출합니다. 기본 제어기와 JavaScript 버튼이 같은 audio 요소를 제어하는지 확인합니다.

자동 재생·파일·출력 장치 조건

브라우저 정책에 따라 소리 있는 자동 재생이나 스크립트 재생이 제한될 수 있습니다. 파일 경로·지원 형식·재생 정책·음소거·출력 장치를 각각 점검합니다.

Promise 이행이나 ended 이벤트를 확인하는 자동 검사는 실제 청취와 다릅니다. 이 자료에서는 미디어 상태를 검사했으며 직접 청취를 수행했다고 주장하지 않습니다. 실제 음성·영상 콘텐츠에는 필요한 자막·텍스트 대안도 제공합니다.

재생 실패 처리

재생 요청과 리소스 로딩, 미디어 상태, 실제 출력은 관련되지만 서로 다른 검사 대상입니다. 실패 시에는 원인을 구분하고 재시도 가능한 상태를 표시합니다.
