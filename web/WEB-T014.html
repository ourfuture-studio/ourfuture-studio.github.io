이벤트 등록과 기본 동작 취소

addEventListener("submit", handler)는 나중에 실행할 함수를 등록합니다. handler()를 즉시 호출하는 것과 다릅니다. preventDefault는 취소 가능한 기본 동작을 막으며 전파를 멈추는 stopPropagation과 다릅니다. FormData(form)는 포함 조건을 만족하는 컨트롤의 name과 값을 읽습니다.

화면 확인과 서버 접수의 차이

확인 문구는 브라우저에서 만든 결과이며 서버 저장의 증거가 아닙니다. preventDefault도 다른 리스너나 작성한 코드까지 모두 중단하지 않습니다. 어떤 기본 동작을 취소했는지 구체적으로 설명해야 합니다. 여기서는 기본 폼 제출을 막습니다.
