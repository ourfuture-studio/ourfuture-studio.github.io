CSS 박스 모델과 box-sizing.

CSS 박스 모델은 내용 영역·padding·border·margin을 구분합니다. box-sizing:content-box에서는 width가 내용 폭이고, border-box에서는 padding과 border를 포함한 폭입니다.

content-box와 border-box 비교

두 div 요소에 width:200px, padding:20px, border:2px를 지정합니다. 한 요소는 content-box, 다른 요소는 border-box를 사용합니다.

width의 숫자는 같지만 이 값이 적용되는 영역이 다르므로 테두리까지의 실제 폭을 비교해야 합니다. 예제에서는 수평 방향의 고정 폭을 계산합니다.

박스 폭 계산

content-box의 테두리 폭은 내용 폭에 좌우 padding과 border를 더한 값입니다. 예제에서는 200 + 20×2 + 2×2 = 244px입니다.

border-box의 테두리 폭은 200px이며, 내용 폭은 200 − 20×2 − 2×2 = 156px입니다. margin은 테두리 바깥의 간격이므로 두 계산에 포함하지 않습니다. 이 계산은 예제의 고정 폭과 별도 최소 크기 제약이 없는 조건을 기준으로 합니다.

padding 변경과 폭 측정

개발자 도구의 박스 모델에서 각 요소의 내용 폭·padding·border를 확인합니다. 두 요소의 padding을 30px로 변경하면 content-box의 테두리 폭은 264px가 됩니다.

border-box의 테두리 폭은 200px를 유지하고 내용 폭은 136px로 줄어듭니다. 같은 속성 변경이 어느 영역의 크기에 반영되는지 비교합니다.

박스 크기와 콘텐츠 넘침

box-sizing:border-box는 margin을 width에 포함하지 않으며 모든 콘텐츠 넘침을 막는 설정도 아닙니다. 긴 문자열, 이미지 크기, min-width 등은 별도로 확인해야 합니다.

가로 폭 계산을 세로 margin의 모든 상황에 그대로 적용하지 않습니다. 측정값을 비교할 때에는 내용 폭인지, 테두리 폭인지, margin까지 포함한 배치 공간인지 기준을 명시합니다.

카드 폭과 레이아웃

여러 요소를 배치할 때에는 각 박스의 크기와 요소 사이 간격을 함께 고려합니다. 박스 크기 계산과 배치 규칙은 구분해서 설정합니다.

다음 편에서는 Flexbox 컨테이너와 flex item의 크기·줄바꿈을 사용해 화면 폭에 따른 배치를 다룹니다.
