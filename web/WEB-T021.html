Geolocation API 콜백과 권한

실제 API는 navigator.geolocation.getCurrentPosition(success, error, options)입니다. 즉시 좌표를 반환하는 함수가 아니며 성공·오류 콜백으로 결과를 받습니다. secure context와 권한 정책 등에 따라 사용할 수 있고, 거절·위치 사용 불가·시간 초과는 서로 다른 오류입니다.

모의 응답과 실제 위치 검증의 차이

실제 센서 정확도, 운영체제 권한, 네트워크 기반 위치는 이 모의 예제에서 검증하지 않습니다. 본문에는 실제 호출의 별도 예시만 적고 기본 실행 코드에는 넣지 않습니다. 실제 기능을 붙일 때에는 필요한 목적과 허용·거절 후 화면을 먼저 정해야 합니다.
