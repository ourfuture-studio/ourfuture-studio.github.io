Geolocation API는 보안 컨텍스트·권한 등의 조건에서 위치 결과를 콜백으로 제공합니다. 실습은 실제 위치를 요청하지 않고 성공·권한 거절·시간 초과의 모의 응답을 처리합니다.

위치 응답 모의 예제

예제는 showPosition()과 showError()에 미리 만든 객체를 전달합니다. 위도 37·경도 127은 모의 성공 객체의 고정 값이며 기기에서 수집한 좌표가 아닙니다.

버튼별 입력 객체와 결과 텍스트를 비교해 콜백 처리 함수를 확인합니다. 기본 실행 코드에는 실제 위치 요청이 없습니다.

Geolocation API 콜백과 권한

navigator.geolocation.getCurrentPosition(success, error, options)는 위치 확인을 요청하는 실제 API 호출 형태입니다. 좌표를 즉시 반환하지 않고 성공·오류 콜백으로 결과를 처리합니다.

실제 API 사용에는 보안 컨텍스트와 사용자 권한·Permissions Policy 등의 조건이 적용됩니다. 성공 결과의 coords에서 위도·경도를 읽으며, 오류는 권한 거절·위치 사용 불가·시간 초과 등을 구분합니다.

모의 성공·거절·시간 초과

모의 성공 버튼은 coords.latitude와 coords.longitude가 있는 객체를 showPosition()에 전달합니다. 권한 거절과 시간 초과 버튼은 각각 code=1과 code=3인 객체를 showError()에 전달합니다.

출력 문자열이 입력 객체의 값과 오류 코드에 대응하는지 확인합니다. 이 검사는 결과 처리 함수의 검증이며 브라우저의 실제 권한 요청 절차 검증이 아닙니다.

모의 응답과 실제 위치 검증의 차이

모의 응답으로 실제 위치 정확도나 운영체제 권한·센서·네트워크 기반 위치 동작을 검증할 수는 없습니다. 실제 API 호출은 사용자에게 목적과 실패 후 대체 동작을 설명한 뒤 별도 조건에서 확인해야 합니다.

거절·사용 불가·시간 초과를 하나의 빈 화면으로 처리하지 않고 구분 가능한 상태를 제공합니다. 실제 위치가 필요하지 않은 기능에는 위치 요청을 추가할 필요가 없습니다.

비동기 응답과 Worker의 차이

Geolocation의 콜백은 비동기 결과 전달 방식입니다. 별도의 JavaScript 실행 문맥에서 계산을 수행하는 Worker와 같은 기능은 아닙니다.

다음 편에서는 메인 문서와 전용 Worker 사이의 메시지·데이터 전달을 다룹니다.
