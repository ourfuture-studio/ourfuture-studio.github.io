연결 파일 전체 코드

worker.js

self.onmessage = event => {
  const n = event.data;
  if (!Number.isInteger(n) || n < 1 || n > 1000000) throw new RangeError("입력 범위 오류");
  let sum = 0;
  for (let i = 1; i <= n; i++) sum += i;
  self.postMessage(sum);
};

직접 확인

입력 n을 10과 100000으로 바꾸어 실행하고 횟수 버튼도 누르세요.

예상 결과 · 합은 각각 55와 5000050000입니다. 화면 횟수는 별도 버튼 동작에 따라 증가합니다.

Worker 생성과 메시지 통신

new Worker("worker.js")로 전용 Worker를 만들고 postMessage(n)로 입력을 보냅니다. Worker는 message를 받아 계산하고 postMessage(sum)으로 결과를 보냅니다. 메인 문서는 받은 값을 DOM에 표시합니다. 일반적인 메시지는 구조화된 복제 방식으로 전달되며 Worker에는 document DOM이 없습니다.

Worker 비용·오류·종료

생성·메시지 전송 비용이 있어 작은 작업의 전체 시간은 오히려 늘 수 있습니다. 브라우저와 기기 조건 없이 배속을 주장하지 않습니다. 오류 시 안내하고 Worker를 종료합니다. 계산을 다른 문맥으로 옮긴 것과 계산 알고리즘 자체를 바꾼 것은 구분합니다.
