좌표와 도구를 가져옵니다

canvas에 width와 height 속성으로 그리기 영역을 정하고 getContext("2d")로 도구를 얻습니다. 기본 좌표의 원점은 왼쪽 위이며 x는 오른쪽, y는 아래쪽으로 증가합니다. fillRect(x, y, width, height)로 사각형을 채울 수 있습니다.

CSS 폭만 늘리면 더 많이 그릴까요

그리기 영역의 속성과 CSS 표시 크기는 다릅니다. CSS로 표시만 늘리면 비트맵이 확대되어 흐려질 수 있습니다. canvas 안에 그린 사각형을 querySelector로 각각 찾을 수는 없습니다. 해상도·기기 픽셀 비율까지 다루는 차트는 별도 설계가 필요합니다.
