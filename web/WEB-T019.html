가상 인원 데이터 시각화

예제는 canvas의 width=300, height=170으로 그리기 영역을 정합니다. 배열 [4, 7, 2]의 각 값을 20배 하여 사각형의 폭으로 사용합니다.

세 사각형의 폭은 80·140·40 좌표 단위입니다. 동일한 배열에서 HTML li 요소의 텍스트도 생성해 그래픽 외의 데이터 표현을 제공합니다.

Canvas 2D 컨텍스트와 좌표

canvas.getContext("2d")는 2D 렌더링 컨텍스트를 가져옵니다. 기본 좌표계의 원점은 왼쪽 위이고 x는 오른쪽, y는 아래쪽으로 증가합니다.

fillRect(x, y, width, height)는 지정한 위치와 크기로 사각형을 채웁니다. 예제는 x=30, y=15+index×50, width=value×20, height=25를 사용하며 fillStyle로 채우기 색을 설정합니다.

데이터와 막대 길이의 대응

배열의 두 번째 값을 7에서 5로 바꾸면 두 번째 사각형의 폭이 140에서 100으로 바뀝니다. 다른 항목과 배치 좌표는 유지됩니다.

HTML 목록도 같은 배열을 사용하므로 두 번째 항목의 텍스트에 5가 반영됩니다. 입력 데이터, 크기 계산식, 실제 그래픽과 텍스트 출력을 함께 비교합니다.

그리기 크기·표시 크기·DOM의 차이

canvas의 width·height 속성은 그리기 영역을, CSS width·height는 표시 크기를 설정합니다. 표시만 확대하면 비트맵이 확대되어 선명도가 달라질 수 있습니다.

canvas에 그린 각 사각형은 독립적인 HTML 요소가 아니므로 querySelector로 개별 사각형을 선택할 수 없습니다. 그래픽과 같은 정보를 DOM 텍스트로도 제공하고, 고해상도 표시가 필요하면 기기 픽셀 비율 등의 조건을 따로 설계합니다.

그래픽의 텍스트 대안

픽셀을 검사하면 특정 위치의 그리기 여부를 확인할 수 있지만 그것만으로 접근성이나 데이터 해석의 적합성을 보증하지 않습니다. 데이터 값과 텍스트 대안을 함께 유지합니다.
