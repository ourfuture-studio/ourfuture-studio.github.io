CSS 캐스케이드와 명시도.

CSS는 단순히 마지막 줄만 따르지 않습니다. 같은 출처·중요도·레이어 등의 조건에서 선택자의 명시도를 비교하고, 그것도 같으면 뒤 선언이 적용됩니다.

캐스케이드 비교 조건과 명시도

예제는 작성자 스타일의 보통 선언만 사용하며 !important, 인라인 선언, 레이어, 애니메이션·전환을 넣지 않습니다. 이 조건에서 클래스 선택자의 명시도는 요소 선택자보다 높으므로 .notice가 h1보다 우선합니다.

같은 .notice 선택자에 color를 두 번 적으면 앞 조건과 명시도가 같으므로 뒤 선언이 이깁니다. 실제 캐스케이드는 출처·중요도·레이어 등도 판단하므로 ‘아이디가 언제나 이긴다’ 같은 규칙으로 일반화하지 않습니다.

important와 상속의 적용 조건

!important를 계속 추가하면 이번 충돌의 원인을 설명하지 못한 채 다른 우선순위 문제를 만들 수 있습니다. 여기서는 어느 선택자가 어느 요소를 가리켰고 비교 조건이 무엇이었는지 말하는 것을 목표로 합니다.

상속도 모든 속성에서 똑같이 일어나지 않습니다. 부모의 글자색을 물려받는 경우를 보고 부모의 padding까지 자식에게 그대로 상속된다고 생각하지 않습니다.
