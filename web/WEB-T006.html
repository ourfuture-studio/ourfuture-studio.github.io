CSS 캐스케이드와 명시도.

CSS 캐스케이드는 같은 요소·속성에 적용되는 선언 중 사용할 값을 결정합니다. 예제와 같이 출처·중요도·레이어 조건이 같을 때에는 명시도를 비교하고, 명시도도 같으면 뒤 선언을 적용합니다.

CSS 규칙 충돌 예제

예제의 h1에는 class="notice"가 있습니다. .notice 선택자는 color:#7A1F2E를, h1 선택자는 color:#2F45D8을 선언하므로 두 규칙이 같은 요소의 color에 적용됩니다.

실습에서는 선언 순서와 선택자의 명시도를 각각 바꾸어 결과를 비교합니다. 다른 조건은 고정합니다.

캐스케이드 비교 조건과 명시도

예제는 작성자 스타일의 일반 선언만 사용하며 !important, 인라인 선언, 레이어, 애니메이션·전환을 포함하지 않습니다. 이 조건에서 클래스 선택자의 명시도는 요소 선택자보다 높으므로 .notice의 color가 적용됩니다.

선택자가 동일하고 다른 비교 조건도 같으면 나중에 선언한 값이 적용됩니다. 실제 캐스케이드에서는 출처·중요도·레이어 등도 판단하므로 명시도나 선언 순서 하나만으로 모든 경우를 설명하지 않습니다.

선언 순서와 명시도 비교

두 규칙의 순서만 바꾸어도 클래스 선택자가 우선하는지 확인합니다. 다음에는 h1 선택자를 .notice로 바꾸어 두 선택자의 명시도를 같게 합니다. 뒤쪽의 color:#2F45D8이 적용되어야 합니다.

개발자 도구에서 재정의된 선언의 취소선과 계산된 color를 비교합니다. 부모로부터 상속된 값과 해당 요소에 직접 적용된 선언도 구분합니다.

important와 상속의 적용 조건

!important는 캐스케이드의 중요도에 영향을 주므로 원인 분석 없이 반복해서 추가하면 규칙 관계를 파악하기 어려워집니다. 예제의 비교 조건을 유지한 상태에서 어느 선언이 선택되었는지 설명합니다.

상속 여부는 CSS 속성마다 다릅니다. color가 상속되는 예를 보고 padding도 같은 방식으로 자동 상속된다고 일반화하지 않습니다.

계산된 스타일 확인

스타일 문제는 스타일시트 로딩, 선택자 일치, 선언의 유효성, 캐스케이드, 계산된 값을 차례로 확인합니다. 문서의 원본 코드와 실제 계산값을 함께 봅니다.
