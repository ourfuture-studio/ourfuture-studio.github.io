CSS Flexbox와 반응형 배치.

Flexbox는 컨테이너 안의 flex item을 배치하는 CSS 레이아웃 방식입니다. flex-wrap, flex, gap과 요소의 최소 크기 조건을 함께 설정해 좁은 뷰포트에서의 줄바꿈을 제어합니다.

뷰포트 폭과 카드 배치

예제의 .courses 요소는 flex container이고, 그 자식 article 요소 세 개는 flex item입니다. article의 텍스트는 배치 결과를 구분하기 위한 예제 값입니다.

뷰포트 폭을 바꾸면서 항목의 폭과 줄바꿈을 확인합니다. 텍스트의 의미를 다른 개념으로 비유하지 않고 컨테이너·항목·크기·간격을 각각 확인합니다.

Flexbox 크기와 줄바꿈

컨테이너의 display:flex는 Flexbox 배치를 설정하고 flex-wrap:wrap은 여러 줄 배치를 허용합니다. gap은 항목 사이 간격을 지정합니다.

항목의 flex:1 1 200px는 flex-grow, flex-shrink, flex-basis를 순서대로 지정하는 단축 속성입니다. 예제는 200px를 기준 크기로 삼아 공간을 분배합니다. min-width:0은 내용에 따른 기본 최소 크기 제약을 줄이는 데 사용합니다. viewport 메타 설정은 모바일 레이아웃 뷰포트와 관련됩니다.

좁은 화면의 배치 확인

1280px와 390px 뷰포트에서 article 요소의 배치를 비교합니다. wrap에서는 항목이 필요한 경우 다음 줄로 이동합니다. nowrap으로 변경하면 한 줄을 유지하면서 축소하거나 조건에 따라 넘칠 수 있습니다.

한 줄에 배치되는 항목 수는 컨테이너의 실제 안쪽 폭, 기준 크기, gap과 항목의 크기 제약에 따라 결정됩니다. 문서 전체에 불필요한 가로 스크롤이 생기는지도 확인합니다.

뷰포트 검사와 실제 기기 검사의 범위

데스크톱 브라우저의 뷰포트 폭 변경은 레이아웃 검사입니다. 실제 모바일 기기의 터치·확대·글꼴·브라우저 UI까지 검증한 결과는 아닙니다.

시각적인 배치 순서와 DOM 순서가 달라지면 읽기·키보드 탐색 순서가 어긋날 수 있습니다. 이 예제는 DOM 순서를 유지하며, 긴 텍스트의 줄바꿈과 항목의 크기를 함께 확인합니다.

레이아웃과 입력 동작의 연결

HTML은 요소 구조를, CSS는 박스 크기와 배치를 지정합니다. 입력값에 따른 계산이나 조건 분기는 JavaScript로 작성합니다.

다음 편에서는 JavaScript 변수·자료형·조건문을 사용해 숫자 입력의 처리 결과를 구분합니다.
