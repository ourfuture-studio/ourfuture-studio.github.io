예상 결과 · 잘못된 경로에서는 그림을 읽지 못합니다. 올바른 경로로 복원하면 자체 제작 강의실 도식이 다시 나타납니다.

파일 이름보다 그림의 목적을 적습니다

img는 src로 지정한 리소스를 표시하며 alt는 문맥에 맞는 대체 텍스트를 제공합니다. ‘photo.png 이미지’처럼 파일 이름을 되풀이하기보다 무엇을 알아야 하는지 적습니다. 주변 문장에서 이미 같은 정보를 전달하는 순수 장식이라면 alt=""를 사용할 수 있습니다.

width와 height는 이미지의 크기 정보를 제공해 공간을 미리 잡는 데 도움이 됩니다. 반응형 CSS의 max-width:100%는 좁은 영역에서 이미지가 영역을 넘지 않게 하는 데 사용합니다. 대체 텍스트의 화면 표시와 보조기술의 읽기 방식은 동일하다고 단정하지 않습니다.

대체 설명은 길수록 좋을까요

같은 문장을 불필요하게 반복하거나 화면 구석의 장식까지 모두 설명하면 핵심 장소 안내가 묻힙니다. 복잡한 도표라면 짧은 alt 외에 인접한 본문·표로 자세한 정보를 제공해야 합니다.

이번 그림의 목적은 장소를 알리는 것이므로 위치를 먼저 씁니다. 이미지 파일을 못 찾는 오류 자체는 경로를 고쳐 해결해야 하며 alt를 적는 것만으로 정상 로딩이 되는 것은 아닙니다.
