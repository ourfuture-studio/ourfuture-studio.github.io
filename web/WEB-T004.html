이미지의 목적과 대체 텍스트

예제의 img는 room.svg를 표시합니다. 이 SVG는 실습용으로 작성한 도식이며, 위치 정보를 전달하는 이미지의 예로 사용합니다. alt에는 ‘웹 기초 수업 장소: 2층 201호’라는 대체 텍스트를 지정합니다.

문서의 img 요소, 외부 이미지 파일, 대체 텍스트라는 세 대상을 구분합니다. 대체 텍스트는 파일을 설명하는 메모가 아니라 해당 문맥에서 이미지가 제공하는 정보의 대안입니다.

img의 src·alt·크기 속성

src="room.svg"는 기준 URL을 바탕으로 이미지 파일을 요청합니다. alt는 이미지를 사용할 수 없거나 이미지 대신 텍스트가 필요한 경우에 제공할 대체 내용을 지정합니다. 주변 텍스트와 같은 정보만 반복하는 순수 장식 이미지에는 alt=""를 사용할 수 있습니다.

width와 height는 HTML 속성으로 이미지 크기 정보를 제공합니다. max-width:100%와 height:auto는 CSS 속성으로 표시 영역에 맞게 크기를 조정합니다. HTML 속성과 CSS 속성을 같은 종류의 표기로 혼동하지 않습니다.

이미지 경로 오류와 복원

index.html과 room.svg를 같은 폴더에 두고 img가 정상적으로 로드되는지 확인합니다. src만 missing.svg로 바꾸면 이미지 요청이 실패하며, 다시 room.svg로 지정하면 정상 경로로 복원됩니다.

이 과정에서 alt 속성값은 유지합니다. 개발자 도구에서는 요소의 src·alt 속성과 이미지 요청 상태를 각각 확인할 수 있습니다.

장식 이미지와 정보 이미지의 구분

이미지 로딩 실패 시 표시 방식은 브라우저와 스타일 조건에 따라 달라질 수 있습니다. 화면에 나타나는 대체 표시와 스크린리더가 접근성 정보를 읽는 방식을 동일하게 취급하지 않습니다.

alt를 지정해도 잘못된 src가 복구되지는 않습니다. 복잡한 도표의 정보는 짧은 alt만으로 충분하지 않을 수 있으므로 본문이나 표로도 제공합니다. 이미지의 목적에 맞춰 대체 정보를 작성합니다.

이미지와 본문의 정보 구성

리소스 URL은 로딩 대상을, alt는 대체 정보를, 크기 속성과 CSS는 공간과 표시 크기를 각각 다룹니다. 한 속성으로 이 역할을 모두 해결하려고 하지 않습니다.
