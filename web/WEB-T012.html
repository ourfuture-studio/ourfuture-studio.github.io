HTML 폼 작성 예제

예제의 form에는 input, select, button 요소가 있습니다. input의 name은 student이고, select의 name은 course입니다. ‘연습생’과 web·css는 입력값을 구분하기 위한 예제 문자열입니다.

이 편의 button은 type="button"이므로 기본 폼 제출을 실행하지 않습니다. 폼 요소의 구성과 제출 이벤트 처리는 별도 단계로 다룹니다.

label·id·name·value

label의 for 속성값과 입력 요소의 id 속성값을 일치시키면 명시적으로 연결됩니다. id는 요소 식별자이고 name은 폼 데이터의 키이므로 두 속성을 같은 기능으로 취급하지 않습니다.

input의 value 속성은 초기값을 지정하며, 실행 중 현재 입력값은 DOM의 value 프로퍼티로 읽습니다. select에서는 option의 표시 텍스트와 value 속성값을 다르게 설정할 수 있습니다. 폼 데이터에 포함되는지는 name·disabled 등의 조건에 따라 달라집니다.

입력 초점과 선택값

이름 label을 눌러 연결된 input으로 초점이 이동하는지 확인합니다. select에서 ‘CSS 기초’를 선택하면 표시 텍스트는 그 문자열이고 현재 값은 css입니다.

Tab으로 컨트롤을 이동해 키보드로도 접근할 수 있는지 확인합니다. type="button"인 버튼을 눌러도 기본 제출 요청은 발생하지 않습니다.

placeholder와 입력 검증의 한계

placeholder 속성은 입력 전 힌트이며 지속적인 입력 이름을 대신하지 않습니다. 입력 이름은 label로 제공합니다. required는 브라우저의 제약 검증에 사용하지만 서버의 입력 검증을 대신하지 못합니다.

HTML 속성으로 지정한 초기값과 사용자가 수정한 현재 DOM 값이 다를 수 있습니다. 실제 데이터를 처리할 때에는 어느 값을 읽는지 명확히 해야 합니다.

폼 요소와 DOM 접근

HTML은 입력 컨트롤의 구조·이름·초기값을 지정합니다. 현재 값을 읽고 화면을 변경하는 처리는 JavaScript와 DOM API로 작성합니다.
