예상 결과 · 정상 요청은 강좌 이름을 표시하고 없는 파일은 HTTP 404 안내를 표시합니다.

요청과 응답의 단위를 봅니다

fetch("courses.json")은 이 문서의 기준 URL에서 요청을 시작합니다. 응답의 status는 HTTP 상태 코드이고 ok는 200~299 범위인지 나타냅니다. await response.json()으로 본문을 해석할 수 있습니다. HTTP 404 응답은 fetch의 네트워크 실패와 다르므로 ok를 직접 검사합니다.

200이면 데이터도 언제나 맞을까요

성공 상태여도 JSON이 아니면 해석에 실패할 수 있고, JSON이어도 필요한 필드가 없을 수 있습니다. 예제는 배열과 title 문자열을 검사합니다. 전송 성공, 형식 해석, 업무 데이터의 적합성은 다른 단계입니다.
