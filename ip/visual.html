A → B → C 순서로 넣었습니다. 한 번 꺼내기를 누르면 스택은 C, 큐는 A를 먼저 꺼냅니다. 두 구조에 같은 값을 더 넣어 순서를 비교하세요.

이진 트리 순회 (Binary Tree Traversal)

왼쪽과 오른쪽 자식을 구분한 뒤, 현재 노드를 결과에 적는 시점을 선택합니다. 색칠되는 노드와 결과 순서를 한 단계씩 따라가세요.

적용 규칙

왼쪽 → 현재 → 오른쪽

0 / 4개 노드

결과에 적은 순서

트리를 준비하고 있습니다.

기존 이론의 중위 결과: B → D → A → C

B의 왼쪽이 비어 있으므로 B를 먼저 적고, B의 오른쪽 D를 적은 뒤 부모 A로 돌아옵니다. 각 서브트리(Subtree)에도 같은 규칙을 적용합니다. N은 현재 노드(Node), L은 왼쪽 서브트리(Left Subtree), R은 오른쪽 서브트리(Right Subtree)를 뜻합니다.

일반 이진 트리(Binary Tree)의 중위 순회가 항상 정렬된 결과를 만드는 것은 아닙니다. 그 성질에는 이진 탐색 트리(Binary Search Tree)의 키 배치 조건이 필요합니다.

페이지 교체 (Page Replacement)

같은 참조열(Reference String)을 FIFO와 LRU로 나란히 처리합니다. 기본 참조열에서 세 번째 참조1의 적중 뒤 기록이 어떻게 달라지는지 보세요. 첫 적재도 페이지 부재(Page Fault)에 포함합니다.

0 / 6회 참조

F = 페이지 부재(Page Fault) · H = 적중(Hit)

페이지 상태를 준비하고 있습니다.

FIFO는 적중 때 적재 순서를 바꾸지 않고, LRU는 최근 사용 기록을 바꿉니다.

FIFO(First-In, First-Out)는 가장 먼저 적재한 페이지, LRU(Least Recently Used)는 가장 오래 사용하지 않은 페이지를 교체합니다. 빈 프레임이 있으면 교체보다 먼저 사용합니다. 기본 참조열·프레임2개에서는 FIFO5회/LRU4회 부재지만, 이 한 결과로 어느 정책이 항상 더 낫다고 결론 내리지 않습니다.

‘프레임 수 비교’ 참조열에서 FIFO의 프레임3개와4개를 비교하면 부재가9회에서10회로 늘어나는 벨라디의 모순(Belady’s Anomaly)을 확인할 수 있습니다. 모든 참조열에서 발생한다는 뜻은 아닙니다.

04 · 비트 경계가 주소 범위를 정합니다

IPv4 서브넷 (IPv4 Subnet)

/27은 주소 32비트 중 앞 27비트가 네트워크 부분이라는 뜻입니다. 프리픽스(Prefix)를 바꾸면 색으로 구분한 비트 경계, 서브넷 마스크(Subnet Mask), 주소 범위가 함께 바뀝니다.

서브넷 마스크 (Subnet Mask)255.255.255.224
호스트 비트 (Host Bits)5
전체 주소 수 (Address Count)32
일반 호스트 수 (Usable Hosts)30

왜 두 주소를 빼나요? · 적용 조건

일반적인 IPv4 브로드캐스트 서브넷에서는 네트워크 주소와 브로드캐스트 주소를 호스트 할당에서 제외합니다. 이 체험은 /8~ /30 범위를 비교합니다. /31 점대점 링크(Point-to-Point Link)의 특례와 /32 단일 주소에 이 공식을 그대로 적용하지 않습니다. 수학적으로 계산한 범위가 실제 네트워크에서 할당 가능한 범위라는 뜻은 아닙니다. 외부 네트워크에 접속하지 않는 교육용 계산입니다.
