행을 나누는 분할과 사본을 두는 복제

관련 문제 1개조건 바꿔 체험

서로 다른 조각을 두는 것과 같은 자료를 여러 번 두는 것은 배치 목적이 다르다.

핵심 이론

수평 분할(horizontal partitioning)은 하나의 관계를 행 기준으로 여러 부분에 나누는 방식이다. 각 행이 한 분할에만 속하는 조건이면 부분들의 합집합으로 원래 관계를 재구성할 수 있다.

복제(replication)는 같은 행 또는 같은 분할의 사본을 여러 노드에 둔다. 특정 노드 장애에 대비하거나 가까운 사본에서 읽을 수 있지만, 갱신이 여러 사본에 반영되는 방식과 읽는 시점의 일관성을 정해야 한다.

분할과 복제를 함께 쓸 수도 있다. 논리 행 네 개를 두 분할로 나눈 뒤 각 분할을 두 번 복제하면 저장되는 행 사본은 여덟 개다. 저장 사본 수와 최신 상태 보장, 실제 조회 속도는 서로 다른 판단이다.

작은 예제로 확인하기

원본 R의 기본키 id는 1, 2, 3, 4다. N1에는 1, 2만, N2에는 3, 4만 저장한다. 숨은 사본은 없고 분할이 겹치지 않는다.

노드 id 행
N1 1, 2
N2 3, 4

원본 id1~4를 서로 다른 두 부분에 한 번씩 둔 배치는 수평 분할이며 완전 복제는 아니다.

다시 떠올릴 단서

논리 행을 나누었는지 같은 행 사본을 늘렸는지 따로 센다.

적용 범위

명시한 노드별 행 집합의 배치를 계산한다. 실제 분산 DB 구축·복제 장애·최신 값 보장·성능 측정을 실행한 것은 아니다.
