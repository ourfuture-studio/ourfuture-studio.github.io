UNION ALL은 반복 행도 보존한다

관련 문제 1개조건 바꿔 체험

합친 결과에서 중복을 지울지는 ALL 유무가 결정한다.

핵심 이론

UNION은 두 질의의 결과를 합치고 결과 행 전체가 같은 중복을 제거한다. UNION ALL은 중복을 유지하며, 한 입력 내부에 이미 있던 반복도 보존한다.

집합 연산의 두 질의는 같은 수의 열을 반환하고 대응 열의 자료형이 호환되어야 한다. 중복 판단은 특정 키 열만이 아니라 선택된 모든 열의 조합으로 한다.

UNION을 썼다고 출력 순서를 약속하지 않는다. 시험에서 순서가 답에 영향을 주면 최종 ORDER BY가 필요하다. 중복 제거 비용이 있을 수 있지만 작은 예제의 행 수만으로 두 명령의 실제 시간을 단정하지 않는다.

작은 예제로 확인하기

L은 2,2,4의 세 행, R은 4,5의 두 행이다. 값은 정수·NOT NULL이며 질의는 value 한 열만 반환한다.

입력 value
L 2,2,4
R 4,5

UNION 결과는 {2,4,5}의 세 행이고 UNION ALL은 2,2,4,4,5의 다섯 행이다.

다시 떠올릴 단서

입력 내부 중복과 입력 사이 중복을 모두 추적하고 ALL 유무를 확인한다.

적용 범위

명시한 작은 예제의 조건에서 판단한다. 다른 DBMS의 실행 결과나 실제 성능 측정으로 일반화하지 않는다.
