문자열의 같은 내용과 같은 참조

관련 문제 1개조건 바꿔 체험

==는 같은 객체인지, String.equals는 같은 문자열 내용인지 묻는다.

핵심 이론

참조형의 ==는 두 참조가 같은 객체를 가리키는지 비교한다. new String("sun")을 두 번 실행하면 내용이 같아도 서로 다른 객체를 생성한다.

String.equals(Object)는 상대가 String이고 같은 문자 시퀀스인지 비교한다. 따라서 별도 생성한 같은 문자열은 ==가 false이고 equals가 true일 수 있다.

문자열 리터럴 공유로 ==가 true인 사례를 보고 내용 비교에 ==를 일반화하면 안 된다. String은 불변이므로 객체 자체의 내용을 대입으로 바꾸는 것이 아니라 새 문자열을 참조하도록 변수를 바꾼다. null 수신자에서 equals를 호출하면 예외가 발생하므로 이 문제에서는 null을 제외한다.

작은 예제로 확인하기

Java SE 17, Main.java로 저장. java.lang은 자동 import하며 외부 입력·다중 스레드·사용자 정의 예외 처리 없음. a와 b를 각각 new String("sun")으로 생성한다.

조건 또는 단계 판단 또는 값
new String("sun") 두 개 == false
위 두 객체 equals true
두 변수에 같은 참조 대입 == true

new를 명시해 우연한 문자열 풀 공유를 정답 조건에서 제거한다.

다시 떠올릴 단서

String 내용 비교와 참조 동일성 검사를 구별한다.

적용 범위

모든 참조는 null이 아니며 대소문자·로캘 변환을 하지 않는다.
