정적 분석과 실행 관찰

관련 문제 1개조건 바꿔 체험

프로그램을 실행했는지에 따라 확인한 근거가 달라진다.

핵심 이론

정적 분석은 대상 프로그램을 실행하지 않고 코드 등의 구조를 도구로 검사한다. 동적 테스트는 실행한 결과를 기대 결과와 비교한다.

도구가 코드를 읽어 도달 불가능한 부분을 보고한 것과 실행 중 응답 시간이 기준을 넘은 것은 서로 다른 관찰이다.

정적 분석기가 모든 결함을 찾거나 한 실행이 모든 경로를 확인한다고 보장하지 않는다. 분석 규칙·실행 입력·환경의 범위를 기록한다.

작은 예제로 확인하기

도구 P는 소스 코드를 구문 분석하고 제어 흐름을 계산해 도달 불가능한 문장 한 곳을 보고했다. 대상 프로그램은 실행하지 않았다. 도구 Q는 실제 입력으로 실행해 응답 시간 4초를 측정했다.

조건 판단과 결과
P=소스/제어 흐름 분석, 대상 실행 없음; Q=대상 실행, 응답4초 측정. P 정적, Q 동적
대상 프로그램 실행 없음; 사람이 요구 문서의 모순 두 곳을 검토해 기록; 자동 분석 도구는 사용하지 않음. 정적 테스트의 리뷰
코드 구조 분석 없음; 대상 프로그램에 입력10을 넣어 결과20과 기대20을 비교. 동적 테스트

P는 코드를 분석했지만 실행하지 않았다. Q는 실제로 실행해 시간 결과를 얻었으므로 각각 정적 분석과 동적 테스트다.

다시 떠올릴 단서

검사 도구가 아니라 시험 대상이 실행됐는지 확인한다.

적용 범위

특정 분석기의 탐지 정확도나 실제 응답 성능을 측정한 기록은 아니다.
