예외 처리와 작업 성공은 별도 상태

관련 문제 1개조건 바꿔 체험

예외(exception)를 잡은 뒤 실행이 이어졌다는 사실만으로 변환이나 저장이 성공한 것은 아니다.

핵심 이론

예외는 정상 계산을 중단하고 처리기나 호출자로 제어를 옮기는 신호이다. try 안 int("bad")는 정수 변환 결과를 만들지 못하고 ValueError를 발생시킨다.

except ValueError가 이 예외를 잡으면 프로그램은 뒤 문장을 실행할 수 있다. 그러나 변환 작업은 실패했으므로 성공 여부를 나타내는 ok는 False로 유지하고 결과 number를 None으로 표시할 수 있다.

처리기에서 무조건 성공을 출력하면 실패 상태를 감춘다. 복구·재시도·실패 반환 중 어떤 정책인지 정해야 한다. except의 예외형과 다른 예외는 그 처리기로 잡히지 않는다는 조건도 확인한다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. text="bad"; ok는 변환 성공 직후에만 True로 설정한다.

조건 또는 단계 판단 또는 값
text="bad" int 변환 ValueError
except ValueError 실행 재개 가능
ok / number False / None

제어 흐름이 살아 있다는 상태와 업무의 결과값이 있다는 상태를 분리한다.

다시 떠올릴 단서

예외를 잡았는지와 업무 성공 조건을 만족했는지를 각각 검사한다.
