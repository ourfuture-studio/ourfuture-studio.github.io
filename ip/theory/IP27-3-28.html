OSI 계층은 장치 이름보다 기능으로 판단

관련 문제 2개조건 바꿔 체험

한 제품이 여러 계층의 기능을 수행할 수 있으므로 관찰한 동작을 기준으로 분류한다.

핵심 이론

핵심 용어: 개방형 시스템 상호 연결 참조 모델(OSI, Open Systems Interconnection).

OSI 기본 참조 모형은 통신 기능을 응용·표현·세션·전송·네트워크·데이터링크·물리의 일곱 계층으로 설명한다. 계층 이름은 기능의 구분이며 제품 상자의 종류를 일대일로 고정하는 표가 아니다.

네트워크 계층은 여러 망을 지나는 경로와 중계를 다룬다. 데이터링크 계층은 연결된 매체 구간의 프레임 전달을 다루고, 물리 계층은 비트 표현과 물리 신호 전달을 다룬다.

예컨대 하나의 장비가 링크 프레임 중계와 IP 경로 선택을 함께 수행할 수 있다. 이때 제품 이름만 보고 기능 하나를 고정하지 않는다. 인터넷 프로토콜군과 OSI 모형은 동일한 계층 수로 구현되어야 하는 관계도 아니다.

OSI 일곱 계층을 기능과 단위로 읽기

계층 설명할 기능 대표 데이터 단위·식별자 학습용 프로토콜·장비 예
7 응용(Application) 응용이 이용하는 통신 기능 응용 데이터·메시지 HTTP, DNS
6 표현(Presentation) 자료 표현·인코딩·변환 표현된 데이터 문자 인코딩·압축
5 세션(Session) 대화·동기화 관리 세션 데이터 대화 제어·동기점
4 전송(Transport) 종단 간 전달·포트 다중화 TCP 세그먼트·UDP 데이터그램, 포트 TCP, UDP
3 네트워크(Network) 여러 망을 지나는 전달·경로 패킷, IP 주소 IP, 라우터
2 데이터링크(Data Link) 연결된 링크 구간의 전달 프레임, MAC 주소 Ethernet, 브리지·L2 스위치
1 물리(Physical) 비트의 물리 신호 전송 비트·신호 케이블, 허브·리피터

TCP와 UDP의 보장 범위는 같지 않으므로 전송 계층 전체를 “신뢰성 보장”으로 외우지 않는다. 이것은 OSI 기능과 인터넷 프로토콜의 학습용 대응 예이며, 실제 제품 하나가 여러 계층 기능을 함께 수행할 수 있다. TLS 같은 실제 프로토콜을 OSI의 한 칸에 고정시키지 않는다.
