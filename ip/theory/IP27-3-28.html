OSI 계층은 장치 이름보다 기능으로 판단

관련 문제 1개조건 바꿔 체험

한 제품이 여러 계층의 기능을 수행할 수 있으므로 관찰한 동작을 기준으로 분류한다.

핵심 이론

OSI 기본 참조 모형은 통신 기능을 응용·표현·세션·전송·네트워크·데이터링크·물리의 일곱 계층으로 설명한다. 계층 이름은 기능의 구분이며 제품 상자의 종류를 일대일로 고정하는 표가 아니다.

네트워크 계층은 여러 망을 지나는 경로와 중계를 다룬다. 데이터링크 계층은 연결된 매체 구간의 프레임 전달을 다루고, 물리 계층은 비트 표현과 물리 신호 전달을 다룬다.

예컨대 하나의 장비가 링크 프레임 중계와 IP 경로 선택을 함께 수행할 수 있다. 이때 제품 이름만 보고 기능 하나를 고정하지 않는다. 인터넷 프로토콜군과 OSI 모형은 동일한 계층 수로 구현되어야 하는 관계도 아니다.

작은 예제로 확인하기

어떤 복합 통신 장치가 목적지 IP 프리픽스를 비교해 다른 네트워크로 보낼 다음 홉을 고른다. 제품 이름이 아니라 이 동작만 분류한다.

조건 또는 단계 판단 또는 값
목적지IP로 다음홉 선택 네트워크계층 기능
링크주소로 같은LAN 프레임전달 데이터링크계층 기능
비트를 전기·광 신호로 전송 물리계층 기능

같은 장치라는 조건은 유지하고 수행 기능만 바꾸어 분류한다.

다시 떠올릴 단서

어떤 주소·데이터 단위·전달 범위로 판단하는지 먼저 본다.

적용 범위

OSI X.200의 기능 분류를 학습용 동작에 대응한다. 특정 복합 제품의 모든 기능을 한 계층이라고 단정하지 않는다.
