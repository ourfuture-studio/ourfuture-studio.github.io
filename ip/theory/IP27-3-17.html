핵심 이론

유효 범위(scope)는 어떤 코드 위치에서 이름을 찾을 수 있는가의 문제이다. Python 함수 안에 대입된 지역 이름 items는 보통 함수 바깥에서 그 이름으로 접근할 수 없다.

함수가 지역 리스트를 return하면 반환된 객체를 호출자가 다른 이름으로 참조할 수 있다. 함수 지역 이름의 사용 범위가 끝났다고 그 객체의 사용도 끝난 것은 아니다.

객체를 더 이상 참조하지 않는 시점과 메모리가 실제 회수되는 시점도 같은 뜻은 아니다. 구현별 수거 시점이나 참조 카운트 값을 이 문제의 정답으로 삼지 않는다. C의 지역 자동 객체 주소를 반환하는 상황은 Python 리스트 반환과 별도 규칙이다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. make가 items=[3]을 만들어 반환하고 saved에 저장한다.

조건 또는 단계 판단 또는 값
make 안 items=[3] 지역 이름
saved=make() 호출자가 반환 객체 참조
saved.append(7) 객체를 계속 수정·관찰 가능

지역 이름과 반환된 리스트 객체를 서로 다른 대상으로 추적한다.
