관계대수의 선택은 행, 투영은 속성을 고른다

관련 문제 1개조건 바꿔 체험

SQL의 SELECT라는 단어와 관계대수의 선택 연산을 같은 뜻으로 읽지 않도록 결과를 그려 보자.

핵심 이론

관계대수의 선택 σ는 조건을 만족하는 튜플, 즉 행을 남기는 연산이다. σ score≥7(R)은 점수 7 이상의 행을 남기며 이 선택만으로 열 수를 줄이지 않는다.

투영 π는 남길 속성을 지정한다. π dept는 dept 열만 남긴다. 고전적인 관계대수는 관계를 집합으로 다루므로 같은 결과 튜플이 생기면 하나로 합쳐진다.

관계의 차수는 속성 수이고 카디널리티는 튜플 수다. SQL은 보통 중복을 보존하므로 고전적 투영을 재현할 때 SELECT DISTINCT가 필요하다. 관계대수의 집합에는 본래 행 순서가 없고, 아래 SQL의 ORDER BY는 관찰 결과를 정리하는 용도다.

작은 예제로 확인하기

NULL 없는 집합 관계 R(id,dept,score)는 (1,A,7),(2,A,9),(3,B,4)다. 고전 관계대수의 집합 의미로 π dept(σ score≥7(R))을 계산한다. 아래 SQL은 DISTINCT로 그 결과를 재현한다.

id dept score
1 A 7
2 A 9
3 B 4

먼저 score≥7로 id1·2를 남긴 뒤 dept만 투영하면 A·A가 같은 튜플이어서 {A} 한 개가 된다. 차수1·카디널리티1이다.

다시 떠올릴 단서

선택할 행과 투영할 속성을 정하고 집합 의미의 중복 제거를 적용한다.

적용 범위

명시한 작은 예제의 조건에서 판단한다. 다른 DBMS의 실행 결과나 실제 성능 측정으로 일반화하지 않는다.
