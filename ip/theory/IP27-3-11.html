참조를 복사한 뒤 수정과 재대입

관련 문제 1개조건 바꿔 체험

같은 객체를 가리키는 두 변수는 객체 수정을 공유한다. 변수 하나의 재대입은 다른 변수를 옮기지 않는다.

핵심 이론

Java의 Box b=a는 객체 전체를 복사하지 않고 참조값을 복사한다. 따라서 a와 b가 같은 Box를 가리키면 b.n에 쓴 값은 a.n으로도 관찰된다.

b=new Box(8)은 b의 참조값을 새 객체로 바꾼다. a는 기존 객체를 계속 가리키므로 이후 b.n을 바꾸어도 a.n은 바뀌지 않는다.

별도 객체를 생성한 것과 깊은 복사는 다르다. Box가 중첩 객체 필드를 가진다면 생성자와 복사 코드가 어떤 내부 참조를 공유하는지도 확인해야 한다. 여기서는 int 필드 하나만 사용한다.

작은 예제로 확인하기

Java SE 17, Main.java로 저장. java.lang은 자동 import하며 외부 입력·다중 스레드·사용자 정의 예외 처리 없음. a=new Box(2); b=a; b.n=7.

조건 또는 단계 판단 또는 값
a=Box(2), b=a 동일 객체
b.n=7 a.n도7
이후 b=Box(8) a는7, b는8

객체에 붙인 화살표와 변수의 화살표를 구분해 그리면 두 조작이 분리된다.

다시 떠올릴 단서

필드 대입은 대상 객체를, 변수 재대입은 그 변수의 참조를 바꾼다.

적용 범위

단일 스레드, null 없음, int 필드 하나인 객체만 다룬다.
