일반 변수와 자식 프로세스 환경

관련 문제 1개조건 바꿔 체험

PowerShell의 일반 변수와 Env: 환경변수는 자식 프로그램에 같은 방식으로 전달되지 않는다.

핵심 이론

환경변수는 프로세스 환경에 저장되는 문자열이다. PowerShell에서 $env:IP27_DEMO로 접근한다. 일반 변수 $IP27_LOCAL은 현재 PowerShell 세션의 변수이며 자동으로 자식 프로그램의 같은 이름 변수로 복제되지 않는다.

새 자식 프로세스는 생성 시점의 부모 환경을 상속받는다. 부모가 환경변수를 먼저 green으로 설정하면 자식에서 green을 읽을 수 있다. 여기서는 -NoProfile로 프로필 초기화의 영향을 제거한다.

자식이 자기 환경을 바꿔도 부모의 환경을 거꾸로 바꾸지 않는다. Process 범위의 수정과 사용자·시스템 영구 설정은 별도이다. 아래 실험은 새로 시작한 프로세스 안의 임시 환경만 바꾼다.

작은 예제로 확인하기

PowerShell 7에서 아래 스크립트를 독립 프로세스로 실행한다. 부모 일반변수 violet, 환경변수 green을 설정한 뒤 새 pwsh -NoProfile을 실행한다.

조건 또는 단계 판단 또는 값
부모 $IP27_LOCAL violet, 일반 변수
부모 $env:IP27_DEMO green, 프로세스 환경
자식 일반 변수 없음 / 환경값 true / green

자식에서 일반 변수가 null인지와 환경 문자열을 각각 출력해 전달 경계를 확인한다.

다시 떠올릴 단서

자식 생성 시 환경은 상속되지만 일반 세션 변수는 자동 전달되지 않는다.

적용 범위

Windows PowerShell이 아닌 PowerShell 7 계열 pwsh, -NoProfile, 독립 새 자식 프로세스. 프로필·영구 사용자/시스템 환경 변경 없음.
