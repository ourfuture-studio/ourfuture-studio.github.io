문자열 길이와 배열 용량을 구분하기

관련 문제 1개조건 바꿔 체험

strlen은 첫 널 문자 앞까지 센다. sizeof 배열은 종료 문자와 여유 공간도 포함한다.

핵심 이론

C 문자열은 첫 널 문자 \0으로 끝나는 문자 시퀀스이다. strlen은 널 문자를 제외한 앞부분의 바이트 수를 반환한다. char s[]="SUN"은 S,U,N,\0 네 char 원소를 가진다.

sizeof s는 s가 실제 배열일 때 전체 저장 크기이다. char의 sizeof는 1이므로 char s[8]="SUN"의 크기는 8이고 strlen은 3이다. 나머지 원소는 0으로 초기화된다.

배열 안에 중간 널 문자가 있으면 strlen은 그 자리에서 멈춘다. 종료 널 문자가 없는 배열을 strlen에 넘기는 동작은 안전하지 않다. 한글 같은 멀티바이트 문자에서는 strlen을 사람이 읽는 글자 수와 동일시하지 않는다.

작은 예제로 확인하기

C11 의미 규칙(N1570), signed int이며 아래 작은 값에서 범위 초과 없음. 각 코드는 표준 헤더와 main을 포함한 독립 프로그램이고 입력 없음. 0으로 나누지 않는다. #include <string.h>; char s[]="SUN".

조건 또는 단계 판단 또는 값
char s[]="SUN" 길이3, 저장크기4
char s[8]="SUN" 길이3, 저장크기8
널 문자 길이에 제외, 저장에는 포함

영문 기본 문자만 사용해 문자 수와 인코딩 바이트 수의 차이를 이 예제에서 제거했다.

다시 떠올릴 단서

strlen은 첫 널 앞까지, sizeof 실제 배열은 전체 공간까지 센다.

적용 범위

널 종료가 보장된 기본 실행 문자 집합의 문자만 사용한다.
