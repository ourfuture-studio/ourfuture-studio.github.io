SQL 명령이 바꾸는 대상을 구별하기

관련 문제 1개조건 바꿔 체험

열 구조, 행의 값, 접근 권한은 서로 다른 변경 대상이다.

핵심 이론

DDL은 테이블 같은 데이터 구조를 정의하거나 제거하는 명령을 가리킨다. CREATE TABLE과 ALTER TABLE은 저장할 열과 제약을 바꾸는 예다.

DML은 행 데이터를 삽입·변경·삭제하거나 조회하는 데 사용한다. UPDATE가 고객 이름 값을 바꾸는 것과 ALTER TABLE이 이름 열의 구조를 바꾸는 것은 대상이 다르다. 교육 체계에 따라 SELECT를 DQL로 따로 분류하기도 하므로 여기서는 UPDATE만 비교한다.

DCL은 권한을 부여·회수하는 GRANT와 REVOKE 같은 제어를 뜻한다. PostgreSQL에서 권한의 실제 유무는 소유권·역할 상속·다른 부여 경로도 확인해야 한다. 여기서는 명령의 직접 목적만 묻고 한 번의 REVOKE로 모든 경로가 사라진다고 주장하지 않는다.

작은 예제로 확인하기

PostgreSQL 18 명세 사례다. Member는 존재하고 실행자에게 필요한 권한이 있으며 reader 역할도 존재한다. 실제 서버에서 실행한 사례가 아니다.

명령 직접 변경 대상
CREATE TABLE Member(id integer) 구조
UPDATE Member SET id=8 WHERE id=7 행 값
REVOKE SELECT ON Member FROM reader 권한 부여 경로

REVOKE는 테이블의 행이나 열을 지우는 명령이 아니라 지정된 접근 권한을 회수한다.

다시 떠올릴 단서

명령이 구조, 행 값, 권한 중 무엇을 직접 바꾸는지 확인한다.

적용 범위

PostgreSQL 18 공식 명세에 따른 명령 목적 분류다. SQLite에는 같은 역할·GRANT/REVOKE 체계가 없으므로 실행 검증으로 표시하지 않는다.
