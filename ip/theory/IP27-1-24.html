기능 정답과 변경·환경 적응의 품질

관련 문제 1개조건 바꿔 체험

같은 계산 결과를 내더라도 수정과 실행 환경의 조건은 다를 수 있다.

핵심 이론

제품 품질은 기능의 정확성 한 가지로만 평가하지 않는다. 유지보수성은 수정 가능성, 이식성은 다른 환경으로 옮길 때의 적응과 관련된 관점이다.

이 예제는 세율 변경에 손댈 위치와 운영체제별 실행 여부를 따로 측정한다. 두 프로그램의 기능 결과가 같아도 이 값들은 다를 수 있다.

품질 모델은 판본마다 특성과 묶음이 달라진다. ISO/IEC 25010:2011과 2023을 같은 목록으로 취급하지 않으며 여기서는 관찰한 두 지표만 비교한다.

작은 예제로 확인하기

자체 평가에서 A와 B는 10개 금액 계산 시험에 모두 통과했다. 동일한 세율 수정에 A는 1개, B는 8개 코드 위치를 바꾼다. A는 Windows/Linux에서 실행되고 B는 Windows에서만 실행된다. 다른 지표는 측정하지 않았다.

조건 판단과 결과
A/B 기능=10/10; 동일 세율 수정 위치 A1/B8; 실행 A Windows·Linux, B Windows만; 나머지 미측정. 기능 동일, 수정 범위·실행 환경 다름
A/B 기능=10/10; 동일 세율 수정 위치 A1/B1; 실행 A Windows·Linux, B Windows만; 나머지 미측정. 실행 환경 관찰만 다름
A/B 기능=10/10; 동일 세율 수정 위치 A1/B1; 둘 다 Windows·Linux 실행; 나머지 미측정. 측정한 세 지표에서 동일

기능 시험 결과는 10/10으로 같지만 변경 위치는 1 대 8, 확인된 실행 환경은 2종 대 1종이다. 전체 품질 우열 대신 이 차이까지만 말할 수 있다.

다시 떠올릴 단서

통과한 기능과 별도로 변경·환경 조건을 비교한다.

적용 범위

코드 위치 수 하나가 유지보수성 전체를 대표하지 않는다. 판본별 품질 특성 암기표를 대신하지 않는다.

근거와 확인 범위

  • IEEE Computer Society SWEBOK Guide v4.0a — 3장 6.2 Quality Attributes; 7장 2.1.4 Maintainability. 확인일 2026-10-31.
  • ISO/IEC 25010:2011 공개 소개 — 공개 소개: 2011판 철회 및 후속 2023판 연결. 확인일 2026-10-31.
  • ISO/IEC 25010:2023 공개 소개 — 공개 소개: 2023판 제품 품질 모델은 9개 특성; 세부 유료 본문 전체 열람 아님. 확인일 2026-10-31.
