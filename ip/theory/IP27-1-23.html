설치 작업과 사용 작업의 매뉴얼

관련 문제 1개조건 바꿔 체험

문서를 읽을 사람과 완료하려는 작업을 먼저 정한다.

핵심 이론

설치 매뉴얼은 운영 환경을 준비하고 설치·초기 설정·설치 확인을 수행하도록 안내한다. 사용자 매뉴얼은 준비된 제품에서 기능을 사용하는 절차를 안내한다.

두 문서는 읽는 사람이 겹쳐도 작업 목표가 다르다. 환경 변수 설정 오류와 신청 취소 방법을 같은 절차로 설명하지 않는다.

문서에는 대상 제품 버전과 전제 상태를 적는다. 설치 전 화면과 사용 중 화면을 구분해야 절차를 재현할 수 있다.

작은 예제로 확인하기

대상 제품은 접수앱 v2다. 운영자는 빈 서버에 런타임을 설치하고 환경 변수를 설정해야 한다. 이미 설치된 앱의 일반 사용자는 신청 취소 방법을 찾고 있다.

조건 판단과 결과
접수앱v2; 운영자=빈 서버 런타임/환경 변수 준비; 일반 사용자=설치 완료 앱에서 신청 취소. 설치 안내와 기능 사용 안내로 배치
접수앱v2; 운영자가 설치 직후 버전 확인 명령과 정상 결과를 찾음; 신청 작업은 묻지 않음. 설치 완료 확인 절차
접수앱v2; 설치 완료·로그인 완료; 일반 사용자가 날짜별 신청 검색 절차를 찾음. 기능 사용 안내

설치 전 환경 준비는 운영자의 설치 작업이다. 앱이 준비된 뒤 신청을 취소하는 일은 일반 기능 사용이므로 각각의 작업 안내에 둔다.
