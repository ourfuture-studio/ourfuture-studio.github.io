입력값보다 그 값을 선택한 근거를 확인한다.

핵심 이론

블랙박스 기법은 내부 구조를 참조하지 않고 명세된 동작을 근거로 사례를 정한다. 화이트박스 기법은 내부 구조와 처리 경로를 근거로 정한다.

같은 입력 0이라도 허용 구간의 경계라서 고른 것인지, 특정 분기를 실행하려고 고른 것인지에 따라 선택 근거가 다르다.

블랙박스가 실행을 하지 않는다는 뜻은 아니다. 구조 관점의 구분과 정적·동적 수행 방식은 다른 축이다.

작은 예제로 확인하기

입력 나이의 허용 명세는 정수 20~60이다. 테스터는 코드를 열지 않고 명세의 하한 바로 아래와 하한을 확인하려고 19와 20을 골랐다.

조건 판단과 결과
정수20~60 허용 명세; 코드 미열람; 하한 밖/하한을 확인하려 19·20 선택. 블랙박스 선택
같은 정수20~60 명세; 코드를 읽고 age<20 분기의 참/거짓을 실행하려 19·20 선택. 화이트박스 선택
정수20~60 명세의 경계19·20을 고른 뒤 내부 age<20 분기 커버리지도 확인함. 두 관점을 함께 사용

값은 허용 구간 20~60의 명세에서 도출됐다. 내부 경로를 참조하지 않았으므로 블랙박스 기법이다.
