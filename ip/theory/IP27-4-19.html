DAS·NAS·SAN을 연결과 접근 단위로 나누기

관련 문제 1개조건 바꿔 체험

같은2TB라도 파일을 요청하는지 블록 장치를 쓰는지에 따라 구성이 다르다.

핵심 이론

DAS는 저장 장치를 서버에 직접 연결하는 구성을 뜻한다. 이 예제에서는 SAS로 서버 한 대에 직접 붙인 블록 장치를 사용한다.

NAS는 네트워크를 통해 파일 서비스를 제공한다. 클라이언트는 NFS나 SMB 같은 파일 프로토콜로 파일·디렉터리를 요청한다. SAN은 이 비교에서 저장 네트워크를 통해 블록 장치를 제공하고 호스트가 그 위의 파일 시스템을 관리한다.

Ethernet을 쓴다는 사실만으로 NAS라고 할 수 없다. iSCSI SAN도 Ethernet을 사용할 수 있다. 용량·속도·가격·접속 매체 하나만으로 분류하거나 특정 방식이 항상 빠르다고 단정하지 않는다.

작은 예제로 확인하기

용량2TB의 장치가 Ethernet을 통해 NFS 서비스를 제공한다. 클라이언트는 파일 경로로 읽고 쓰며 이 장치가 제공하는 파일 시스템을 사용한다.

구성 경로 클라이언트 접근
DAS SAS 직접 연결 블록 장치
NAS Ethernet·NFS 파일
SAN Ethernet·iSCSI 블록 장치

NFS 파일 서비스와 iSCSI 블록 서비스는 둘 다 Ethernet을 써도 접근 단위가 다르다.

다시 떠올릴 단서

저장 용량이 아니라 연결 경로와 파일·블록 접근 단위로 구별한다.

적용 범위

명시한 전통적 DAS·NAS·SAN의 경로 비교다. 실제 저장장치 연결·성능·장애 내성 측정은 수행하지 않았다.
