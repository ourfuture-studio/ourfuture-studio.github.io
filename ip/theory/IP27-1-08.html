UI 공통 규칙과 화면 흐름 명세

관련 문제 1개조건 바꿔 체험

반복되는 표현 규칙과 특정 화면의 동작을 다른 수준에서 정한다.

핵심 이론

UI는 사용자가 시스템과 상호작용하는 화면과 조작 요소다. UI 표준은 버튼·색·간격 같은 공통 규칙을, 화면 스토리보드는 특정 장면과 전환을 기술하는 데 사용한다.

이 예제의 스토리보드는 화면, 입력, 버튼 선택 후 이동, 오류 표시를 적는 화면 명세로 정의한다. UX에서 사용자 상황을 장면으로 그리는 스토리보드와 표현 범위가 같다고 단정하지 않는다.

공통 규칙만으로 다음 화면이 결정되지는 않는다. 반대로 한 화면의 전환 명세만으로 전체 서비스의 버튼 스타일이 일관되게 정해지지는 않는다.

작은 예제로 확인하기

서비스 공통 규칙은 '주요 버튼은 지정된 파란색'이다. 회원가입 화면의 화면 명세에는 '완료 선택 후 약관 미동의면 같은 화면에 오류 표시'가 있다. 오류 조건만 '약관 미동의 또는 이메일 누락'으로 변경한다.

조건 판단과 결과
공통 주요 버튼=파란색; 가입 화면 완료 시 미동의 오류; 이를 미동의 또는 이메일 누락 오류로 변경. 가입 화면의 처리 조건 갱신
공통 주요 버튼=파란색에서 보라색으로 변경; 가입 화면의 미동의/이메일 누락 오류 조건은 동일. 공통 스타일 규칙 갱신
공통 주요 버튼=파란색 유지; 가입 성공 후 이동을 홈에서 가입 완료 화면으로 변경; 오류 조건 동일. 가입 화면의 성공 전환 갱신

변경 대상은 이메일 누락을 포함하는 화면 오류 조건이다. 버튼 공통 색은 그대로이므로 해당 화면 명세의 완료 처리 분기를 갱신한다.

다시 떠올릴 단서

전체 화면에 적용할 규칙인지, 특정 화면의 동작인지 묻는다.

적용 범위

스토리보드의 조직별 서식은 다르다. 여기서는 명시한 화면 명세의 의미로 사용한다.
