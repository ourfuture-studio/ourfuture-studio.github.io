COUNT는 행과 값을 다르게 센다

관련 문제 1개조건 바꿔 체험

NULL이 있는 열을 셀 때는 무엇을 하나로 세는지부터 정해야 한다.

핵심 이론

COUNT(*)는 결과에 들어온 행 수를 센다. COUNT(value)는 그중 value가 NULL이 아닌 행의 값을 센다. 값 0이나 빈 문자열을 NULL과 같은 이유로 제외하지 않는다.

COUNT(DISTINCT value)는 NULL이 아닌 서로 다른 값 수를 센다. 5가 두 번 나타나면 COUNT(value)에는 두 번 들어가지만 DISTINCT를 붙인 계산에는 한 번 들어간다.

행이 하나도 없는 집합에서도 GROUP BY 없는 COUNT는 0을 담은 한 결과 행을 만든다. SUM이나 AVG가 빈 입력에서 NULL을 반환하는 것과 구별한다. 이 예제는 정수·NULL만 쓰며 빈 문자열의 제품 차이는 포함하지 않는다.

작은 예제로 확인하기

Measure에는 (1,5),(2,5),(3,NULL),(4,9)만 있다. 삭제나 다른 필터는 없다.

id value
1 5
2 5
3 NULL
4 9

행은 4개, NULL 아닌 값은 5·5·9의 3개, 서로 다른 비NULL 값은 {5,9}의 2개다.

다시 떠올릴 단서

COUNT가 행, 비NULL 값, 서로 다른 값 중 무엇을 세는지 확인한다.

적용 범위

명시한 작은 예제의 조건에서 판단한다. 다른 DBMS의 실행 결과나 실제 성능 측정으로 일반화하지 않는다.
