반환시간에서 실행시간을 빼면 대기시간인가

관련 문제 1개조건 바꿔 체험

도착·시작·완료 시점을 분리하고 I/O와 선점 유무부터 고정한다.

핵심 이론

반환시간 T는 도착부터 완료까지 걸린 시간으로 T=C-A이다. C는 완료 시각, A는 도착 시각이다. 대기시간 W는 준비 상태에서 CPU를 기다린 시간이다.

이 예제는 단일 CPU, 한 번의 CPU 버스트, I/O 없음, 선점 없음, 문맥 교환 비용0이다. 따라서 실행시간 B를 빼 W=T-B로 구할 수 있고, 시작 시각 S를 알면 W=S-A로 독립 검산할 수 있다.

FCFS는 먼저 도착한 준비 작업부터 실행하고, 비선점 SJF는 CPU가 비었을 때 도착해 있는 작업 중 버스트가 가장 짧은 것을 고른다. 미래에 도착할 짧은 작업 때문에 이미 실행 중인 작업을 중단하지 않는다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. 단일 CPU 비선점 FCFS. P(A=0,B=4), Q(A=1,B=3), R(A=2,B=1). I/O와 문맥교환 비용0.

조건 또는 단계 판단 또는 값
P:도착0·실행4 0~4 실행
Q:도착1·실행3 4~7 실행
R:도착2·실행1 7~8 실행
Q의 T / W 7-1=6 / 4-1=3

Q의 반환시간6에서 실제 실행3을 빼도 대기3으로 일치한다.

다시 떠올릴 단서

반환은 도착부터 완료, 대기는 실행하지 않고 준비 상태로 기다린 구간이다.

적용 범위

시간 단위는 모두 같다. 선점·I/O·문맥 교환이 없는 지정 모형만 계산한다.
