얕은 복사는 어느 깊이까지 새로 만드는가

관련 문제 1개조건 바꿔 체험

바깥 리스트가 새로 만들어져도 내부 리스트는 공유될 수 있다.

핵심 이론

Python의 b=a는 객체 복사가 아니라 이름 b를 같은 객체에 연결하는 대입이다. a=[[1],[2]]라면 a와 b가 같은 바깥 리스트를 가리킨다.

a.copy()는 새 바깥 리스트를 만들지만 원소의 참조를 그대로 넣는 얕은 복사이다. 따라서 b=a.copy(); b[0].append(9)는 a[0]으로도 관찰된다. 반면 b.append([9])는 새 바깥 리스트 b에만 원소를 추가한다.

copy.deepcopy는 중첩 객체도 재귀적으로 복사하는 기능이다. 사용자 정의 복사 동작과 순환 참조에는 별도 규칙이 있으므로 여기서는 정수와 중첩 리스트만 비교한다. 바깥 객체 동일성과 내부 객체 동일성을 따로 검사한다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. a=[[1],[2]]; b=a.copy(); b[0].append(9).

조건 또는 단계 판단 또는 값
b=a.copy() 바깥 리스트는 다름
b[0].append(9) 내부 첫 리스트는 공유
a, b의 값 둘 다 [[1,9],[2]]

바깥 리스트 복사를 내부 원소 객체 복사로 확대 해석하지 않는다.

다시 떠올릴 단서

새 바깥 객체인지, 내부 객체까지 새로 만든 것인지 나누어 본다.

적용 범위

정수와 리스트만 사용하며 사용자 정의 copy·__deepcopy__는 없다.
