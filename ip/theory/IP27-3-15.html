컨테이너별 순서·중복·변경 가능성

관련 문제 1개조건 바꿔 체험

리스트, 튜플, 집합, 사전은 서로 다른 제약을 가진다.

핵심 이론

리스트는 순서가 있고 같은 값을 여러 번 저장하며 원소 대입으로 바꿀 수 있다. 튜플도 순서와 중복을 허용하지만 튜플 원소 자리 자체는 바꿀 수 없다. 튜플 안 가변 객체의 변경 가능성과 튜플 자리 재대입은 구별한다.

집합은 동등한 원소의 중복을 보관하지 않으며 인덱스로 순서를 지정해 접근하는 시퀀스가 아니다. 집합 원소는 해시 가능해야 한다. 출력 순서 자체를 정답으로 삼지 않고 len이나 membership으로 확인한다.

사전은 키와 값의 대응을 저장하며 키는 해시 가능해야 한다. 같은 키에 다시 대입하면 기존 값이 바뀌고 항목 수가 자동으로 늘어나지 않는다. Python 3.13 사전은 삽입 순서를 보존하지만 이 보존 규칙을 집합에 적용하지 않는다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. values=[2,2,5]; print(len(values),len(set(values))).

조건 또는 단계 판단 또는 값
[2,2,5] len=3
(2,2,5) len=3, 자리 재대입 불가
{2,2,5} len=2
{"x":1} 뒤 d["x"]=9 len=1, 값9

집합의 표시 순서를 예측하지 않아도 중복 제거 여부는 검증할 수 있다.

컨테이너 이름보다 원하는 조작과 그 제약을 짝지어 확인한다.

적용 범위

정수 집합과 문자열 키 사전만 사용하며 출력 순서가 미정인 컨테이너 전체를 출력하지 않는다.
