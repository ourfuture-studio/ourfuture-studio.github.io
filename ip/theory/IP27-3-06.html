인자의 복사와 포인터가 가리키는 대상 수정

관련 문제 1개조건 바꿔 체험

C는 인자 값을 복사한다. 복사한 포인터로 원래 대상을 수정할 수는 있다.

핵심 이론

함수의 int v 매개변수는 호출자가 준 정수값으로 초기화되는 별도 객체이다. 함수 안에서 v=11을 실행해도 호출자 x의 값은 바뀌지 않는다.

int p 매개변수도 포인터값을 복사받는다. 그러나 p가 &x를 받았다면 p=11은 호출자 x가 있는 저장 위치를 수정한다. 포인터 전달을 C의 참조 전달이라고 단정하면 포인터 자체의 재대입과 대상 수정을 혼동하게 된다.

함수 안에서 p를 다른 주소로 재대입하는 것은 복사된 포인터 매개변수만 바꾼다. 호출자 포인터 자체를 수정하려면 그 포인터의 주소 등을 별도로 전달해야 한다. 여기서는 NULL, 수명 종료 객체, 잘못된 주소를 사용하지 않는다.

작은 예제로 확인하기

C11 의미 규칙(N1570), signed int이며 아래 작은 값에서 범위 초과 없음. 각 코드는 표준 헤더와 main을 포함한 독립 프로그램이고 입력 없음. 0으로 나누지 않는다. x=5에서 by_value(x)만 호출한다.

조건 또는 단계 판단 또는 값
x=5; by_value(x) x=5
x=5; by_pointer(&x) x=11
값 복사 후 대상 접근 *p로 x에 쓰기

매개변수 객체가 무엇인지, 대입의 왼쪽이 v인지 *p인지 구분한다.

다시 떠올릴 단서

복사된 값이 주소이면 그 주소가 가리키는 객체는 수정할 수 있다.

적용 범위

모든 포인터는 호출 중 살아 있는 int 객체를 가리킨다.
