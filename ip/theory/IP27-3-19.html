스택과 큐는 제거할 끝이 다르다

관련 문제 1개조건 바꿔 체험

같은 순서로 넣었어도 스택(Stack, LIFO: Last In First Out)은 마지막 원소, 큐(Queue, FIFO: First In First Out)는 첫 원소를 먼저 꺼낸다.

핵심 이론

스택은 마지막에 넣은 원소를 먼저 제거하는 LIFO 구조이다. 여기서는 리스트 오른쪽에 append하고 같은 오른쪽에서 pop한다. 맨 위 top은 가장 최근 삽입 원소이다.

큐는 먼저 넣은 원소를 먼저 제거하는 FIFO 구조이다. deque의 오른쪽 append와 왼쪽 popleft를 사용한다. front는 아직 제거되지 않은 가장 오래된 원소이다.

두 구조의 차이는 저장된 원소의 집합보다 허용된 삽입·제거 끝에 있다. 빈 구조에서 제거할 때의 오류나 우선순위 큐는 별도 규칙이므로 여기서는 비어 있지 않은 독립 구조에서 한 번씩 제거한다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. A,B,C 순으로 각각 스택·큐에 삽입한 뒤 한 번씩 제거한다.

조건 또는 단계 판단 또는 값
삽입 순서 A→B→C
스택 제거 C
큐 제거 A

삽입된 시각과 제거하는 끝을 적어 두 구조를 각각 추적한다.

다시 떠올릴 단서

스택은 마지막 삽입, 큐는 첫 삽입부터 제거한다.

적용 범위

원소 수가 1개 이상이며 스택과 큐는 독립 객체이다.
