슬라이스는 끝값을 포함하지 않는다

관련 문제 3개조건 바꿔 체험

시작점에서 간격만큼 이동하되 끝 경계에 닿기 전에 멈춘다.

코드 한 줄씩 추적하기

변수·객체·실행 순서를 함께 살펴보고 같은 개념의 문제로 이어갑니다.

프로그래밍 학습 →관련 문제풀이

핵심 이론

핵심 용어: 슬라이싱(slicing).

a[start:stop:step]에서 start는 시작 인덱스, stop은 포함하지 않는 끝 경계, step은 이동 간격이다. 인덱스는 0부터 센다. a[1:5:2]는 1, 3번 원소를 선택한다.

step이 음수이면 인덱스가 감소한다. a[5:1:-2]는 5, 3을 선택하고 1은 제외한다. 생략한 경계와 명시한 -1의 의미는 음수 간격에서 다를 수 있어 여기서는 둘 다 명시한다.

일반 슬라이스의 범위 밖 경계는 허용 범위로 조정되지만 step=0은 ValueError이다. 단일 인덱스 접근의 IndexError 규칙을 슬라이스 전체에 그대로 적용하지 않는다.

작은 예제로 확인하기

Python 3.13, UTF-8 독립 스크립트, 외부 입력 없음. a=[0, 1, 2, 3, 4, 5]; a[1:5:2].

조건 또는 단계 판단 또는 값
a=[0, 1, 2, 3, 4, 5] 인덱스와 값이 같음
a[1:5:2] [1, 3]
끝 경계 5 원소 5는 제외

값을 계산하기 전에 선택되는 인덱스만 나열하면 경계 실수를 줄일 수 있다.

다시 떠올릴 단서

간격의 부호로 진행 방향을 정하고 stop은 제외한다.

적용 범위

리스트·명시적 정수 경계·0이 아닌 간격만 다룬다.
