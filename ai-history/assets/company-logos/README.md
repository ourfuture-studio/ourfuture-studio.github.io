# 회사·연구조직 PNG 로고

16개 로고를 회사 선택 목록, 회사 소개 상단, 연결 보기에서 사용한다. 모두 로컬 PNG이며 외부 이미지 서비스에 실시간 의존하지 않는다.

- `sources.json`: 원본 URL, 확인일, 실제 크기, SHA-256, 원본과의 차이 및 권리 확인 범위.
- 회사별 경로·크기·출처는 `company-history/<companyId>.json`의 `logo`에 저장한다.
- 공식 PNG는 원본 그대로 또는 비율을 유지해 축소했다. SVG만 제공되는 경우 원본을 수정하지 않고 PNG로 변환했다.
- 긴 워드마크는 가로형으로 배치하고 `object-fit: contain`으로 표시한다. 색상 반전·가로세로 늘이기·로고 일부 자르기를 하지 않는다.
- Google 로고는 Google/DNNresearch 탐색 단위의 Google 대표 표시다. DNNresearch 자체 로고라는 뜻이 아니다. Qwen은 팀·모델 로고이며 Alibaba 회사 전체의 로고가 아니다.
- 현재 조직의 대표 로고를 사용하며 과거 각 사건 당시에 사용된 로고를 재현하는 자료는 아니다.

공개 사이트에서 구할 수 있다는 사실은 상업 이용·재배포의 포괄적 허가를 뜻하지 않는다. 일부 브랜드 지침에는 사전 허락이나 크기·여백 조건이 있으므로 공개 배포 시 실제 사용 맥락에 맞는 조건을 확인해야 한다. 각 회사의 구체적인 확인 범위는 `sources.json`에 보존했다.
