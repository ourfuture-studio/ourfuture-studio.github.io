# AI 과거와 미래

연결주의 AI 28개, 심볼릭 AI 13개, 결합 연구 9개를 같은 연표에서 탐색합니다.
50개 상세 카드에는 핵심 질문, 논문·표준의 출처, 직접 조작하는 시각화가 있습니다.

- [사이트 열기](https://ourfuture-studio.github.io/ai-history/)
- [소재·출처와 공개본 구성](PUBLIC-ASSETS.json)
- [스튜디오 저작권·이용 안내](../COPYRIGHT.md)

`entries/`는 카드 본문과 예시, `visuals/`는 상호작용과 스타일입니다.
정적 HTML·JavaScript로 실행하며 모델 서버나 별도 계정은 필요하지 않습니다.
그림의 계산 범위와 논문 결과의 차이는 각 카드에 명시했습니다.

출처가 다른 인물 사진과 논문 도판은 각각의 저자와 라이선스를 따릅니다.
공개 재배포 조건을 확인하지 못한 도판은 원문 링크로 연결합니다.
원본 PDF, 로컬 검토 이미지, 편집 기록은 이 배포본에 포함하지 않습니다.

## 인물 관계도 · v0.36

지도 관계·공동 연구·영향을 그래프로 탐색합니다. 기본 53명·36개 관계이며, 공동 창업·논쟁·기관 인연을 추가하면 64명·46개 관계를 볼 수 있습니다. 관계마다 기존 원고의 출처와 설명을 연결하고, 지도자→제자와 영향을 준 사람→받은 사람의 방향을 구분합니다. 배치상의 거리는 영향력이나 시대 순서를 뜻하지 않습니다.

인물 이름 검색, 한 인물의 직접 연결 보기, 관계 종류 필터, 확대·축소·이동을 제공합니다. 기존 카드가 있는 인물 41명은 노드를 눌러 해당 카드로 이동합니다. 나머지는 관계 근거를 표시하며 빈 인물 카드를 만들지 않습니다. `person-graph-core.js`가 자료·필터·배치를, `person-graph.js`와 `person-graph.css`가 화면을 관리합니다.

튜링은 사용자가 지정한 [16세 때 사진](https://commons.wikimedia.org/wiki/File:Alan_Turing_Aged_16.jpg)을 표시합니다. 원본 파일을 변경 없이 보관하며, 사이트 내부 사진을 먼저 불러옵니다. Commons가 표시한 Public domain 상태, 불확실성을 남긴 촬영자 표기와 [King's College의 신원 기록](https://turingarchive.kings.cam.ac.uk/material-given-kings-college-cambridge-1960-amtk/amt-k-7-4)을 함께 안내합니다. 아래 v0.35 문단의 Wellcome 사진은 이전 개정의 기록이며 파일과 출처는 보존했습니다.

## 이전 인물 배경 · v0.35

주요24명과 결합 연구2명의 출신·학업·연구 환경, 근거를 붙인 인물 관계50개를 제공합니다. 출생과 성장을 구분하고, 학업 장소를 출생지로 처리하지 않습니다. 이미 등록된 관련 인물은 이름을 눌러 이동할 수 있습니다.

배경 데이터는 `person-background-data.js`, 표시와 방향을 구분한 연결 구조는 `person-background.js`, 스타일은 `person-background.css`입니다. 작업 원본은 인물별 JSON으로 분리해 관리합니다. 튜링과 로젠블랫의 사진은 Wellcome/미 해군박물관 출처이며, 사진 아래에 각각의 소장기관·원본·이용 조건을 표시합니다.
