# AI 과거와 미래

연결주의 AI 28개, 심볼릭 AI 13개, 결합 연구 9개를 같은 연표에서 탐색합니다.
50개 상세 카드에는 핵심 질문, 논문·표준의 출처, 직접 조작하는 시각화가 있습니다.

- [사이트 열기](https://ourfuture-studio.github.io/ai-history/)
- [소재·출처와 공개본 구성](PUBLIC-ASSETS.json)
- [스튜디오 저작권·이용 안내](../COPYRIGHT.md)

`entries/`는 카드 본문과 예시, `visuals/`는 상호작용과 스타일입니다.
정적 HTML·JavaScript로 실행하며 모델 서버나 별도 계정은 필요하지 않습니다.
그림의 계산 범위와 논문 결과의 차이는 각 카드에 명시했습니다.

출처가 다른 인물 사진과 논문 도판은 각각의 저자와 라이선스를 따릅니다.
공개 재배포 조건을 확인하지 못한 도판은 원문 링크로 연결합니다.
원본 PDF, 로컬 검토 이미지, 편집 기록은 이 배포본에 포함하지 않습니다.

## 이전 맥스 뉴먼 · v0.38

“어떤 논리식이 주어져도, 규칙만 따라 답을 낼 수 있을까?”에서 시작하는 인물 카드를 추가했습니다. 1935년 결정문제 강의의 영향은 King’s College의 아카이브 전시와 기관 기록에, 뉴먼 자신의 후대 설명은 1955년 회고 원본에, 구체적인 계산 모형은 튜링 원논문에 근거합니다. 확인하지 못한 당시 강의 원고나 칠판을 복원한 것처럼 표시하지 않습니다.

대상 둘과 관계 하나의 16개 세계에서 양화사의 순서를 바꿀 때의 참·거짓과 반례를 실제로 검사합니다. 이어서 튜링 원논문 §3 Example I의 네 행을 따라 테이프에 기호를 쓰는 유한한 동작을 보여 줍니다. 이 제한된 계산을 일반 결정문제의 해결이나 계산불가능성 정리의 증명으로 제시하지 않습니다.

뉴먼과 튜링의 관계는 연구에 준 영향과 피드백으로 연결하며, 처치의 프린스턴 박사 지도와 구분합니다. 기존 연표 50개를 보존하고 인물은211명·상세28명·고유 연구80개입니다. 관계도는64명·46개 관계를 유지하며 카드로 연결되는 인물은43명입니다.

로고와 표시된 ‘홈’ 링크는 [스튜디오 메인](https://ourfuture-studio.github.io/)으로 이동합니다. 메인 홈페이지 상단의 ‘AI 과거와 미래’ 메뉴로 이 탐색기에 돌아올 수 있습니다. 뉴먼 원고는 `newman-data.js`, 계산은 `visuals/newman-decision-core.js`, 화면은 `visuals/newman-decision.js`·`newman-decision.css`에서 관리합니다. 아래는 이전 개정 기록입니다.

## 이전 알론조 처치 · v0.37

“계산을 수학적으로 어떻게 정의할까?”를 중심으로, 처치의 1936년 논문을 읽는 인물 카드를 추가했습니다. 함수의 식·입력·치환 규칙을 연결하고, 입력 돌려주기·입력 복제·이름이 겹칠 때의 변환·양의 정수의 후속자·되돌아오는 식을 한 단계씩 살펴봅니다. 식의 자유변수가 잘못 묶이지 않도록 하는 이름 변경과 실제 입력의 치환을 구분합니다.

원문의 기호와 현대 표기를 나란히 보여주며, 직접 구성한 사례와 원문의 문법 조건을 구분합니다. 계산 단계 한도에 도달한 상태를 정규형이나 비종료의 증명으로 표시하지 않습니다. 계산가능성의 정의 제안·형식적 결과·지능에 대한 해석도 나누어 읽습니다.

처치의 배경·연구 기관과 튜링의 1936–1938년 박사 지도를 출처와 함께 표시합니다. 기존 튜링→처치 기록의 역방향 원고를 더하되, 관계도에서는 지도자→제자의 같은 간선 하나로 합칩니다. 연표의 기존 50개 연구는 유지하며 인물은 210명, 상세 인물은 27명, 고유 연구 기록은 79개입니다. 관계도는 기존 64명·46개 관계를 유지하고, 카드로 연결되는 인물은 42명입니다.

처치 원고는 `church-data.js`, 계산은 `visuals/church-lambda-core.js`, 화면은 `visuals/church-lambda.js`·`visuals/church-lambda.css`에서 관리합니다. 처치 사진이나 논문 PDF를 새로 배포하지 않습니다. 아래 문단은 이전 개정의 기록입니다.

## 이전 인물 관계도 · v0.36

지도 관계·공동 연구·영향을 그래프로 탐색합니다. 기본 53명·36개 관계이며, 공동 창업·논쟁·기관 인연을 추가하면 64명·46개 관계를 볼 수 있습니다. 관계마다 기존 원고의 출처와 설명을 연결하고, 지도자→제자와 영향을 준 사람→받은 사람의 방향을 구분합니다. 배치상의 거리는 영향력이나 시대 순서를 뜻하지 않습니다.

인물 이름 검색, 한 인물의 직접 연결 보기, 관계 종류 필터, 확대·축소·이동을 제공합니다. 기존 카드가 있는 인물 41명은 노드를 눌러 해당 카드로 이동합니다. 나머지는 관계 근거를 표시하며 빈 인물 카드를 만들지 않습니다. `person-graph-core.js`가 자료·필터·배치를, `person-graph.js`와 `person-graph.css`가 화면을 관리합니다.

튜링은 사용자가 지정한 [16세 때 사진](https://commons.wikimedia.org/wiki/File:Alan_Turing_Aged_16.jpg)을 표시합니다. 원본 파일을 변경 없이 보관하며, 사이트 내부 사진을 먼저 불러옵니다. Commons가 표시한 Public domain 상태, 불확실성을 남긴 촬영자 표기와 [King's College의 신원 기록](https://turingarchive.kings.cam.ac.uk/material-given-kings-college-cambridge-1960-amtk/amt-k-7-4)을 함께 안내합니다. 아래 v0.35 문단의 Wellcome 사진은 이전 개정의 기록이며 파일과 출처는 보존했습니다.
