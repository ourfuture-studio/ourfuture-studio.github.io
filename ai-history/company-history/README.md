# 회사·연구조직 연대기

각 JSON이 한 회사·조직의 원본이다. `company-core.js`는 검색·기간 필터, `companies.js`와 `companies.css`는 공통 화면을 담당한다. 회사 추가 시 `AtlasCompanyCore.ids`에도 식별자를 추가한다.

## 자료 수정

- `id`는 파일명과 같아야 한다. 회사·연구조직·연구팀은 `kind`로 구분한다.
- `aliases`에는 회사 탐색에 유용한 별칭·제품·기술어를 넣을 수 있다. `orgAliases`에는 조직명 별칭만 둔다. 사건 검색에서 다른 연도의 기술어가 섞이지 않도록 분리한다.
- `people[].id`, `events[].peopleIds`, `events[].workIds`는 기존 인물·연구 식별자만 사용한다. 아직 상세 카드가 없는 인물은 이름과 당시 역할을 적는다.
- `date`와 `precision`은 확인된 정밀도까지만 적는다. 일자를 모르면 임의로 1일을 넣지 않는다. `dateLabel`에 분기, 공지일과 예정 행사일 등을 설명한다.
- 사건에는 질문, 아이디어, 변화, 단계별 `flow`, 원자료, 확인 범위인 `caveat`를 적는다. 도식은 설명을 위한 재구성이며 실제 시스템 실행 결과를 뜻하지 않는다.
- 같은 협력을 두 회사 연표에 표시하면 `sharedEventId`를 공유한다. 현재 86개 회사 기록은 공동 협력의 양쪽 표시 1쌍을 포함한다.
- `connections`는 다른 회사·조직과의 관계다. 유형·당시 역할·날짜를 보존한다. 화면에서 역방향 탐색을 제공해도 관계 자체를 반대로 해석하지 않는다. 기간 필터를 쓰면 시점 미확인 관계는 표시하지 않는다.
- `logo`는 로컬 PNG의 경로·실제 크기·대표 브랜드명·출처·권리 메모를 보존한다. PNG는 `assets/company-logos/`에 있으며 `sources.json`에 출처를 모았다. 로고 교체 시 원본 비율·색을 유지하고 해당 회사 JSON의 크기·출처도 함께 갱신한다. 어두운 화면에서도 색 반전 대신 로고 받침의 대비를 조정한다.
- 원논문은 당시 소속으로 귀속한다. 인수·이직 후의 회사를 과거 연구의 소속으로 덧씌우지 않는다.

## 공개판

회사 JSON과 독립적인 인물·연구 모듈을 수정한 뒤 배포 패키지를 검증합니다. 원도판의 직접 표시와 원문 링크는 자료별 출처 기록에 따릅니다.
